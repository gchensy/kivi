基于 pandas 的信用风险建模#

kivi 是面向信用风险与金融建模的 pandas 工具包。它分析候选变量、为其分箱并对类别分组，衡量每一箱对违约等二分类结果的区分能力，筛选变量并拟合逻辑回归评分卡，推断被拒申请人的结果，把模型刻度为分值，评估模型并基于主标尺进行校准，衡量各截断点的代价与预期损失。模型上线后，它逐期监控评分，跟踪已批准贷款的表现，并计量其 IFRS 9 预期信用损失。表格结果都是 pandas DataFrame，每箱、每个等级、每个截断点、每期或每个变量一行。

速览#

import pandas as pd
from kivi.binning import bin_edges
from kivi.datasets import Dataset
from kivi.stability import psi_table
from kivi.woe import woe_table

data = Dataset.bank_data()
reference, current = data.iloc[:3000], data.iloc[3000:]

edges = bin_edges(reference["age"], bins=5)
before = pd.cut(reference["age"], edges)
after = pd.cut(current["age"], edges)

evidence = woe_table(before, reference["target"])
stability = psi_table(before, after)

分箱

细分箱与粗分箱、特殊值处理、单调 WOE，以及用于逻辑回归评分卡的类别分组。

分箱
WOE 与 IV

每箱的 WOE 和 IV，平滑时不改动计数，以及新数据的 WOE 编码。

证据权重与信息值
变量筛选

按 IV 给候选变量排序，剔除高度相关的变量，并选出系数方向全部正确的逻辑回归模型。

变量筛选
拒绝推断

用模糊扩充、打包法或重新加权推断被拒申请人的结果，并在全部申请人上重新拟合模型。

拒绝推断
评分卡

用 PDO 刻度把模型转换为分值，为新申请打分，并用原因码解释每个分数。

评分卡
模型表现

在开发样本和验证样本上计算 AUC、Gini、KS、增益表与 ROC 表，并给出 AUC 的置信区间和两个评分的 DeLong 检验。

模型表现
校准

先验校正、主标尺，按评级做二项检验、Jeffreys 检验和 Hosmer-Lemeshow 检验，以及 Platt 与保序回归重新校准。

校准
信贷策略

每个截断点的通过率与坏账率、现行评分与新评分之间的交换集，以及按等级的预期损失。

信贷策略
分箱方案

把每个变量的分箱和 WOE 保存为带版本号的 JSON，生产环境对新数据的分组与开发时完全一致。

分箱方案
群体稳定性

逐箱比较线上数据与开发样本，按期跟踪 PSI，并用 CSI 衡量每个变量对分数的影响。

群体稳定性指标
模型监控

每期一行：样本量、已知结果、AUC、Gini、KS 和评分的 PSI；以及各变量在每期的 PSI。

模型监控
Vintage 与滚动率分析

按放款批次的 vintage 曲线，以及逾期档位之间的滚动率和转移矩阵。

Vintage 与滚动率分析

工作流程#

概况与分箱

profile_table 让你先概览每个候选变量。 bin_edges ，或 monotonic_edges 等有监督方法，在开发样本上拟合一次边界， chimerge_groups 则对类别变量的类别分组。之后的每个样本都用同样的边界和分组，最外侧边界为无穷，因此后续数据总能落入某个箱。

编码与拟合

woe_table 衡量每箱相对目标变量的表现， woe_transform 据此编码。 stepwise 和 logistic_regression 筛选变量并拟合模型，可通过 weights 纳入推断的拒绝样本。

刻度与评估

points_table 把模型转换为分值， gains_table 、 roc_auc 和 ks 在留出样本上衡量分数对申请人的排序能力。 roc_auc_interval 显示一个样本对 AUC 的测量有多精确。

校准与决策

master_scale 和 assign_grades 把 PD 划分为等级，二项检验和 Jeffreys 检验核对每个等级的 PD。 cutoff_table 显示每个截断点通过哪些申请， expected_loss_table 汇总每个等级的预期损失。

部署与监控

BinningSpec 把分箱方案保存为 JSON 供生产环境使用。 monitoring_table 和 stability_table 把每一期与开发样本比较， csi_table 衡量各变量对评分的影响。

跟踪贷款

vintage_table 和 transition_matrix 跟踪已批准的贷款。 convert_pd 和 transition_pd 把它们转换为 PD 期限结构， expected_credit_loss 和 assign_stages 给出 IFRS 9 损失准备。
