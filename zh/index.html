基于 pandas 的信用风险建模#

kivi 是面向信用风险与金融建模的 pandas 工具包。它由交易流水和还款历史计算时点正确的特征，分析候选变量、为其分箱并对类别分组，衡量每一箱对违约等二分类结果的区分能力，筛选变量并拟合逻辑回归评分卡，或为专家评分卡确定各因子的权重，推断被拒申请人的结果，把模型刻度为分值，评估模型，基于主标尺进行校准并校准到长期平均违约率，由清收和授信额度估计违约损失率和违约风险敞口，按预期损失和利润为各截断点定价，并衡量和搜索无论评分如何都会拒绝申请人的政策规则。模型上线后，它逐期监控评分，用监管机构对内部评级模型要求的检验验证模型，计算其 PD 所需的监管资本，跟踪已批准贷款的还款和表现，并估计其存续期 PD 和 IFRS 9 预期信用损失。表格结果都是 pandas DataFrame，每箱、每个等级、每个截断点、每条规则、每期或每个变量一行， kivi.plotting 则把这些表绘制成图表。

速览#

import pandas as pd
from kivi.binning import bin_edges
from kivi.datasets import load_bank
from kivi.stability import psi_table
from kivi.woe import woe_table

data = load_bank()
reference, current = data.iloc[:3000], data.iloc[3000:]

edges = bin_edges(reference["age"], bins=5)
before = pd.cut(reference["age"], edges)
after = pd.cut(current["age"], edges)

evidence = woe_table(before, reference["target"])
stability = psi_table(before, after)

为风控团队打造#

时间窗特征

由事件表和月度状态面板，以时点正确的方式为每笔申请计算交易时间窗特征和还款行为特征，特征定义保存为带版本号的 JSON。

时间窗特征
单变量概况

用一张表列出每个候选变量的缺失值、分布及其形态、事件率、初步的 IV 排序和卡方检验。

单变量概况
分箱

细分箱与粗分箱、特殊值处理、ChiMerge、决策树、Best-KS 与单调分箱，在每箱占比、事件数和 WOE 形状的约束下的最优分箱，LGD 等连续型响应的分箱，以及用于逻辑回归评分卡的类别分组。

分箱
WOE 与 IV

每箱的 WOE 和 IV，平滑时不改动计数，各箱 WOE 的趋势，新数据的 WOE 编码，以及为什么有监督分箱会高估其自身样本上的 IV。

证据权重与信息值
变量筛选

按 IV 给候选变量排序，剔除 Pearson 或 Spearman 相关系数或 VIF 过高的变量，选出系数方向全部正确的逻辑回归模型，并在验证样本上跟踪嵌套模型的 AUC。

变量筛选
拒绝推断

用模糊扩充、打包法或重新加权推断被拒申请人的结果，并在全部申请人上重新拟合模型。

拒绝推断
评分卡

用 PDO 刻度把模型转换为分值，为新申请打分，并用原因码解释每个分数。

评分卡
专家评分卡

用层次分析法为按判断设定的评分卡确定各因子的权重，并检验两两比较是否一致。

专家评分卡
模型表现

在开发样本和验证样本上计算 AUC、Gini、KS、增益表与 ROC 表，并给出 AUC 的置信区间、两个评分的 DeLong 检验、LGD 分段的广义 AUC 以及信用评分的期望最大利润。

模型表现
校准

先验校正、主标尺，按评级做二项检验、Jeffreys 检验和 Hosmer-Lemeshow 检验，Spiegelhalter 检验、Brier 分数分解，Platt 与保序回归重新校准，以及把 PD 校准到长期平均违约率。

校准
LGD 与 EAD

由清收现金流计算实际 LGD、计算授信额度的实际 CCF、LGD 表（含按 LGD 拟合的驱动变量分段）和分数 logit，并给出巴塞尔、EBA 和中国的规则。

LGD 与 EAD
信贷策略

每个截断点的通过率与坏账率、收益与利润、混淆矩阵与 F1，现行评分与新评分之间的交换集，以及按等级的预期损失。

信贷策略
政策规则

每条政策规则的命中、事件率和独有命中，规则集的决策瀑布表（在只有通过的申请人才有结果时同样可以衡量），以及单阈值新规则的搜索。

政策规则
分箱方案

把每个变量的分箱和 WOE 保存为带版本号的 JSON，生产环境对新数据的分组与开发时完全一致。

分箱方案
群体稳定性

逐箱比较线上数据与开发样本，按期跟踪 PSI，并用 CSI 衡量每个变量对分数的影响。

群体稳定性指标
模型监控

每期一行：样本量、已知结果、AUC、Gini、KS 和评分的 PSI；以及各变量在每期的 PSI。

模型监控
模型验证

欧洲央行验证报告对 PD、LGD 和 CCF 模型要求的检验：回测、当前与初始的 AUC 和 gAUC 比较、评级迁移以及等级集中度。

模型验证
监管资本

巴塞尔框架和中国 2023 年规则下内部评级法的资本要求，Vasicek 模型的压力 PD，以及低违约组合的最审慎 PD。

监管资本
Vintage 与滚动率分析

根据还款计划构建的月度逾期面板、按放款批次的 vintage 曲线、按队列法计算的一年违约率、逾期档位之间的滚动率和转移矩阵，以及评级等级之间的迁移。

Vintage 与滚动率分析
存续期 PD 与预期信用损失

由 vintage 曲线、转移矩阵和生存表得到 PD 期限结构，计算多种经济情景下的 12 个月与整个存续期 ECL，并划分 IFRS 9 的三个阶段。

存续期 PD 与预期信用损失
图表

用 matplotlib 直接根据 kivi 的表绘制 WOE、ROC、精确率-召回率、增益、分布、校准、截断点、利润、PSI、监控、vintage、生存曲线、转移矩阵、规则集和 LGD 图表。

工作流程#

特征、概况与分箱

window_features 和 panel_features 把交易流水和月度还款状态变成候选变量，只使用每个申请日期时已知的信息。 profile_table 让你先概览每个候选变量。 bin_edges ，或 monotonic_edges 、 optimal_edges 等有监督方法，在开发样本上拟合一次边界， chimerge_groups 则对类别变量的类别分组。之后的每个样本都用同样的边界和分组，最外侧边界为无穷，因此后续数据总能落入某个箱。

编码与拟合

woe_table 衡量每箱相对目标变量的表现， woe_trend 给出其 WOE 的形状， woe_transform 据此编码。 vif_filter 剔除共线变量， stepwise 和 logistic_regression 筛选变量并拟合模型，可通过 weights 纳入推断的拒绝样本， selection_path 则在验证样本上显示从哪里开始增加变量不再带来收益。

刻度与评估

points_table 把模型转换为分值， gains_table 、 roc_auc 和 ks 在留出样本上衡量分数对申请人的排序能力。 roc_auc_interval 显示一个样本对 AUC 的测量有多精确， expected_maximum_profit 显示评分的最优截断点能赚多少。

校准与决策

master_scale 和 assign_grades 把 PD 划分为等级， central_tendency_shift 把它们调整到长期平均违约率，二项检验和 Jeffreys 检验核对每个等级的 PD。 workout_lgd 和 conversion_factor 给出违约贷款的实际 LGD 和 CCF， variance_edges 按 LGD 为驱动变量拟合分段， lgd_table 按组汇总它们， fractional_regression 对 LGD 建模。 cutoff_table 显示每个截断点通过哪些申请，并在给出每个申请人的收益和损失时显示它赚多少， confusion_table 显示它拒绝了多少事件， expected_loss_table 汇总每个等级的预期损失。 rule_candidates 提出政策规则， rule_table 和 rule_set_table 在截断点之外衡量它们。 capital_requirement 把 PD 转换为内部评级法的资本要求， most_prudent_pd 给出违约太少的等级的 PD 上界。

部署、监控与验证

FeatureSpec 和 BinningSpec 把特征和分箱方案保存为 JSON 供生产环境使用。 monitoring_table 和 stability_table 把每一期与开发样本比较， csi_table 衡量各变量对评分的影响。每年一次， default_rate_table 统计各等级的一年违约率， backtest_table 、 generalized_auc 、 migration_test 和 concentration_test 给出欧洲央行验证报告中的检验。

跟踪贷款

delinquency_panel 根据已批准贷款的还款计划和还款记录构建其月度逾期情况， vintage_table 和 transition_matrix 对其进行跟踪。 convert_pd 、 transition_pd 和 survival_table 把 vintage 曲线、转移矩阵和贷款的存续时长转换为 PD 期限结构， conditional_pd 把它们移到各经济情景下， expected_credit_loss 和 assign_stages 给出 IFRS 9 损失准备。
