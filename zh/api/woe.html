证据权重与信息值#

衡量变量的每个分组区分二元目标变量的能力，并用结果对分组编码。 woe_table() 给出每组的 WOE 和 IV， woe_transform() 用它们对新数据编码； woe() 和 iv() 根据汇总计数计算同样的指标， woe_trend() 给出数值变量各箱 WOE 的趋势形状。

定义、示例以及如何解读结果，见 证据权重与信息值 。

woe_table(groups, target, *[, smoothing, ...])

按观察到的分组计算证据权重（WOE）和信息值（IV）。

woe_transform(groups, table, *[, unseen])

将每个分组替换为其证据权重（WOE）。

woe(event_counts, non_event_counts, *[, ...])

根据每组的计数计算其证据权重（WOE）。

iv(event_counts, non_event_counts, *[, ...])

根据每组的计数计算信息值（IV）。

woe_trend(table)

给出数值变量各箱 WOE 的趋势形状。
kivi.woe.woe_table(groups, target, *, smoothing=0.5, weights=None)#

按观察到的分组计算证据权重（WOE）和信息值（IV）。

比较每组在全部事件中的占比与在全部非事件中的占比。将 iv 列求和即得到该变量的信息值。

参数:
groupsarray_like

已分箱的数值或类别标签。缺失值独立成组。

targetarray_like

二分类标签，1 表示事件。如果 groups 和 target 都是 pandas Series，二者的索引必须完全相同；否则按位置对应。

smoothingfloat，默认 0.5

计算占比时，用这个正数替代零计数。

weightsarray_like，可选

每个观测的非负权重，例如其抽样比例的倒数，对应方式与 target 相同。此时计数为权重之和，权重之和为零的组会被排除，因此 woe_transform 会把它们视为未见过的分组。此时 smoothing 以权重为单位：请把权重缩放到总和等于观测数，或按相同比例缩放 smoothing 。

返回值:
pandas.DataFrame

每组一行，包含以下列： non_event 、 event 和 total （计数）， non_event_share 和 event_share （各自类别内平滑后的占比）， total_share （占全部观测的比例）， event_rate 、 woe 和 iv 。将 iv 列求和即得到该变量的信息值。

异常:
ValueError

如果输入不是一维、索引或长度不一致、 target 没有同时包含 0 和 1 或含有缺失值及其他标签，或者 smoothing 不是有限正数。此外，如果 weights 不是数值、没有为每个观测给出一个有限非负的权重、索引与 groups 不同，或使事件或非事件的权重总和为零，也会引发此异常。

参见

woe_transform

将每个分组替换为其 WOE。

woe, iv

根据每组计数计算同样的指标。

kivi.binning.bin_edges

为数值变量拟合分箱边界。

kivi.stability.psi_table

比较两个样本的分布。

说明

对第 \(i\) 组，令 \(p_i\) 和 \(q_i\) 分别为其在全部事件和全部非事件中的占比。则

\[\mathrm{WOE}_i = \ln \frac{p_i}{q_i}, \qquad \mathrm{IV}_i = (p_i - q_i)\,\mathrm{WOE}_i, \qquad \mathrm{IV} = \sum_i \mathrm{IV}_i.\]

在归一化占比之前，每个零计数都会被替换为 smoothing，因此每个 WOE 都是有限值。计数列、 total_share 和 event_rate 始终使用实际观测到的计数。

分类型的分组（例如 kivi.binning.cut 或 pandas.cut 的结果）按类别顺序排列，缺失值排在最后。其他分组按首次出现的次序排列。从未出现的类别不会列出。

参考文献

[1]

N. Siddiqi, "Credit Risk Scorecards: Developing and Implementing Intelligent Credit Scoring", Wiley, 2006.

示例

>>> import pandas as pd
>>> from kivi.woe import woe_table
>>> groups = pd.Series(["a", "a", "a", "b", "b", "b"])
>>> target = pd.Series([1, 1, 0, 1, 0, 0])
>>> woe_table(groups, target)[["event", "non_event", "woe", "iv"]].round(4)
     event  non_event     woe     iv
bin
a        2          1  0.6931  0.231
b        1          2 -0.6931  0.231
kivi.woe.woe_transform(groups, table, *, unseen='raise')#

将每个分组替换为其证据权重（WOE）。

WOE 取自在开发样本上拟合的表，因此评分卡模型在开发、验证和生产环境中看到的是同一套编码。

参数:
groupsarray_like

一维分组标签，划分方式须与传给 woe_table 的分组相同，例如使用同一组边界和 pandas.cut 。

tablepandas.DataFrame 或 pandas.Series

woe_table 的结果，或以分组为索引的 WOE 序列。索引中的缺失标签对应缺失值的 WOE。

unseenfloat 或 "raise"，默认 "raise"

不在 table 中的分组所用的有限 WOE，例如新类别、开发样本中没有观测值的区间，或 table 没有缺失组时的缺失值。默认情况下，这类分组会引发错误。

返回值:
pandas.Series 或 numpy.ndarray

按 groups 顺序排列的浮点 WOE 值。输入为 Series 时返回 Series，索引和名称保持不变。

异常:
ValueError

如果 groups 不是一维、 table 没有 woe 列或有重复的分组、 unseen 既不是 "raise" 也不是有限数值，或者 unseen 为 "raise" 而部分分组不在 table 中。

参见

woe_table

拟合每个分组的 WOE。

kivi.binning.bin_edges

拟合用于划分数值分组的边界。

说明

标签按相等关系匹配，因此 pandas.cut 得到的区间会与 table 中边界相同的区间对应，而数字只与相等的标签对应，绝不会对应包含它的区间。对每个要转换的样本，都请使用在开发样本上拟合的边界。

示例

>>> import pandas as pd
>>> from kivi.woe import woe_table, woe_transform
>>> groups = pd.Series(["a", "a", "a", "b", "b", "b"])
>>> target = pd.Series([1, 1, 0, 1, 0, 0])
>>> table = woe_table(groups, target)
>>> woe_transform(pd.Series(["b", "a", None]), table, unseen=0.0).round(4).tolist()
[-0.6931, 0.6931, 0.0]
kivi.woe.woe(event_counts, non_event_counts, *, smoothing=0.5)#

根据每组的计数计算其证据权重（WOE）。

适用于计数已经汇总的情况，例如来自数据库查询或报表，而不是每个观测一个标签。

参数:
event_counts, non_event_countsarray_like

每组事件和非事件的一维非负计数，两者的分组顺序须一致。两个 Series 的索引必须相同。加权计数不必是整数。

smoothingfloat，默认 0.5

计算占比时，用这个正数替代零计数。

返回值:
pandas.Series 或 numpy.ndarray

每组的 WOE。如果某个计数参数是 Series，结果为具有其索引、名为 woe 的 Series；否则为数组。

异常:
ValueError

如果计数不是一维、不是数值、不是有限非负数，两组计数长度不同或总和为零，或者是索引不同的两个 Series，或者 smoothing 不是有限正数。

参见

iv

同一组计数的信息值。

woe_table

根据分组标签和目标计算计数、占比、WOE 和 IV。

说明

记 \(p_i\) 和 \(q_i\) 为第 \(i\) 组在全部事件和全部非事件中平滑后的占比，则 \(\mathrm{WOE}_i = \ln(p_i / q_i)\) ，与 woe_table 的 woe 列一致。

示例

>>> import pandas as pd
>>> from kivi.woe import woe
>>> woe([2, 1], [1, 2]).round(4)
array([ 0.6931, -0.6931])
>>> event = pd.Series([2, 1], index=["a", "b"])
>>> non_event = pd.Series([1, 2], index=["a", "b"])
>>> woe(event, non_event).round(4)
a    0.6931
b   -0.6931
Name: woe, dtype: float64
kivi.woe.iv(event_counts, non_event_counts, *, smoothing=0.5)#

根据每组的计数计算信息值（IV）。

信息值概括了各组区分事件与非事件的能力，这里直接根据已汇总的计数计算。

参数:
event_counts, non_event_countsarray_like

每组事件和非事件的一维非负计数，两者的分组顺序须一致。两个 Series 的索引必须相同。加权计数不必是整数。

smoothingfloat，默认 0.5

计算占比时，用这个正数替代零计数。

返回值:
float

该变量的信息值。

异常:
ValueError

如果计数不是一维、不是数值、不是有限非负数，两组计数长度不同或总和为零，或者是索引不同的两个 Series，或者 smoothing 不是有限正数。

参见

woe

每组的证据权重。

woe_table

根据标签和目标计算每组的 IV 贡献。

kivi.stability.psi

两个样本之间的同一种散度。

说明

\[\mathrm{IV} = \sum_i (p_i - q_i) \ln \frac{p_i}{q_i},\]

它等于相同分组下 woe_table 中 iv 列之和。

示例

>>> from kivi.woe import iv
>>> round(iv([2, 1], [1, 2]), 4)
0.4621
kivi.woe.woe_trend(table)#

给出数值变量各箱 WOE 的趋势形状。

按表的行顺序读取索引标签为区间的各行的 WOE；对 kivi.binning.cut 或 pandas.cut 得到的箱，这个顺序就是从变量的最小值到最大值。特殊值和缺失值的行在这条刻度上没有位置，不参与判断。

参数:
tablepandas.DataFrame 或 pandas.Series

woe_table 的结果、 kivi.spec.BinningSpec 中的某张表，或以分组为索引的 WOE 值 Series，与 woe_transform 接受的相同。至少需要一行的标签是 pandas.Interval 。

返回值:
str

以下之一：

  • 'increasing' ：WOE 逐箱上升；

  • 'decreasing' ：WOE 逐箱下降；

  • 'u_shaped' ：WOE 先降后升；

  • 'inverted_u' ：WOE 先升后降；

  • 'irregular' ：方向变化不止一次；

  • 'flat' ：所有箱的 WOE 都相同，或者只有一个箱。

异常:
ValueError

如果 table 既不是 woe_table 的结果也不是 Series，没有 woe 列或有重复的分组，没有标签为区间的行（类别变量就没有），或者某个区间行的 WOE 不是有限的数值。

参见

woe_table

每个分组的 WOE。

kivi.binning.monotonic_edges

拟合 WOE 逐箱上升或下降的分箱边界。

kivi.plotting.woe_chart

绘制每个分组的 WOE。

说明

相邻两箱的 WOE 相对差不超过 1e-10 时视为相等。相等的相邻箱既不算上升也不算下降，因此不会打断趋势：WOE 为 0.1、0.1 和 0.3 时趋势为上升。方向的变化是指上升之后出现下降，或下降之后出现上升，中间可以隔着任意多个相等的相邻箱。

趋势由表的行顺序决定，因此在 woe_table 之后重新排序的表（例如用 sort_values("woe") ）得到的是新顺序下的趋势。请先按区间排序；当所有标签都是区间时， table.sort_index() 即可做到。

示例

>>> import pandas as pd
>>> from kivi.woe import woe_table, woe_trend
>>> values = pd.Series([1, 2, 3, 4, 5, 6, 7, 8, 9])
>>> target = pd.Series([1, 0, 0, 0, 0, 0, 1, 1, 0])
>>> table = woe_table(pd.cut(values, [0, 3, 6, 9]), target)
>>> table["woe"].round(3).tolist()
[-0.154, -1.253, 1.232]
>>> woe_trend(table)
'u_shaped'
