群体稳定性指标#

衡量分布在两个样本之间偏移了多少。 psi_table() 和 psi() 给出群体稳定性指标， csi_table() 给出这种偏移使评分卡平均分值发生的变化。

示例和常用阈值见 群体稳定性指标 。

psi_table(reference, current, *[, ...])

通过群体稳定性指标（PSI）比较两个样本的分布。

psi(reference_counts, current_counts, *[, ...])

根据每组的计数计算群体稳定性指标（PSI）。

csi_table(reference, current, points, *[, ...])

衡量变量分布的变化使平均分数移动了多少。
kivi.stability.psi_table(reference, current, *, smoothing=0.5, reference_weights=None, current_weights=None)#

通过群体稳定性指标（PSI）比较两个样本的分布。

比较每组在当前样本中的占比与在基准样本中的占比。将 psi 列求和即得到该指数。

参数:
reference, currentarray_like

类别标签或按相同边界分箱的数值。保留缺失值以及仅出现在一侧的类别。

smoothingfloat，默认 0.5

计算占比时，用这个正数替代零计数。

reference_weights, current_weightsarray_like，可选

基准样本和当前样本中每个观测的非负权重，对应方式与样本相同。此时计数为权重之和，在两个样本中权重之和都为零的组会被排除，且 smoothing 以权重为单位。

返回值:
pandas.DataFrame

各组的原始计数、归一化占比和 PSI 贡献。对 psi 列求和即得到总体 PSI。

异常:
ValueError

如果任一样本为空或不是一维，或者 smoothing 不是有限正数。此外，如果某个权重数组不是数值、没有为对应样本的每个观测给出一个有限非负的权重、权重总和不为正，或其索引与对应样本不同。

参见

psi

根据每组计数计算同一指标。

csi_table

以分组分值为权重衡量每组占比的变化。

kivi.binning.bin_edges

在基准样本上拟合分箱边界。

kivi.woe.woe_table

将分组与二分类目标关联起来。

说明

对第 \(i\) 组，令 \(q_i\) 为其在基准样本中的占比，\(p_i\) 为其在当前样本中的占比，则

\[\mathrm{PSI}_i = (p_i - q_i) \ln \frac{p_i}{q_i}, \qquad \mathrm{PSI} = \sum_i \mathrm{PSI}_i.\]

在归一化占比之前，每个零计数都会被替换为 smoothing，因此只在一个样本中出现的组也有有限的贡献值。 reference 和 current 列始终报告实际观测到的计数。

如果两个样本都是分类型且类别相同，各行按类别顺序排列，缺失值排在最后。否则按分组首次出现的次序排列，先看基准样本，再看当前样本。

参考文献

[1]

N. Siddiqi, "Credit Risk Scorecards: Developing and Implementing Intelligent Credit Scoring", Wiley, 2006.

示例

>>> import pandas as pd
>>> from kivi.stability import psi_table
>>> reference = pd.Series(["x", "x", "y", "y"])
>>> current = pd.Series(["x", "y", "y", "y"])
>>> psi_table(reference, current)[["reference", "current", "psi"]].round(4)
     reference  current     psi
bin
x            2        1  0.1733
y            2        3  0.1014
kivi.stability.psi(reference_counts, current_counts, *, smoothing=0.5)#

根据每组的计数计算群体稳定性指标（PSI）。

适用于样本已经汇总的情况，例如监控报表中按分数段统计的月度计数。

参数:
reference_counts, current_countsarray_like

基准样本和当前样本中每组的一维非负计数，两者的分组顺序须一致。加权计数不必是整数。

smoothingfloat，默认 0.5

计算占比时，用这个正数替代零计数。

返回值:
float

群体稳定性指标。

异常:
ValueError

如果计数不是一维、不是数值、不是有限非负数，两组计数长度不同或总和为零，或者 smoothing 不是有限正数。

参见

psi_table

根据分组标签计算该指标及各组贡献。

kivi.woe.iv

事件与非事件之间的同一种散度。

说明

记 \(q_i\) 和 \(p_i\) 为第 \(i\) 组在基准样本和当前样本中平滑后的占比，则

\[\mathrm{PSI} = \sum_i (p_i - q_i) \ln \frac{p_i}{q_i},\]

它等于相同分组下 psi_table 中 psi 列之和。

示例

>>> from kivi.stability import psi
>>> round(psi([2, 2], [1, 3]), 4)
0.2747
kivi.stability.csi_table(reference, current, points, *, unseen_points=None, reference_weights=None, current_weights=None)#

衡量变量分布的变化使平均分数移动了多少。

特征稳定性指标（CSI）以每组的评分卡分值为权重，衡量各组占比从基准样本到当前样本的变化。将 csi 列求和，即得到该变量平均分值的变化。

参数:
reference, currentarray_like

类别标签或按相同边界分箱的数值，与 psi_table 相同。保留缺失值以及仅出现在一个样本中的分组。

pointspandas.DataFrame、pandas.Series 或 mapping

每个分组的分值。DataFrame 把一个变量的分组放在 bin 列中（没有该列时放在索引中），把分值放在 points 列中，例如 kivi.scorecard.points_table 结果的 table.loc[[variable]] 。Series 或映射按分组给出分值。缺失标签给出缺失值的分值。

unseen_pointsfloat，可选

points 中缺少的已观测分组的分值，例如 kivi.woe.woe_transform 用 unseen 编码的新类别。这些申请人得到的是对该 WOE 调用 kivi.scorecard.woe_to_points 的结果，而不是 WOE 本身；参见“说明”。默认情况下，这样的分组会引发错误。

reference_weights, current_weightsarray_like，可选

基准样本和当前样本中每个观测的非负权重，对应方式与样本相同。此时计数和占比都基于权重之和，在两个样本中权重之和都为零的组会被排除。

返回值:
pandas.DataFrame

每个观测到的分组一行，以 bin 为索引，列出计数 reference 和 current 、占比 reference_share 和 current_share 、该组的 points 及其贡献 csi 。将 csi 列求和即得到该指标。

异常:
ValueError

如果任一样本为空或不是一维的， points 不是 DataFrame、Series 或映射，包含多个变量、重复某个分组或含有不是有限数的值， unseen_points 不是有限数，或者某个观测到的分组没有分值且未给出 unseen_points 。此外，权重数组无效时也会引发错误，与 psi_table 相同。

参见

psi_table

相同分组的群体稳定性指标。

kivi.scorecard.points_table

评分卡每个分组的分值。

kivi.binning.bin_edges

在基准样本上拟合分箱边界。

说明

对分值为 \(s_i\) 的第 \(i\) 组，令 \(q_i\) 为其在基准样本中的占比， \(p_i\) 为其在当前样本中的占比，则

\[\mathrm{CSI}_i = (p_i - q_i)\, s_i, \qquad \mathrm{CSI} = \sum_i \mathrm{CSI}_i = \sum_i p_i s_i - \sum_i q_i s_i,\]

即该变量在当前样本中的平均分值减去在基准样本中的平均分值 [1] 。两个样本的占比之和都为 1，因此给每组的分值加上同一个数不会改变 CSI：起作用的只是各组之间的差别，而不是 kivi.scorecard.points_table 分摊给每个变量的截距和偏移量份额。对评分卡的所有变量，CSI 之和就是平均分数的变化。

与 psi_table 不同，这里的占比不做平滑。贡献中没有对数，因此空组不经平滑也只有有限的贡献；而平滑后的占比会让空组拥有它并没有的申请人，求和结果也就不再是平均分值的变化。

unseen_points 与 points 一样以分值为单位。对 woe_transform(..., unseen=woe) 编码的申请人，它是对包含该 WOE 的单行数据调用 woe_to_points 的结果；WOE 为 0 时得到该变量分摊的截距和偏移量份额，每个变量都相同。如果直接传入 WOE 本身，会在没有任何报错的情况下得到错误的 CSI。

有些文献也把单个变量的 PSI 称为它的 CSI，那就是对该变量的分组调用 psi_table 的结果。各行顺序与 psi_table 相同； points 中在两个样本里都没有出现的分组不计入，因为它们没有贡献。

参考文献

[1]

N. Siddiqi, "Credit Risk Scorecards: Developing and Implementing Intelligent Credit Scoring", Wiley, 2006.

示例

>>> import pandas as pd
>>> from kivi.stability import csi_table
>>> reference = pd.Series(["x", "x", "y", "y"])
>>> current = pd.Series(["x", "y", "y", "y"])
>>> csi_table(reference, current, {"x": 40.0, "y": 25.0})
     reference  current  reference_share  current_share  points    csi
bin
x            2        1              0.5           0.25    40.0 -10.00
y            2        3              0.5           0.75    25.0   6.25

平均分值从 32.5 降到 28.75，降幅即 csi 列之和 -3.75。
