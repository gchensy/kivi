单变量概况#

用一行概括数据框的每一列：完整程度、取值分布，以及在给出二元目标变量时区分事件与非事件的能力。 profile_table() 是对模型候选变量的第一次全面审视。

示例以及如何解读概况表，见 单变量概况 。

profile_table(frame[, target, columns, ...])

用一行概括数据框的每一列。
kivi.univariate.profile_table(frame, target=None, *, columns=None, bins=5, special=None, weights=None)#

用一行概括数据框的每一列。

每一列都会给出其类型、缺失值个数和最常见的取值；数值列还给出取值范围、分位数、均值、标准差和分布形态。有二分类目标时，每一列还会给出缺失行与非缺失行的事件率，以及快速分箱的信息值和卡方检验；数值列还给出其取值的 Gini 系数和 KS 统计量。

参数:
framepandas.DataFrame

每个变量一列。数值 dtype（bool 除外）的列是数值列；其他所有列（例如 object、string、category 或 bool）是类别列，与 kivi.spec.fit_spec 相同。

targetarray_like，可选

二分类标签，1 表示事件， frame 的每一行一个。两类都必须出现。Series 必须与 frame 的索引相同；其他输入按位置对应。没有 target 时，表格只描述各列。

columnsstr 序列，可选

要分析的列，其顺序即结果中行的顺序。默认为 frame 的所有列。

binsint，默认 5

数值列快速分箱的等频箱数，用于 kivi.binning.bin_edges ，结果见 iv 列。

specialdict，可选

数值列的特殊值编码，例如 {"pdays": [-1]} ，与 kivi.spec.fit_spec 相同。它们算作取值而不算缺失，但不参与数值汇总和 Gini 系数，并在快速分箱中各自成组。

weightsarray_like，可选

每一行的非负频数权重，例如其抽样比例的倒数，对应方式与 target 相同。计数变为权重之和，每项统计量都加权计算，因此整数权重与重复相应行并使用单位权重的结果相同。权重为零的行不计入，因此也不检查其取值。卡方检验把它们当作频数权重：权重为 \(w\) 的行算作 \(w\) 个观测。

返回值:
pandas.DataFrame

每列一行，以列名为索引，索引名为 variable 。各列含义见“说明”。

异常:
ValueError

如果 frame 不是 DataFrame、没有行或没有列， columns 重复某一列或指定了 frame 中没有的列，列名不是字符串，或 bins 不是正整数。如果 target 的标签不是每行一个 0 或 1、缺少两类中的一类或是被分析的列之一，或者 weights 无效或使某一类没有权重。此外，如果 special 不是按列的 dict、指定了未分析的列或类别列、含有不是数值的编码，或某个数值列含有不属于特殊值的无穷值，也会引发此异常。

参见

kivi.spec.fit_spec

对分析后选出的列进行分箱和编码。

kivi.woe.woe_table

单个已分组列的 WOE 和 IV。

kivi.metrics.gini

评分的 Gini 系数。

kivi.metrics.ks

评分的 KS 统计量。

kivi.binning.bin_edges

快速分箱的分位数边界。

说明

每一列都包含

  • kind ： "numeric" 或 "categorical" ；

  • count 和 missing ：有取值和无取值的行数； missing_share ：无取值的行所占的比例；

  • distinct ：不同取值的个数；

  • top 和 top_share ：最常见的取值及其在有取值的行中所占的比例。若多个取值同样常见，显示类别顺序中的第一个，没有类别顺序时显示最先出现的一个；

  • special 和 special_share ：取特殊值编码的行数及其比例，类别列为 0；

  • mean 、 std 、 min 、 q01 、 q50 、 q99 和 max ：数值列去除缺失值和特殊值编码后的均值、样本标准差、最小值、1%、50% 和 99% 分位数以及最大值。类别列为 NaN。

分位数按线性插值计算，与 numpy.quantile 相同；使用 weights 时，取逆累积分布（inverted CDF）意义下的加权分位数，与 kivi.binning.bin_edges 的边界相同。因此权重（即使全为 1）会改变分位数，并通过边界改变 iv 、 chi2_p_value 和 tied_bins ；使用整数权重时，其他各列都等于不加权的重复行的结果。标准差除以总权重减 1，正如不加权时除以行数减 1，因此当某列取值的权重之和不超过 1 时，标准差为 NaN。

有 target 时，每一列还包含

  • event_rate ：全部行的事件率，在表格的每一行中都相同；

  • missing_event_rate 和 non_missing_event_rate ：无取值和有取值的行的事件率，没有这样的行时为 NaN；

  • missing_lift 和 non_missing_lift ：上述事件率除以 event_rate ，提升度大于 1 表示这些行风险更高；

  • iv ：该列的信息值，即 kivi.woe.woe_table 各分组之和。数值列用 kivi.binning.bin_edges 和 kivi.binning.cut 切分为 bins 个等频箱，每个特殊值编码单独成组；类别列保留其标签。缺失值单独成组；

  • tied_bins ：数值列的快速分箱箱数少于所请求的箱数时为 True，原因是分位数重合而被合并，或者除缺失值和特殊值编码外没有可分箱的取值。表格记录这一情况，而不像 kivi.binning.bin_edges 那样对每一列发出警告；在用自定义边界或特殊值编码分箱之前，这样的 IV 会低估该列；

  • gini ：把数值列的取值作为评分时的 Gini 系数，不含缺失值和特殊值编码。事件的取值较高时为正，较低时为负；对类别列，或这些取值缺少某一类时，为 NaN。

在这些列之后（没有 target 时在 max 之后），每一列还给出描述分布形态的三个统计量，与汇总统计使用相同的取值，不含缺失值和特殊值编码。分类列为 NaN。

  • skewness ：偏差校正后的样本偏度 \(G_1\) ，与 pandas.Series.skew 的计算相同；

  • kurtosis ：偏差校正后的样本超额峰度 \(G_2\) ，与 pandas.Series.kurt 的计算相同，正态分布为 0；

  • cv ：变异系数 std / mean ，符号与均值相同，均值为 0 时为 NaN。

设有 \(n\) 个取值 \(x_i\) ，其均值为 \(\bar x\) ，并记 \(M_k = \sum_i (x_i - \bar x)^k\) ，则

\[G_1 = \frac{n \sqrt{n - 1}}{n - 2} \frac{M_3}{M_2^{3/2}}, \qquad G_2 = \frac{n (n + 1) (n - 1)}{(n - 2)(n - 3)} \frac{M_4}{M_2^2} - \frac{3 (n - 1)^2}{(n - 2)(n - 3)}.\]

取值不超过 2 个时 \(G_1\) 为 NaN，不超过 3 个时 \(G_2\) 为 NaN；所有取值都相等时两者均为 NaN。使用 weights 时， \(n\) 为总权重，每个求和都加权计算，因此整数权重与重复相应行相同，总权重须分别大于 2 和 3。

有 target 时，其后还有

  • ks ：同一组取值的 KS 统计量，即事件取值的累计分布与非事件取值的累计分布之间的最大差距，无论取值方向如何都在 0 到 1 之间，定义与 kivi.metrics.ks 相同。 gini 为 NaN 时它也为 NaN；

  • chi2_p_value ：目标与给出 iv 的快速分箱各组之间卡方独立性检验的 p 值，包含缺失值组和特殊值编码组。记 \(O\) 为 \(k\) 个组中每组事件和非事件的计数， \(E\) 为各组事件率相同时的期望计数，则统计量 \(\sum (O - E)^2 / E\) 与自由度为 \(k - 1\) 的卡方分布比较。只有一个组时 p 值为 1。

快速分箱只给出初步排序而非最终排序：五个等频箱的 IV 可能遗漏其他边界才能显示的规律，而含有许多稀有标签的类别列，IV 会被高估。卡方检验只回答各组的事件率是否不同：样本有数千行时，即使关系很弱，p 值也接近 0，因此请按 iv 排序，并把较大的 p 值理解为没有证据表明该列与目标有关。来自抽样比例的权重会放大观测数，使 p 值偏小。

示例

>>> import pandas as pd
>>> from kivi.univariate import profile_table
>>> frame = pd.DataFrame({
...     "age": [23, 31, None, 52, 38, 27, 61, 49],
...     "housing": ["yes", "no", "yes", "no", "no", "yes", None, "yes"],
... })
>>> profile = profile_table(frame)
>>> profile[["kind", "count", "missing", "distinct", "top", "top_share"]]
                 kind  count  missing  distinct  top  top_share
variable
age           numeric      7        1         7  23.0   0.142857
housing   categorical      7        1         2  yes   0.571429
>>> profile.loc["age", ["min", "q50", "max"]].tolist()
[23.0, 38.0, 61.0]
>>> profile.loc["age", ["skewness", "kurtosis", "cv"]].round(4).tolist()
[0.2736, -1.51, 0.3536]

有目标变量时，给出各列的事件率和区分能力：

>>> target = pd.Series([1, 0, 1, 0, 1, 1, 0, 0])
>>> profile = profile_table(frame, target, bins=2)
>>> profile[["missing_event_rate", "non_missing_event_rate", "iv", "gini"]].round(4)
          missing_event_rate  non_missing_event_rate      iv    gini
variable
age                      1.0                  0.4286  1.5607 -0.8333
housing                  0.0                  0.5714  0.7466     NaN
>>> profile[["ks", "chi2_p_value"]].round(4)
            ks  chi2_p_value
variable
age       0.75        0.0821
housing    NaN        0.3114
