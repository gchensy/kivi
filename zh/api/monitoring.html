模型监控#

按期跟踪评分及其变量。 monitoring_table() 给出评分在每一期的样本量、事件、区分能力和 PSI， stability_table() 给出每个已分组变量的 PSI。

基于合成申请数据的示例见 模型监控 。

monitoring_table(score, period[, target, ...])

监控评分的样本量、事件率、区分能力和稳定性。

stability_table(groups, period, *[, ...])

按期监控已分组变量的群体稳定性。
kivi.monitoring.monitoring_table(score, period, target=None, *, reference_period=None, reference_score=None, bins=10, smoothing=0.5, weights=None, reference_weights=None)#

监控评分的样本量、事件率、区分能力和稳定性。

每行汇总一期，例如一个月或一个季度：该期有多少观测、结果已知的观测中有多少事件、评分区分两类结果的能力如何，以及评分分布相对基准样本偏移了多少。

参数:
scorearray_like

有限的数值评分，事件概率越高，评分越高，例如 PD。评分卡分数越高表示风险越低，因此须取负后再传入。

periodarray_like

每个观测所属的期，例如申请月份，不能有缺失值。各期按升序排列，分类型的期按类别顺序排列。如果 score 和 period 都是 pandas Series，二者的索引必须完全相同；否则按位置对应。

targetarray_like，可选

二元标签，1 表示事件；结果尚未得知时为缺失值，例如尚未走完表现期的贷款，对应方式与 period 相同。不给出 target 时，所有结果都视为未知，表中只有 total 和 psi 两列。

reference_periodobject，可选

每一期都与之比较的那一期的标签，例如开发样本之后的第一个月。对于日期时间型的期和 pandas 的 Period，恰好指向其中一期的字符串（例如月份 "2024-01" ）会选中该期。 reference_period 和 reference_score 二者给出其一。

reference_scorearray_like，可选

每一期都与之比较的基准样本的评分，例如开发样本，索引不限。应传入基准行的评分，例如 score[mask] ，而不是布尔掩码；布尔掩码会被拒绝。

binsint 或 array_like，默认 10

基准评分的分位数评分段个数，或递增的评分段边界。整数等同于对基准评分传入 kivi.binning.bin_edges(reference, bins=bins) ，并以其权重作为 weights ，因此并列的评分可能使评分段少于请求的数量。每一期都在同一组评分段上比较。

smoothingfloat，默认 0.5

计算 PSI 时用这个正数替代零计数，含义与 kivi.stability.psi_table 相同；给出 weights 时以权重为单位。

weightsarray_like，可选

每个观测的非负权重，例如其抽样比例的倒数，对应方式与 period 相同。计数变为权重之和，区分能力和 PSI 也按权重计算。在相同的评分段边界上，整数权重与重复相应行得到的表相同。

reference_weightsarray_like，可选

reference_score 中每个评分的非负权重，对应方式与它相同。基准期的权重取自 weights 。

返回值:
pandas.DataFrame

每期一行，索引名为 period ，各列含义见“说明”。

异常:
ValueError

如果 score 或 period 为空，某个输入不是一维的，输入长度不同或是索引不同的 Series， score 不是实数型数值或含有缺失值或无穷值， target 含有 0、1 和缺失值以外的值，或 period 含有缺失值。此外，如果 reference_period 和 reference_score 都没有给出或同时给出， reference_period 不是有观测的某一期， reference_score 为空、为布尔型或不是有限数值，给出 reference_period 的同时给出了 reference_weights ， bins 既不是正整数也不是递增边界，某个评分落在边界之外， smoothing 不是有限正数，或者某个权重数组不是数值型、没有为每个观测给出一个有限非负且总和为正的权重，或其索引与对应样本的索引不同。

警告:
UserWarning

如果 bins 是整数，且并列的基准评分使评分段少于请求的数量，与 kivi.binning.bin_edges 相同。

参见

stability_table

评分各变量在每一期的 PSI。

kivi.metrics.roc_auc

单个样本的 AUC。

kivi.stability.psi_table

单个样本的 PSI 及各组贡献。

说明

各列为：

  • total ：该期的观测数或其权重之和，包括结果尚未得知的观测；

  • known ：结果已知的观测数；

  • event ：其中的事件数；

  • event_rate ： event 除以 known ，没有已知结果时为 NaN；

  • auc 、 gini 和 ks ：该期已知结果的 kivi.metrics.roc_auc 、 kivi.metrics.gini 和 kivi.metrics.ks ，两类结果不全时为 NaN；

  • psi ：该期评分相对基准评分的群体稳定性指标，基于 bins 所描述的评分段。

没有目标变量时，表中只有 total 和 psi 两列。每一行都等于仅对该期计算时指标函数和 psi_table(pandas.cut(reference, edges), pandas.cut(period_score, edges)) 的结果，两个样本的权重分别作为 reference_weights 和 current_weights 传入。记 \(q_i\) 和 \(p_i\) 为评分段 \(i\) 在基准评分和该期评分中平滑后的占比，则

\[\mathrm{PSI} = \sum_i (p_i - q_i) \ln \frac{p_i}{q_i},\]

其中两个样本中都为空的评分段不计入。基准期的 PSI 为 0。

分类型 period 中没有观测或权重之和为零的类别仍保留一行，计数为零，其他列为 NaN，以便不同样本的监控表能够对齐。这一规则与 kivi.vintage.vintage_table 和 kivi.calibration.calibration_table 不同，后两者会略去这样的类别。其他类型的期只由其观测产生，权重之和为零的期会被排除，与重复相应行时一样。

最近几期的区分能力通常只基于很少的已知结果，而小样本期的 PSI 主要反映抽样噪声，因此应结合 known 和 total 一起解读。

示例

>>> import numpy as np
>>> from kivi.monitoring import monitoring_table
>>> score = [0.1, 0.2, 0.3, 0.4, 0.2, 0.3, 0.6, 0.7, 0.5, 0.6, 0.8, 0.9]
>>> target = [0, 0, 1, 1, 0, 1, 0, 1, 0, np.nan, 1, np.nan]
>>> period = ["2024-01"] * 4 + ["2024-02"] * 4 + ["2024-03"] * 4
>>> table = monitoring_table(score, period, target, reference_period="2024-01", bins=2)
>>> table[["total", "known", "event", "event_rate"]]
         total  known  event  event_rate
period
2024-01      4      4      2         0.5
2024-02      4      4      2         0.5
2024-03      4      2      1         0.5
>>> table[["auc", "gini", "ks", "psi"]].round(4)
          auc  gini   ks     psi
period
2024-01  1.00   1.0  1.0  0.0000
2024-02  0.75   0.5  0.5  0.2747
2024-03  1.00   1.0  1.0  0.8087

3 月有两个观测的结果尚未得知，因此其区分能力只基于另外两个。

kivi.monitoring.stability_table(groups, period, *, reference_period=None, reference_groups=None, smoothing=0.5, weights=None, reference_weights=None)#

按期监控已分组变量的群体稳定性。

每个值是某个变量在某一期相对基准样本的 PSI，与 kivi.stability.psi_table 仅对该期计算的结果相同。对评分卡各变量的分组而言，这就是稳定性报告中的变量部分，发生变化的变量可以解释 monitoring_table 所显示的评分偏移。

参数:
groupspandas.DataFrame

每个变量一列，存放标签或在每一期都使用相同边界分箱后的值，例如 kivi.spec.BinningSpec.cut 的结果。缺失值单独成组，只在一个样本中出现的组也会包含在内。

periodarray_like

groups 每一行所属的期，不能有缺失值。各期按升序排列，分类型的期按类别顺序排列。Series 的索引必须与 groups 相同。

reference_periodobject，可选

每一期都与之比较的那一期的标签，与 monitoring_table 相同。 reference_period 和 reference_groups 二者给出其一。

reference_groupspandas.DataFrame，可选

每一期都与之比较的基准样本（例如开发样本）的分组，须包含 groups 的每一列，索引不限。其他列会被忽略。

smoothingfloat，默认 0.5

计算占比时用这个正数替代零计数；给出 weights 时以权重为单位。

weightsarray_like，可选

groups 每一行的非负权重，对应方式与 period 相同。计数变为权重之和，因此整数权重与重复相应行得到的表相同。

reference_weightsarray_like，可选

reference_groups 每一行的非负权重。基准期的权重取自 weights 。

返回值:
pandas.DataFrame

每期一行，索引名为 period ；每个变量一列，列与 groups 的列相同，列索引名为 variable 。每个值是该变量在该期的 PSI。

异常:
ValueError

如果 groups 不是 DataFrame，没有行、没有列、列名重复或列名不止一层， period 不是一维的、不是每行一个值或含有缺失值，或某个 Series 参数的索引与 groups 的索引不同。此外，如果 reference_period 和 reference_groups 都没有给出或同时给出， reference_period 不是有观测的某一期， reference_groups 不是有行、列名唯一且包含 groups 每一列的 DataFrame，给出 reference_period 的同时给出了 reference_weights ， smoothing 不是有限正数，或者某个权重数组不是数值型、没有为每一行给出一个有限非负且总和为正的权重，或其索引与对应样本的索引不同。

参见

monitoring_table

评分的样本量、区分能力和 PSI。

kivi.stability.psi_table

单个样本的 PSI 及各组贡献。

kivi.stability.csi_table

变量平均分值的变化。

说明

对变量的第 \(i\) 组，记 \(q_i\) 和 \(p_i\) 为其在基准样本和该期中平滑后的占比，则

\[\mathrm{PSI} = \sum_i (p_i - q_i) \ln \frac{p_i}{q_i},\]

求和范围为在基准样本或该期中出现的组。基准期的 PSI 为 0。

分类型 period 中没有观测或权重之和为零的类别仍保留一行，其值为 NaN，与 monitoring_table 相同。其他类型的期只由其行产生，权重之和为零的期会被排除，与重复相应行时一样。

示例

>>> import pandas as pd
>>> from kivi.monitoring import stability_table
>>> groups = pd.DataFrame({
...     "housing": ["own", "own", "rent", "rent", "own", "rent", "rent", "rent"],
...     "region": ["north", "south", "north", "south", "north", "north", "south", None],
... })
>>> period = ["2024-01"] * 4 + ["2024-02"] * 4
>>> stability_table(groups, period, reference_period="2024-01").round(4)
variable  housing  region
period
2024-01    0.0000   0.000
2024-02    0.2747   0.231

2 月有一个 region 值缺失，这是 1 月没有的一组。
