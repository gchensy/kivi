存续期 PD 与预期信用损失#

把 PD 期限结构转化为 IFRS 9 的预期信用损失和阶段。 convert_pd() 在累计、边际和条件 PD 之间转换期限结构， transition_pd() 由转移矩阵推算期限结构， conditional_matrix() 把转移矩阵移到某个情景下的经济状况， matrix_factor() 和 matrix_correlation() 由观察到的迁移估计其因子和相关系数， survival_table() 由存在删失、提前还款或只从某一账龄起才被观测到的贷款估计期限结构， expected_credit_loss() 给出每个账户的 12 个月预期信用损失和整个存续期预期信用损失， significant_increase() 、 assign_stages() 和 stage_table() 划分阶段并汇总每个阶段的损失准备。

基于随包数据的示例见 存续期 PD 与预期信用损失 。

kivi.lifetime.convert_pd(probability, *, kind, to)#

在累计、边际和条件 PD 之间转换 PD 期限结构。

期限结构给出从某个起点（例如贷款发放）开始每一期的违约概率。第 \(k\) 期的累计 PD 是在第 1 期到第 \(k\) 期之间违约的概率，边际 PD 是在第 \(k\) 期违约的概率，条件 PD（又称风险率，hazard rate）是此前未违约的前提下在第 \(k\) 期违约的概率。

参数:
probabilityarray_like 或 pandas.DataFrame

取值在 0 到 1 之间的 PD：一条曲线（一维），或每行一条曲线（二维），例如 kivi.vintage.vintage_table 给出的累计坏账率，每个批次一行、每个账龄一列。各期就是曲线上的位置：第一个位置是第 1 期。缺失值表示没有观测到的期，例如批次尚未达到的账龄。布尔值按 0 和 1 计。

kind{"cumulative", "marginal", "conditional"}

probability 中 PD 的种类。

to{"cumulative", "marginal", "conditional"}

要返回的 PD 种类。

返回值:
pandas.DataFrame、pandas.Series 或 numpy.ndarray

种类为 to 的 PD，形状与 probability 相同，并保留其索引、列和名称。缺失值保持缺失，依赖于它们的 PD 也为缺失，详见“说明”。

异常:
ValueError

如果 kind 或 to 不是这三种之一， probability 不是实数数值、不是一维或二维、没有任何一期，或有取值超出 [0, 1]。此外，如果累计 PD 沿曲线下降，或一条曲线的边际 PD 之和超过 1，也会引发此异常。

参见

transition_pd

由转移矩阵得到的累计 PD。

expected_credit_loss

由边际 PD 计算的预期信用损失。

kivi.vintage.vintage_table

按批次和账龄统计的累计坏账率。

说明

设第 \(k = 1, 2, \ldots\) 期的累计 PD 为 \(C_k\) 、边际 PD 为 \(m_k\) 、条件 PD 为 \(h_k\) ，并令 \(C_0 = 0\) ，则

\[m_k = C_k - C_{k-1}, \qquad h_k = \frac{C_k - C_{k-1}}{1 - C_{k-1}}, \qquad C_k = \sum_{j \le k} m_j = 1 - \prod_{j \le k} (1 - h_j).\]

在舍入误差范围内，这些转换互为逆运算。各期的标签不参与计算：从账龄 1 开始的 vintage 表各列给出月度 PD，按季度快照的各列给出相邻快照之间各季度的 PD。

缺失值不会被填补。某一期的边际 PD 和条件 PD 需要该期期末和上一期期末的累计 PD，某一期的累计 PD 则需要截至该期每一期的边际或条件 PD。因此，批次尚未达到的账龄在每一种 PD 中都保持缺失，往返转换之后也是如此。曲线开头的缺失值（面板晚于放款开始时， kivi.vintage.vintage_table 会给出这样的缺失值）不影响从第二个观测期起的边际和条件 PD，但由它们无法再转换回累计 PD，因为面板开始之前的累计 PD 未知。

一条曲线的累计 PD 达到 1 之后，已没有敞口可以违约，此后各期的条件 PD 为 0 / 0，取为 0，以保证这些转换仍互为逆运算。

kivi.vintage.vintage_table 的累计坏账率计入批次中的每一笔贷款，也包括提前还清、不会再违约的贷款。因此它的边际 PD 已经考虑了提前还款，它的条件 PD 是以未违约为条件，而不是以贷款仍在账上为条件。

示例

>>> from kivi.lifetime import convert_pd
>>> cumulative = [0.02, 0.05, 0.08]
>>> convert_pd(cumulative, kind="cumulative", to="marginal")
array([0.02, 0.03, 0.03])
>>> conditional = convert_pd(cumulative, kind="cumulative", to="conditional")
>>> conditional.round(4)
array([0.02  , 0.0306, 0.0316])
>>> convert_pd(conditional, kind="conditional", to="cumulative")
array([0.02, 0.05, 0.08])

Vintage 表每个批次一条曲线，批次尚未达到的账龄保持缺失：

>>> from kivi.vintage import vintage_table
>>> loan = [1, 1, 1, 2, 2, 2, 3, 3, 4, 4]
>>> cohort = ["2024-01"] * 6 + ["2024-02"] * 4
>>> month_on_book = [1, 2, 3, 1, 2, 3, 1, 2, 1, 2]
>>> bad = [0, 1, 1, 0, 0, 0, 1, 1, 0, 0]
>>> table = vintage_table(loan, cohort, month_on_book, bad)
>>> convert_pd(table, kind="cumulative", to="conditional")
month_on_book    1    2    3
cohort
2024-01        0.0  0.5  0.0
2024-02        0.5  0.0  NaN
kivi.lifetime.transition_pd(matrix, *, horizons, default_state=None)#

由转移矩阵推算每个状态的累计 PD。

转移矩阵的第 \(i\) 行给出一期内从状态 \(i\) （例如某个评级或逾期档位）迁移到各个状态的概率。如果迁移服从时齐马尔可夫链，矩阵的 \(h\) 次幂给出 \(h\) 期内的迁移概率，其违约列就是每个起始状态的累计 PD。

参数:
matrixarray_like 或 pandas.DataFrame

一期（例如一年或一个月）内各状态之间迁移概率的方阵，例如 kivi.vintage.transition_matrix 在 normalize=True 时的结果。每一行是取值在 0 到 1 之间、和为 1 的概率，但违约状态所在的行不会被使用。DataFrame 的状态是其索引，必须与列相同；数组的状态是位置 0、1，依此类推。

horizonsint 或 array_like

报告累计 PD 的期数：正整数 \(n\) 表示从 1 到 \(n\) 的每一个期限，也可以是递增的正整数序列，例如 [12, 24, 36] 。

default_state可选

违约状态的标签。默认取最后一个状态；状态按从最好到最差排列时（如 kivi.vintage.transition_matrix ），它就是最差的状态。

返回值:
pandas.DataFrame

累计 PD，每个起始状态一行（索引名为 state ；状态有多个层级时，索引为 matrix 索引的各层级），每个期限一列（列名为 horizon ）。违约状态所在的行为 1。

异常:
ValueError

如果 matrix 不是由实数构成的二维方阵，DataFrame 的索引与列不同或有重复， default_state 不是其中的状态，或者其他状态所在的行含有缺失值、有取值超出 [0, 1] 或之和不为 1。此外，如果 horizons 不是正整数，也不是递增的正整数序列，也会引发此异常。

参见

kivi.vintage.transition_matrix

由观测到的迁移得到的转移矩阵。

convert_pd

由累计 PD 得到的边际 PD 和条件 PD。

expected_credit_loss

由边际 PD 计算的预期信用损失。

说明

违约状态被设为吸收态：它所在的行被替换为以概率 1 停留在违约状态的行。因此，数据中从违约状态回到正常的敞口仍算作违约，与 kivi.vintage.vintage_table 的“曾经为坏”比例一致。对于这个矩阵 \(P\) 和违约状态 \(d\) ，状态 \(i\) 在期限 \(h\) 的累计 PD 为

\[\mathrm{PD}_i(h) = (P^h)_{id}.\]

它不随期限下降，也不会超过 1。由于 \(P^{a+b} = P^a P^b\) ， \(a + b\) 期的 PD 等于 \(a\) 期后所到达各状态的 \(b\) 期 PD，以到达这些状态的概率加权。

这一推算假设各状态之间的迁移概率每一期都相同，且与敞口在当前状态或在账上停留的时间无关。用一年数据估计的矩阵给出年度 PD，月度矩阵给出月度 PD。每行之和与 1 的差不得超过 1e-9；经过舍入的公开矩阵，请先把每行除以该行之和。

示例

>>> import pandas as pd
>>> from kivi.lifetime import transition_pd
>>> states = ["A", "B", "D"]
>>> matrix = pd.DataFrame(
...     [[0.90, 0.08, 0.02], [0.10, 0.70, 0.20], [0.00, 0.00, 1.00]],
...     index=states,
...     columns=states,
... )
>>> transition_pd(matrix, horizons=3)
horizon     1      2        3
state
A        0.02  0.054  0.09596
B        0.20  0.342  0.44480
D        1.00  1.000  1.00000

两期之后，状态 A 违约的概率为 0.90 × 0.02 + 0.08 × 0.20 + 0.02 = 0.054。

kivi.lifetime.conditional_matrix(matrix, *, correlation, factor, default_state=None)#

在单因子模型中把转移矩阵移到给定的经济状况。

在 Belkin、Suchower 和 Forest（1998）的单参数表示中，从每个状态出发的迁移服从一个标准正态的信用指数，按再现长期矩阵该行的阈值分箱，与 CreditMetrics 相同。所有借款人的信用指数共享一个系统因子，因此给定因子时整个矩阵一起平移：经济好时违约和降级更少、升级更多，经济差时相反。其违约列就是 kivi.capital.conditional_pd 的条件 PD。

参数:
matrixarray_like 或 pandas.DataFrame

一期内各状态之间长期迁移概率的方阵，与 transition_pd 的要求相同，状态按信用质量从最好到最差排列。每一行是取值在 0 到 1 之间、和为 1 的概率，但违约状态所在的行不会被使用。DataFrame 的状态是其索引，必须与列相同；数组的状态是位置 0、1，依此类推。

correlationfloat

单因子模型的资产相关系数 \(\rho\) ，取值从 0 到小于 1。

factorfloat

该期标准正态系统因子的取值 \(z\) ，必须有限；正值表示经济好于平均。

default_state可选

违约状态的标签；无论位于何处，它都是最差的状态。默认为最后一个状态。

返回值:
pandas.DataFrame

给定因子时的矩阵，索引和列与 matrix 相同，数组则为位置。每一行之和为 1，违约状态所在的行以概率 1 停留在违约状态。

异常:
ValueError

如果 matrix 或 default_state 无效（与 transition_pd 相同）， correlation 不是从 0 到小于 1 的实数，或 factor 不是有限的实数。

参见

matrix_factor

由一期的迁移估计该期的因子。

matrix_correlation

由多期的迁移估计相关系数。

transition_pd

由转移矩阵的各次幂得到的累计 PD。

kivi.capital.conditional_pd

条件 PD，即结果的违约列。

说明

设状态从最好到最差排列、违约状态在最后，记 \(C_{ij}\) 为从状态 \(i\) 迁移到状态 \(j\) 或更差状态的长期概率。状态 \(i\) 的借款人的信用指数 \(X = \sqrt{\rho}\,Z + \sqrt{1 - \rho}\,Y\) 低于 \(b_{ij} = \Phi^{-1}(C_{ij})\) 时，落入状态 \(j\) 或更差的状态；给定 \(Z = z\) 时

\[C_{ij}(z) = \Phi\!\left(\frac{b_{ij} - \sqrt{\rho}\,z}{\sqrt{1 - \rho}}\right).\]

结果的每个元素是相邻两个 \(C_{ij}(z)\) 之差，由较小的尾部计算，因此 0 和 1 保持精确，很小的元素保持其相对精度。

因子为 0 给出中位数经济下的矩阵，而不是 matrix ：对标准正态因子取平均时，一期的结果才是 matrix 。每期一个、相互独立的因子构成的路径同样如此，其乘积的平均是 matrix 的幂；但同一个因子保持多期时并非如此，其乘积的平均与幂不同：只有两个状态时 PD 更低，状态更多时可能有的状态更高、有的状态更低。因子和相关系数属于 matrix 的期间，例如一个月或一年。

阈值的做法依据 CreditMetrics 技术文档（Gupton、Finger 和 Bhatia，1997，第 8.4 节），条件矩阵依据 Witzany（2020，式 10）。在信用质量的顺序中没有位置的退出，例如提前还款，必须先去掉，并把各行除以行和，这样得到的是不退出的贷款的迁移。

示例

>>> import pandas as pd
>>> from kivi.lifetime import conditional_matrix, transition_pd
>>> states = ["A", "B", "D"]
>>> matrix = pd.DataFrame(
...     [[0.90, 0.08, 0.02], [0.10, 0.70, 0.20], [0.00, 0.00, 1.00]],
...     index=states,
...     columns=states,
... )
>>> shifted = conditional_matrix(matrix, correlation=0.1, factor=-1.0)
>>> shifted.round(4)
        A       B       D
A  0.8456  0.1209  0.0335
B  0.0461  0.6641  0.2899
D  0.0000  0.0000  1.0000

因子比中位数低一个标准差时，状态 A 违约的概率是 0.0335 而不是 0.02，即 conditional_pd(0.02, correlation=0.1, factor=-1.0) ，并且更常迁移到 B，而 B 回到 A 的次数更少。这个因子保持三期时，累计 PD 为：

>>> transition_pd(shifted, horizons=3).round(4)
horizon       1       2       3
state
A        0.0335  0.0969  0.1740
B        0.2899  0.4839  0.6157
D        1.0000  1.0000  1.0000
kivi.lifetime.matrix_factor(counts, matrix, *, correlation, default_state=None)#

由一期在各状态之间的迁移估计该期的系统因子。

因子是使 conditional_matrix 最能解释该期迁移的取值：每个状态迁移所服从的多项分布的极大似然估计。负的因子表示该期比平均差，违约和降级多于 matrix 给出的水平。

参数:
countsarray_like 或 pandas.DataFrame

该期在各状态之间迁移的对象数的方阵，例如不带 normalize 的 kivi.vintage.transition_matrix ，或频数权重之和。若 matrix 是 DataFrame，则 DataFrame 必须具有 matrix 的索引和列；数组按位置对应。计数必须非负且有限，但违约状态所在的行不会被使用。

matrixarray_like 或 pandas.DataFrame

长期转移矩阵，与 conditional_matrix 的要求相同，状态从最好到最差排列。

correlationfloat

单因子模型的资产相关系数，严格介于 0 与 1 之间。

default_state可选

违约状态的标签，与 conditional_matrix 相同。

返回值:
float

估计的因子。

异常:
ValueError

如果 matrix 、 correlation 或 default_state 无效（与 conditional_matrix 相同），或 correlation 为 0；如果 counts 与 matrix 不匹配，在违约状态所在的行以外有负的、缺失的或无穷的计数，或者没有任何来自可以迁移到多个状态的状态的迁移；如果有对象迁移到 matrix 给出概率为 0 的格子；或者因子不是有限值，因为所有迁移都去往各自状态能到达的最好状态，或都去往最差状态。

参见

conditional_matrix

给定因子时的转移矩阵。

matrix_correlation

使多期的因子像 Z 一样变化的相关系数。

kivi.capital.systematic_factor

违约率所对应的因子。

说明

设有 \(n_{ij}\) 个对象从状态 \(i\) 迁移到状态 \(j\) ， \(p_{ij}(z)\) 是 conditional_matrix 的概率，因子使下式最大：

\[\ell(z) = \sum_{i \ne d} \sum_j n_{ij} \log p_{ij}(z)\]

其中 \(i\) 取违约状态 \(d\) 以外的状态。由于正态密度是对数凹的，每一项都是 \(z\) 的凹函数，因此最大点唯一；它通过对导数二分求得。计数乘以同一个常数得到相同的因子；只有两个状态时，因子等于 kivi.capital.systematic_factor 对该违约率给出的因子。

Belkin、Suchower 和 Forest（1998）则最小化观察概率与条件概率之差的平方（据 Shao、Li 和 Li 2018 年式 1.5 的转述），每项的权重是该状态的对象数除以二项方差 \(p_{ij}(z)(1 - p_{ij}(z))\) 。对于罕见的迁移，这个权重没有上界：最好状态的一个对象迁移到概率为 0.00001 的状态，就能使因子移动四分之一个标准差；似然没有这么脆弱。

因子吸收所有使各行一起变化的因素，包括组合结构的变化，例如账龄，因此 counts 和 matrix 应当描述可比的组合。

示例

>>> import pandas as pd
>>> from kivi.lifetime import conditional_matrix, matrix_factor
>>> states = ["A", "B", "D"]
>>> matrix = pd.DataFrame(
...     [[0.90, 0.08, 0.02], [0.10, 0.70, 0.20], [0.00, 0.00, 1.00]],
...     index=states,
...     columns=states,
... )
>>> counts = pd.DataFrame(
...     [[850, 110, 40], [60, 280, 160], [0, 0, 0]], index=states, columns=states
... )
>>> print(f"{matrix_factor(counts, matrix, correlation=0.1):.4f}")
-0.8425

两个状态的违约都比 matrix 给出的多，A 为 4% 对 2%，B 为 32% 对 20%，因此该期比平均差。

kivi.lifetime.matrix_correlation(counts, matrix, *, default_state=None)#

由多期的迁移估计资产相关系数。

Belkin、Suchower 和 Forest（1998）选择这样的相关系数：各期因子的变化与模型中标准正态因子的变化一样大，即样本方差为 1。每期的因子就是 matrix_factor 给出的因子。

参数:
countsmapping、sequence 或 pandas.Series

返回值:

异常:

kivi.capital.vasicek_fit

由违约率序列得到的相关系数。

说明

样本方差用 ddof=1 计算，与 kivi.capital.vasicek_fit 相同，因子的均值不强制为 0。相关系数从 0 上升时，方差从无穷大陡然下降，在 0.5 附近趋于平缓；相关系数更高时，方差可能再次上升又下降。这一形状经过数值检验，但没有证明。结果是 0.99 以内方差为 1 的最小相关系数：先以 0.01 为步长的网格找到第一个方差不超过 1 的相关系数，再在它与前一步之间二分。相关系数高于约 0.5 时，单位方差条件不能确定相关系数，真实值可能是较大的那个根：在 Witzany（2020，表 2）的矩阵下，样本方差为 1 的六期因子在相关系数 0.6、0.7、0.8 和 0.9 下的期望计数，分别给出 0.557、0.503、0.462 和 0.431。

由于估计因子的方差被设为 1，估计值约等于真实相关系数乘以各期真实因子的样本方差，因此期数少时估计很不确定。小组合的二项噪声会增大因子的方差，使估计偏高。

单位方差条件来自 Belkin、Suchower 和 Forest（据 Shao、Li 和 Li 2018 年第 2 节的转述）；他们用加权最小二乘估计因子（见 matrix_factor ）。另一条路线是用 kivi.capital.vasicek_fit 由违约率序列估计相关系数，用 kivi.capital.systematic_factor 估计因子。

>>> import pandas as pd

>>> matrix = pd.DataFrame(
...     [[0.90, 0.08, 0.02], [0.10, 0.70, 0.20], [0.00, 0.00, 1.00]],
...     index=states,
...     columns=states,
... )
>>> years = {
...     2023: [[930, 60, 10], [130, 740, 130], [0, 0, 0]],
...     2024: [[850, 110, 40], [60, 280, 160], [0, 0, 0]],
...     2025: [[900, 80, 20], [100, 700, 200], [0, 0, 0]],
... }
>>> correlation = matrix_correlation(years, matrix)
>>> print(f"{correlation:.4f}")
0.0515
>>> factors = [matrix_factor(c, matrix, correlation=correlation) for c in years.values()]
>>> [round(factor, 4) for factor in factors]
[0.8946, -1.1045, -0.0529]

这些计数是列表，按位置与 matrix 的状态对应。在这个相关系数下，三年的因子的样本方差为 1。

kivi.lifetime.survival_table(duration, event, *, competing=None, entry=None, weights=None)#

由存在删失和截断的账户估计累计 PD 期限结构。

每个账户（例如一笔贷款）从某个起点（例如放款）开始逐期跟踪，直到违约、因其他原因退出（例如提前还款），或最后一次被观测到，此时该账户被删失。该表给出每期处于风险中的账户数和违约风险率；不给 competing 时给出累计 PD 的 Kaplan–Meier 估计，给出时给出违约累计发生率的 Aalen–Johansen 估计。

参数:
durationarray_like

每个账户违约、退出或最后一次被观测的期数，为正整数，例如月度面板中该账户最后一行的账龄。

eventarray_like

账户是否在第 duration 期违约，为布尔值或 0 与 1。

competingarray_like，可选

账户是否在第 duration 期因其他原因退出、从而不再有违约风险，例如提前还款，为布尔值或 0 与 1。在 event 为 1 的行上它不能为 1。不给出时，所有未违约的账户都视为删失。

entryarray_like，可选

每个账户开始被观测时已经过去的期数，为 0 到该账户 duration − 1 之间的整数，默认为 0。账户从第 entry + 1 期起处于风险中，因此在账龄 7 首次被观测到的贷款，其 entry 为 6。这用于处理左截断，例如在贷款发放之后才开始的面板。

weightsarray_like，可选

每个账户的非负频数权重。计数变为权重之和，因此整数权重与重复相应账户得到的表相同，权重为 0 的账户被排除。作为 Series 传入的输入，索引必须完全相同；否则按位置对应。

返回值:
pandas.DataFrame

从第 1 期到最大的 duration 每期一行，索引名为 period ，各列为 at_risk 、 event 、 competing （仅在给出 competing 时）、 censored 、 hazard 、 survival 和 cumulative_pd ，含义见“说明”。不给 weights 时计数为整数，给出时为权重之和。

异常:
ValueError

如果输入为空、不是一维、长度不同或是索引不同的 Series。此外，如果 duration 不是实数数值或含有不是正整数的值， event 或 competing 含有 0 和 1 以外的值，二者在同一行都为 1， entry 不是实数数值或含有不是 0 到该账户 duration − 1 之间整数的值，或者 weights 不是数值，或没有为每个账户给出一个有限非负、总和为正的权重，也会引发此异常。

参见

convert_pd

由 cumulative_pd 得到边际 PD 和条件 PD。

expected_credit_loss

由边际 PD 计算的预期信用损失。

kivi.vintage.vintage_table

按批次和账龄统计的累计坏账率。

kivi.datasets.make_loan_panel

含提前还款的合成贷款面板。

说明

对 duration 为 \(T_i\) 、entry 为 \(e_i\) 、权重为 \(w_i\) （不给 weights 时为 1）的账户 \(i\) ，第 \(t\) 期的各列为：

  • at_risk ： \(n_t = \sum_i w_i \, [e_i < t \le T_i]\) ，该期处于违约风险中的账户；

  • event ： \(d_t\) ，该期违约账户的权重；

  • competing ： \(c_t\) ，该期因其他原因退出的账户的权重；

  • censored ：该期最后一次被观测、既未违约也未退出的账户的权重；

  • hazard ： \(h_t = d_t / n_t\) ，处于风险中的账户中违约的比例；

  • survival ： \(S(t) = \prod_{s \le t} (1 - (d_s + c_s) / n_s)\) ，到该期末既未违约也未退出的概率，其中 \(S(0) = 1\) ；

  • cumulative_pd ：到该期末发生违约的概率。

不给 competing 时， \(c_t = 0\) ， cumulative_pd 是 Kaplan–Meier 估计

\[F(t) = 1 - \prod_{s \le t} (1 - h_s) = 1 - S(t).\]

给出 competing 时，它是违约累计发生率的 Aalen–Johansen 估计，累加此前既未违约也未退出的账户的违约：

\[F(t) = \sum_{s \le t} S(s - 1) \, h_s.\]

在某期被删失的账户在该期仍处于风险中：删失排在该期的违约和退出之后。没有账户处于风险中的期，其风险率为 NaN，从该期起 survival 和 cumulative_pd 也为 NaN，因为不知道有多少比例的账户能度过这一期。给出 entry 时，如果最初几期没有观测到任何账户，也会出现这种情况；此时后面各期的风险率给出以到达这些期为条件的 PD。

提前退出的账户不会再违约。像 1 − Kaplan–Meier 那样把它计为删失，估计的是一直留在账上直到违约的账户的 PD，会高估违约账户的比例：应把提前退出作为 competing 传入。如果每个账户都从第 1 期起被观测，直到违约或退出，或直到所有账户共同的最后一期，累计发生率就是到各期为止已违约账户的比例，即 kivi.vintage.vintage_table 的累计坏账率。

cumulative_pd 是可传给 convert_pd 的累计期限结构。不给 competing 时，它的条件 PD 就是风险率。给出 competing 时，条件 PD 以此前未违约为条件，与 vintage 表一样也计入已退出的账户，而风险率以账户仍在账上为条件。

参考文献

[1]

E. L. Kaplan and P. Meier, "Nonparametric estimation from incomplete observations", Journal of the American Statistical Association, 53(282), pp. 457-481, 1958.

[2]

O. O. Aalen and S. Johansen, "An empirical transition matrix for non-homogeneous Markov chains based on censored observations", Scandinavian Journal of Statistics, 5(3), pp. 141-150, 1978.

示例

八笔贷款、三个月：三笔违约，两笔提前还款，三笔在观测结束时仍在账上。

>>> from kivi.lifetime import survival_table
>>> duration = [1, 1, 2, 2, 2, 3, 3, 3]
>>> event = [1, 0, 1, 0, 0, 1, 0, 0]
>>> repaid = [0, 1, 0, 1, 0, 0, 0, 0]
>>> survival_table(duration, event, competing=repaid).round(4)
        at_risk  event  competing  censored  hazard  survival  cumulative_pd
period
1             8      1          1         0  0.1250    0.7500         0.1250
2             6      1          1         1  0.1667    0.5000         0.2500
3             3      1          0         2  0.3333    0.3333         0.4167

第三个月时还有一半贷款在账上，其中三分之一违约：0.25 + 0.5 × 1/3 = 0.4167。把提前还款计为删失，得到的 Kaplan–Meier 估计 1 − (7/8)(5/6)(2/3) 更高：

>>> survival_table(duration, event)["cumulative_pd"].round(4)
period
1    0.1250
2    0.2708
3    0.5139

kivi.lifetime.expected_credit_loss(probability, lgd, ead, *, rate, horizon=None)#

计算每个账户的 12 个月或整个存续期预期信用损失。

IFRS 9 的预期信用损失对报告日之后的各期求和：每一期的违约概率乘以该期的违约损失率和违约风险敞口，再按实际利率折现到报告日。把 12 个月对应的期数作为 horizon 传入，得到第一阶段的 12 个月预期信用损失；不传则得到第二、三阶段的整个存续期预期信用损失。

参数:
probabilityarray_like 或 pandas.DataFrame

边际 PD，每个账户一行，报告日之后每一期一列：第 \(t\) 列是在报告日看来该账户在第 \(t\) 期违约的概率。每行之和至多为 1。 convert_pd 可由累计或条件期限结构得到边际 PD。布尔值按 0 和 1 计。

lgdfloat、array_like 或 pandas.DataFrame

违约损失率，即占违约风险敞口的比例，取值在 0 到 1 之间：可以是适用于所有账户和各期的一个值，每个账户一个值的一维 array_like，或每个账户每期一个值的二维计划表。二维数组也可以只有一行（适用于所有账户）或只有一列（适用于各期）。

eadfloat、array_like 或 pandas.DataFrame

违约风险敞口，须为有限非负值，形式与 lgd 相同：一个值，每个账户一个值（例如报告日的余额），或计划表（例如每期预计的余额）。账户到期之后的各期，敞口请设为 0。每个账户一行的 Series 和 DataFrame 必须具有相同的索引，每期一列的 DataFrame 必须具有相同的列。只有一行或一列的输入会被广播，因此只有一个账户或一期时，只使用 probability 的标签。

ratefloat 或 array_like

用于折现损失的每期实际利率，须大于 -1，可以是一个值，也可以每个账户一个值。按月分期、年利率为 \(r\) 时，传入 \((1 + r)^{1/12} - 1\) 。传入 0 表示不折现。

horizonint，可选

从第 1 期起求和的期数：按月分期时为 12，按年分期时为 1，得到 12 个月预期信用损失。默认取 probability 的全部期数，得到整个存续期预期信用损失。

返回值:
pandas.Series 或 numpy.ndarray

每个账户的预期信用损失，单位与 ead 相同。如果 probability 是 DataFrame，或在有多个账户时另一个每个账户一行的输入是 pandas 对象，返回名为 expected_credit_loss 、具有其索引的 Series；否则返回数组。

异常:
ValueError

如果 probability 不是至少有一个账户和一期的二维输入，某个输入不是实数数值或不具有上述任何一种形状，或 pandas 输入的索引或列不同。此外，如果 probability 或 lgd 有取值超出 [0, 1]， probability 某一行之和超过 1， ead 含有负值或无穷值， rate 为无穷值、不大于 -1 或使折现因子溢出，或者 horizon 不是不超过期数的正整数，也会引发此异常。

参见

convert_pd

由累计或条件 PD 得到的边际 PD。

transition_pd

由转移矩阵得到的累计 PD。

assign_stages

每个账户的阶段，它决定了求和的期限。

stage_table

按阶段汇总的敞口和预期信用损失。

kivi.strategy.expected_loss

单一期限内的预期损失。

说明

对于第 \(t\) 期边际 PD 为 \(m_t\) 、违约损失率为 \(\mathrm{LGD}_t\) 、违约风险敞口为 \(\mathrm{EAD}_t\) ，每期实际利率为 \(r\) 的账户，

\[\mathrm{ECL} = \sum_{t=1}^{H} m_t \, \mathrm{LGD}_t \, \mathrm{EAD}_t \, (1 + r)^{-t},\]

其中 \(H\) 为 horizon 或期数。约定如下：

  • 第 1 期从报告日开始，一期后结束；第 \(t\) 期在报告日之后 \(t\) 期结束。

  • 第 \(t\) 期的违约视为发生在该期期末，因此其损失折现 \(t\) 期。

  • 边际 PD 不以存续为条件：它们是在报告日看来的概率，之和等于累计 PD。对于截至报告日未违约的账户，请把其期限结构中从报告日时的账龄开始的条件 PD 用 kind="conditional" 和 to="marginal" 转换。

  • 各列必须覆盖期限最长的账户的剩余存续期。在求和期限内到期的账户，到期后的敞口为 0，因此其 12 个月预期信用损失与整个存续期预期信用损失相等。

报告日已经违约的敞口在报告日就已违约，而不是在某一期期末。请为其设置第 1 期边际 PD 为 1、利率为 0，使其预期信用损失等于 LGD 乘以 EAD：已违约敞口的 LGD 通常已经对回收款做了折现。

若求和的某一期 PD、LGD 或 EAD 缺失，或者利率缺失，该账户的预期信用损失为缺失，与 kivi.strategy.expected_loss 一致。 horizon 之后各期的缺失值不会被使用。

示例

>>> from kivi.lifetime import expected_credit_loss
>>> marginal = [[0.02, 0.03, 0.03], [0.10, 0.08, 0.06]]
>>> schedule = [[1000.0, 700.0, 400.0], [500.0, 250.0, 0.0]]
>>> expected_credit_loss(marginal, 0.5, schedule, rate=0.05).round(2)
array([24.23, 32.88])
>>> expected_credit_loss(marginal, 0.5, schedule, rate=0.05, horizon=1).round(2)
array([ 9.52, 23.81])

第一个账户在第 1 期损失 0.02 × 0.5 × 1000 / 1.05 = 9.52，在第 2 期损失 0.03 × 0.5 × 700 / 1.05² = 9.52，在第 3 期损失 0.03 × 0.5 × 400 / 1.05³ = 5.18。

kivi.lifetime.significant_increase(probability, origination_probability, *, relative, absolute)#

标记自初始确认以来信用风险是否显著增加。

当敞口的信用风险自初始确认以来显著增加时，IFRS 9 将其划入第二阶段。常见的定量测试比较报告日的 PD 与发放时预期的 PD，可以看比率、差值或两者兼看。阈值是报告主体的政策，而不是准则规定的数值，因此没有默认值。

参数:
probabilityarray_like

每笔敞口在报告日的 PD，取值在 0 到 1 之间。

origination_probabilityarray_like

每笔敞口在初始确认时对同一期间预期的 PD，取值在 0 到 1 之间。如果两个输入都是 Series，二者的索引必须完全相同；否则按位置对应。

relativefloat 或 None

如果 probability 超过 origination_probability 的 relative 倍，即为显著增加，因此 2 会标记 PD 增加到两倍以上的敞口。必须大于 1。传入 None 表示不做这项测试。

absolutefloat 或 None

如果 probability 比 origination_probability 高出 absolute 以上（以 PD 为单位），即为显著增加，因此 0.01 会标记 PD 上升超过一个百分点的敞口。必须介于 0 和 1 之间。传入 None 表示不做这项测试。

返回值:
pandas.Series 或 numpy.ndarray

布尔值，信用风险显著增加时为 True。如果某个输入是 Series，返回名为 significant_increase 、具有其索引的 Series；否则返回数组。

异常:
ValueError

如果输入为空、不是一维、长度不同、是索引不同的 Series、不是实数数值，或含有缺失值或 [0, 1] 以外的值。此外，如果 relative 既不是 None 也不是大于 1 的数， absolute 既不是 None 也不是介于 0 和 1 之间的数，或者两者都是 None，也会引发此异常。

参见

assign_stages

由这些标记和逾期天数确定阶段。

convert_pd

由期限结构得到剩余存续期内的累计 PD。

transition_pd

由转移矩阵得到的累计 PD。

说明

设报告日的 PD 为 \(p\) ，发放时预期的 PD 为 \(p_0\) ，测试为

\[p > \mathrm{relative} \cdot p_0 \qquad \text{且} \qquad p - p_0 > \mathrm{absolute}.\]

两项比较都是严格的；PD 在浮点数舍入误差范围内（与 PD 的末位相差几个单位以内）等于阈值时，视为恰好等于阈值：在浮点运算中 0.04 - 0.03 大于 0.01 ， 1.5 * 0.30 小于 0.45 ，但这两对都不会被标记。

同时给出两个阈值时，只有两项测试都通过才算显著增加，这样绝对阈值可以避免低 PD 的微小变化被计入。若规则只要求通过任一项测试，请分别用一个阈值调用两次，再用 | 合并。定性标准（例如关注名单或债务重组）也以同样的方式与这些标记合并。

IFRS 9 评估的是敞口在预计存续期内违约风险的变化；若未来 12 个月的违约风险能给出合理的近似，也允许使用它。请比较相同期限的 PD：对于存续期 PD，应与发放时对同一剩余存续期预期的 PD 比较。

示例

>>> from kivi.lifetime import significant_increase
>>> probability = [0.004, 0.012, 0.03, 0.09]
>>> origination_probability = [0.001, 0.010, 0.01, 0.05]
>>> significant_increase(
...     probability, origination_probability, relative=2.0, absolute=None
... )
array([ True, False,  True, False])
>>> significant_increase(
...     probability, origination_probability, relative=2.0, absolute=0.01
... )
array([False, False,  True, False])

第一个 PD 增加到四倍，但只上升了 0.3 个百分点；最后一个上升了 4 个百分点，但没有翻倍。

kivi.lifetime.assign_stages(significant_increase, days_past_due=None, defaulted=None, *, stage_2_days=30, stage_3_days=90)#

把敞口划分到 IFRS 9 的三个阶段。

第一阶段包括自初始确认以来信用风险没有显著增加的敞口，第二阶段包括信用风险已显著增加的敞口，第三阶段包括已发生信用减值的敞口。逾期天数作为兜底标准：逾期超过 stage_2_days 天的敞口至少处于第二阶段，逾期至少 stage_3_days 天或被标记为违约的敞口处于第三阶段。

参数:
significant_increasearray_like

每笔敞口的信用风险自初始确认以来是否显著增加，取布尔值或 0 和 1，例如函数 significant_increase 的结果，也可以与定性标准合并。

days_past_duearray_like，可选

每笔敞口在报告日的逾期天数，须为有限非负值。不传入时不适用兜底标准。

defaultedarray_like，可选

每笔敞口是否已发生信用减值（通常是因为按主体的违约定义处于违约状态），取布尔值或 0 和 1。这些敞口处于第三阶段。

stage_2_daysfloat，默认 30

逾期超过该天数的敞口至少处于第二阶段。默认值依据 IFRS 9 第 5.5.11 段的可推翻假设：合同付款逾期超过 30 天时，信用风险已显著增加。

stage_3_daysfloat，默认 90

逾期达到或超过该天数的敞口处于第三阶段。默认值依据 IFRS 9 第 B5.5.37 段的可推翻假设：违约的发生不晚于金融资产逾期 90 天之时。必须大于 stage_2_days 。

返回值:
pandas.Series 或 numpy.ndarray

每笔敞口的阶段，取整数 1、2 或 3。如果某个输入是 Series，返回名为 stage 、具有其索引的 Series；否则返回数组。

异常:
ValueError

如果输入为空、不是一维、长度不同或是索引不同的 Series， significant_increase 或 defaulted 含有 0 和 1 以外的值，或者 days_past_due 不是实数数值或含有缺失值、负值或无穷值。此外，如果 stage_2_days 或 stage_3_days 不是有限的非负数，或 stage_3_days 不大于 stage_2_days ，也会引发此异常。

参见

significant_increase

信用风险显著增加的定量测试。

stage_table

按阶段汇总的敞口和预期信用损失。

expected_credit_loss

12 个月和整个存续期的预期信用损失。

说明

敞口已违约或逾期至少 stage_3_days 天时处于第三阶段；否则，若 significant_increase 为真或逾期超过 stage_2_days 天，处于第二阶段；其余处于第一阶段。因此按默认值，恰好逾期 30 天的敞口仍处于第一阶段，而恰好逾期 90 天的敞口处于第三阶段，与两项假设的表述一致。

IFRS 9 按对预计现金流量产生不利影响的事件来界定已发生信用减值的敞口，例如违约或借款人发生重大财务困难。实务中，主体通常使其与自身的违约定义保持一致。阈值、违约定义以及回到正常的处理都是报告主体的政策。观察期（敞口不再满足某项标准后仍留在原阶段的期间）需要每笔敞口的历史，此处不予处理。

示例

>>> from kivi.lifetime import assign_stages
>>> increase = [False, True, False, False, False]
>>> days_past_due = [0, 0, 45, 90, 0]
>>> defaulted = [False, False, False, False, True]
>>> assign_stages(increase, days_past_due, defaulted)
array([1, 2, 2, 3, 3])
kivi.lifetime.stage_table(stage, exposure, allowance, *, weights=None)#

汇总每个阶段的敞口和预期信用损失。

每行汇总一个阶段的敞口和损失准备，并给出二者之比，即银行按阶段披露的覆盖率。

参数:
stagearray_like

每笔敞口的阶段，取 1、2 或 3，例如 assign_stages 的结果。

exposurearray_like

每个账户在报告日的敞口，例如其账面余额，须为有限非负值。

allowancearray_like

每个账户的损失准备，须为有限非负值：第一阶段为其 12 个月预期信用损失，第二、三阶段为其整个存续期预期信用损失。作为 Series 传入的输入，索引必须完全相同；否则按位置对应。

weightsarray_like，可选

每笔敞口的非负权重，例如其抽样比例的倒数，对应方式与 exposure 相同。计数、敞口和损失准备都变为加权和，因此整数权重与重复相应行得到的表相同。

返回值:
pandas.DataFrame

阶段 1、2、3 各占一行（索引名为 stage ），没有敞口的阶段也保留，各列含义见“说明”。

异常:
ValueError

如果输入为空、不是一维、长度不同或是索引不同的 Series，或不是实数数值。此外，如果 stage 含有 1、2、3 以外的值， exposure 或 allowance 含有缺失值、负值或无穷值，或者 weights 不是数值，或没有为每笔敞口给出一个有限非负、总和为正的权重，也会引发此异常。

参见

assign_stages

每笔敞口的阶段。

expected_credit_loss

12 个月和整个存续期的预期信用损失。

kivi.strategy.expected_loss_table

按等级汇总的敞口和预期损失。

说明

对于一个阶段中的敞口 \(i\) ，权重为 \(w_i\) （不传 weights 时为 1），各列为：

  • total：敞口数， \(\sum_i w_i\)；

  • exposure ： \(\sum_i w_i E_i\) ，其中 \(E_i\) 为敞口；

  • exposure_share ：该阶段占全部阶段敞口的比例；总敞口为 0 时，每个阶段均为 NaN；

  • expected_credit_loss ： \(\sum_i w_i L_i\) ，其中 \(L_i\) 为损失准备；

  • coverage ： expected_credit_loss 除以 exposure ，没有敞口的阶段为 NaN。

资产组合的敞口和损失准备分别是 exposure 列和 expected_credit_loss 列之和，其覆盖率是后者之和除以前者之和。

示例

>>> from kivi.lifetime import stage_table
>>> stage = [1, 1, 1, 2, 3]
>>> exposure = [1000.0, 2000.0, 1000.0, 800.0, 200.0]
>>> allowance = [5.0, 8.0, 3.0, 40.0, 90.0]
>>> stage_table(stage, exposure, allowance)
       total  exposure  exposure_share  expected_credit_loss  coverage
stage
1          3    4000.0            0.80                  16.0     0.004
2          1     800.0            0.16                  40.0     0.050
3          1     200.0            0.04                  90.0     0.450
