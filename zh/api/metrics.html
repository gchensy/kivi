模型表现#

衡量随事件概率升高而增大的评分区分事件与非事件的能力。 roc_auc() 、 gini() 和 ks() 概括排序能力， roc_table() 列出 ROC 曲线， roc_auc_interval() 和 delong_test() 给出 DeLong 标准误， generalized_auc() 把带标准误的 AUC 推广到实际 LGD 分段等有序结果， gains_table() 按评分段分解排序能力， brier_score() 把概率与实际结果比较， expected_maximum_profit() 给出信用评分最优截断点的期望利润。

定义、示例以及如何解读增益表，见 模型表现 。

估计 AUC 的标准误和置信区间。

kivi.metrics.roc_auc(score, target, *, weights=None)#

计算评分的 ROC 曲线下面积。

AUC 是随机抽取的一个事件比随机抽取的一个非事件评分更高的概率，评分相同时计为二分之一。

评分在前、目标在后，与 kivi.woe.woe_table 相同；scikit-learn 的指标函数则把目标放在前面。

参数:
scorearray_like

有限的数值评分，事件概率越高，评分越高。评分卡分数越高表示风险越低，因此须取负后再传入。

targetarray_like

二分类标签，1 表示事件。两个类别都必须出现。如果 score 和 target 都是 pandas Series，二者的索引必须完全相同；否则按位置对应。

weightsarray_like，可选

每个观测的非负权重，例如其抽样比例的倒数，对应方式与 target 相同。每个计数都变为权重之和，因此整数权重与重复相应行的结果相同。

返回值:
float

AUC，取值 0 到 1。与目标无关的评分约为 0.5，低于 0.5 则说明评分方向可能相反。

异常:
ValueError

如果输入为空或不是一维的，索引或长度不一致，target 含有 0 和 1 以外的标签或缺少其中之一，或 score 不是实数数值或含有缺失值、无穷值。此外，如果 weights 不是数值、没有为每个观测给出一个有限非负的权重、索引与 score 不同，或使某一类没有权重，也会引发此异常。

参见

gini

同一排序度量，取值范围为 -1 到 1。

ks

两个类别评分分布之间的最大差距。

gains_table

各评分段的事件率和捕获的事件。

说明

设有 \(n_1\) 个事件和 \(n_0\) 个非事件，\(R_1\) 为事件在全部评分中的秩之和，相同评分取平均秩。由 Mann-Whitney 统计量得

\[\mathrm{AUC} = \frac{R_1 - n_1 (n_1 + 1) / 2}{n_1 n_0}.\]

使用权重时，每一对事件 \(i\) 与非事件 \(j\) 以权重 \(w_i w_j\) 计入， \(n_1\) 和 \(n_0\) 则是两类的权重总和。

参考文献

[1]

J. A. Hanley and B. J. McNeil, "The meaning and use of the area under a receiver operating characteristic (ROC) curve", Radiology, 143(1), pp. 29-36, 1982.

示例

>>> from kivi.metrics import roc_auc
>>> score = [0.1, 0.4, 0.4, 0.8, 0.7, 0.9]
>>> target = [0, 0, 1, 0, 1, 1]
>>> round(roc_auc(score, target), 4)
0.7222

评分卡分数越高表示风险越低，因此要取负：

>>> import numpy as np
>>> points = np.array([720, 650, 650, 560, 590, 510])
>>> round(roc_auc(-points, target), 4)
0.7222
kivi.metrics.gini(score, target, *, weights=None)#

计算评分的 Gini 系数。

Gini 系数把 AUC 换算到 -1 到 1 的范围，使与目标无关的评分约为 0。

评分在前、目标在后，与 kivi.woe.woe_table 相同；scikit-learn 的指标函数则把目标放在前面。

参数:
scorearray_like

有限的数值评分，事件概率越高，评分越高。评分卡分数越高表示风险越低，因此须取负后再传入。

targetarray_like

二分类标签，1 表示事件。两个类别都必须出现。如果 score 和 target 都是 pandas Series，二者的索引必须完全相同；否则按位置对应。

weightsarray_like，可选

每个观测的非负权重，例如其抽样比例的倒数，对应方式与 target 相同。每个计数都变为权重之和，因此整数权重与重复相应行的结果相同。

返回值:
float

Gini 系数，取值 -1 到 1。负值说明评分方向可能相反。

异常:
ValueError

如果输入为空或不是一维的，索引或长度不一致，target 含有 0 和 1 以外的标签或缺少其中之一，或 score 不是实数数值或含有缺失值、无穷值。此外，如果 weights 不是数值、没有为每个观测给出一个有限非负的权重、索引与 score 不同，或使某一类没有权重，也会引发此异常。

参见

roc_auc

ROC 曲线下面积。

ks

两个类别评分分布之间的最大差距。

说明

Gini 系数也称为准确性比率（accuracy ratio），其定义为

\[\mathrm{Gini} = 2\,\mathrm{AUC} - 1.\]

示例

>>> from kivi.metrics import gini
>>> score = [0.1, 0.4, 0.4, 0.8, 0.7, 0.9]
>>> target = [0, 0, 1, 0, 1, 1]
>>> round(gini(score, target), 4)
0.4444
kivi.metrics.ks(score, target, *, weights=None)#

计算评分的 Kolmogorov-Smirnov 统计量。

KS 统计量是事件评分的累计分布与非事件评分的累计分布之间的最大差距。

评分在前、目标在后，与 kivi.woe.woe_table 相同；scikit-learn 的指标函数则把目标放在前面。

参数:
scorearray_like

有限的数值评分，例如预测的事件概率。

targetarray_like

二分类标签，1 表示事件。两个类别都必须出现。如果 score 和 target 都是 pandas Series，二者的索引必须完全相同；否则按位置对应。

weightsarray_like，可选

每个观测的非负权重，例如其抽样比例的倒数，对应方式与 target 相同。每个计数都变为权重之和，因此整数权重与重复相应行的结果相同。

返回值:
float

最大差距，取值 0 到 1。

异常:
ValueError

如果输入为空或不是一维的，索引或长度不一致，target 含有 0 和 1 以外的标签或缺少其中之一，或 score 不是实数数值或含有缺失值、无穷值。此外，如果 weights 不是数值、没有为每个观测给出一个有限非负的权重、索引与 score 不同，或使某一类没有权重，也会引发此异常。

参见

gains_table

每个评分段边界处的差距。

roc_auc

事件评分高于非事件评分的概率。

说明

设 \(F_1\) 和 \(F_0\) 分别为事件评分和非事件评分的经验分布函数，则

\[\mathrm{KS} = \max_t \, \lvert F_1(t) - F_0(t) \rvert,\]

其中 \(t\) 取遍观测到的评分。使用权重时，分布函数按权重计算。与双样本 Kolmogorov-Smirnov 检验一样，差距取绝对值，因此评分取负后 KS 不变；请用 gini 的符号检查方向。

最大差距可能来自评分方向相反的区域，例如事件既集中在最高评分处，也集中在最低评分处。此时 KS 衡量的是两个分布相距多远，而不是评分把事件排在非事件之前的能力。gains_table 中的累计占比可以显示差距出现的位置。

参考文献

[1]

L. C. Thomas, D. B. Edelman and J. N. Crook, "Credit Scoring and Its Applications", SIAM, 2002.

示例

>>> from kivi.metrics import ks
>>> score = [0.1, 0.4, 0.4, 0.8, 0.7, 0.9]
>>> target = [0, 0, 1, 0, 1, 1]
>>> round(ks(score, target), 4)
0.3333
kivi.metrics.roc_table(score, target, *, weights=None)#

列出评分的 ROC 曲线，每个不同的评分一行。

每一行标记评分不低于该行阈值的观测，并统计其中的事件数和非事件数。以 false_positive_rate 为横轴、 true_positive_rate 为纵轴作图，就得到从最高阈值到最低阈值的 ROC 曲线。

评分在前、目标在后，与 kivi.woe.woe_table 相同；scikit-learn 的指标函数则把目标放在前面。

参数:
scorearray_like

有限的数值评分，事件概率越高，评分越高。评分卡分数越高表示风险越低，因此须取负后再传入。

targetarray_like

二分类标签，1 表示事件。两个类别都必须出现。如果 score 和 target 都是 pandas Series，二者的索引必须完全相同；否则按位置对应。

weightsarray_like，可选

每个观测的非负权重，例如其抽样比例的倒数，对应方式与 target 相同。计数变为权重之和，所有观测权重都为零的评分不占一行，因此整数权重与重复相应行得到相同的表。

返回值:
pandas.DataFrame

每个阈值一行，索引名为 threshold ：第一行为无穷大，不标记任何观测；其后是从高到低的每个不同评分，最后一行标记全部观测。各列见“说明”。

异常:
ValueError

如果输入为空或不是一维的，索引或长度不一致，target 含有 0 和 1 以外的标签或缺少其中之一，或 score 不是实数数值或含有缺失值、无穷值。此外，如果 weights 不是数值、没有为每个观测给出一个有限非负的权重、索引与 score 不同，或使某一类没有权重，也会引发此异常。

参见

roc_auc

曲线下面积。

ks

两个比率之间的最大差距。

gains_table

按评分段计算的同样的累计占比。

说明

各列为：

  • cum_non_event 和 cum_event ：评分不低于阈值的非事件数和事件数，或者它们的权重之和；

  • false_positive_rate 和 true_positive_rate ：上述计数分别占全部非事件和全部事件的比例；

  • precision ： cum_event 除以两项计数之和，即被标记观测中的事件率，第一行为 NaN。

评分相同的观测共用一行，因此曲线沿对角方向越过并列的评分。于是曲线下各梯形的面积之和等于 roc_auc ，后者把评分相同的一对计为二分之一：

\[\mathrm{AUC} = \sum_{k \ge 1} (\mathrm{FPR}_k - \mathrm{FPR}_{k-1}) \, \frac{\mathrm{TPR}_k + \mathrm{TPR}_{k-1}}{2},\]

而两个比率之间的最大差距 \(\max_k \lvert \mathrm{TPR}_k - \mathrm{FPR}_k \rvert\) 等于 ks 。各行与 sklearn.metrics.roc_curve 在 drop_intermediate=False 时返回的点相同。

示例

>>> from kivi.metrics import roc_table
>>> score = [0.1, 0.4, 0.4, 0.8, 0.7, 0.9]
>>> target = [0, 0, 1, 0, 1, 1]
>>> table = roc_table(score, target)
>>> table[["cum_non_event", "cum_event", "false_positive_rate", "true_positive_rate"]].round(3)
           cum_non_event  cum_event  false_positive_rate  true_positive_rate
threshold
inf                    0          0                0.000               0.000
0.9                    0          1                0.000               0.333
0.8                    1          1                0.333               0.333
0.7                    1          2                0.333               0.667
0.4                    2          3                0.667               1.000
0.1                    3          3                1.000               1.000
>>> table["precision"].round(3).tolist()
[nan, 1.0, 0.5, 0.667, 0.6, 0.5]
kivi.metrics.roc_auc_interval(score, target, *, level=0.95, weights=None)#

估计 AUC 的标准误和置信区间。

标准误采用 DeLong、DeLong 和 Clarke-Pearson 的方法 [1] ，不对评分的分布作任何假设。Gini 系数的区间由 AUC 的区间换算得到。

评分在前、目标在后，与 kivi.woe.woe_table 相同；scikit-learn 的指标函数则把目标放在前面。

参数:
scorearray_like

有限的数值评分，事件概率越高，评分越高。评分卡分数越高表示风险越低，因此须取负后再传入。

targetarray_like

二分类标签，1 表示事件。不使用 weights 时，至少要有两个事件和两个非事件。如果 score 和 target 都是 pandas Series，二者的索引必须完全相同；否则按位置对应。

levelfloat，默认 0.95

区间的置信水平，介于 0 和 1 之间。

weightsarray_like，可选

每个观测的非负频数权重，对应方式与 target 相同。权重为 \(w\) 的观测计为 \(w\) 个观测，因此整数权重与重复相应行的结果相同，标准误也是如此。每一类的权重之和必须大于 1。

返回值:
pandas.DataFrame

两行 auc 和 gini ，位于名为 statistic 的索引中；列为 estimate 、表示标准误的 se ，以及表示区间上下限的 lower 和 upper 。

异常:
ValueError

如果输入为空或不是一维的，索引或长度不一致，target 含有 0 和 1 以外的标签，或在不使用 weights 时其中某一类少于两个，或 score 不是实数数值或含有缺失值、无穷值。此外，如果 level 不是介于 0 和 1 之间的数，或者 weights 不是数值、没有为每个观测给出一个有限非负的权重、索引与 score 不同，或使某一类的权重之和不超过 1，也会引发此异常。

参见

roc_auc

只计算 AUC。

delong_test

在同一批观测上比较两个评分的 AUC。

说明

设 \(n_1\) 为事件数， \(n_0\) 为非事件数。事件 \(i\) 的位置值 \(V_{10,i}\) 是评分低于它的非事件所占的比例，非事件 \(j\) 的位置值 \(V_{01,j}\) 是评分高于它的事件所占的比例，评分相同时计为二分之一。两组位置值的均值都等于 AUC \(\hat\theta\) ，其方差的估计为

\[\widehat{\mathrm{Var}}(\hat\theta) = \frac{S_{10}}{n_1} + \frac{S_{01}}{n_0}, \qquad S_{10} = \frac{1}{n_1 - 1} \sum_{i=1}^{n_1} (V_{10,i} - \hat\theta)^2,\]

其中 \(S_{01}\) 在非事件上按同样的方式定义。与 Sun 和 Xu 的算法 [2] 一样，位置值由中秩求得：一个事件在全部评分中的秩减去它在事件中的秩，就是评分低于它的非事件个数，评分相同时计为二分之一。因此，对 \(N\) 个观测，计算耗时为 \(O(N \log N)\) ，无须比较每一对观测。

区间为 \(\hat\theta \pm z \, \mathrm{SE}\) ，并截断到 0 与 1 之间，其中 \(z\) 是标准正态分布在 \((1 + \mathrm{level}) / 2\) 处的分位数。Gini 系数为 \(2\,\mathrm{AUC} - 1\) ，其估计值和区间上下限按同样的方式换算，标准误加倍。

当 AUC 接近 0 或 1，或某一类的观测很少时，正态近似的效果较差。只要每一类内部的位置值都相同，标准误就为 0，例如把两类完全分开的评分、把两类完全颠倒的评分以及常数评分，此时区间缩为估计值本身。

使用权重时， \(n_1\) 和 \(n_0\) 是两类的权重总和，每个离差平方按其观测的权重计入。因此，代表比样本更大的总体的权重（例如抽样比例的倒数）会使标准误偏小。

参考文献

[1]

E. R. DeLong, D. M. DeLong and D. L. Clarke-Pearson, "Comparing the areas under two or more correlated receiver operating characteristic curves: a nonparametric approach", Biometrics, 44(3), pp. 837-845, 1988.

[2]

X. Sun and W. Xu, "Fast implementation of DeLong's algorithm for comparing the areas under correlated receiver operating characteristic curves", IEEE Signal Processing Letters, 21(11), pp. 1389-1393, 2014.

示例

六个观测给出的区间很宽，其上限被截断为 1：

>>> from kivi.metrics import roc_auc_interval
>>> score = [0.1, 0.4, 0.4, 0.8, 0.7, 0.9]
>>> target = [0, 0, 1, 0, 1, 1]
>>> roc_auc_interval(score, target).round(4)
           estimate      se   lower  upper
statistic
auc          0.7222  0.2485  0.2353    1.0
gini         0.4444  0.4969 -0.5295    1.0
kivi.metrics.delong_test(current, new, target, *, level=0.95, weights=None)#

检验同一批观测的两个评分的 AUC 是否相同。

DeLong 检验 [1] 比较同一样本上的两个评分，例如新模型与它要替换的模型。两个评分对同样的事件与非事件对进行排序，因此它们的 AUC 是相关的，差值的标准误考虑了这种相关性。

评分在前、目标在后，与 kivi.strategy.swap_set 相同；scikit-learn 的指标函数则把目标放在前面。

参数:
currentarray_like

其中一个模型（例如现行模型）的有限数值评分，事件概率越高，评分越高。

newarray_like

另一个模型对同一批观测的有限数值评分，方向相同。

targetarray_like

二分类标签，1 表示事件。不使用 weights 时，至少要有两个事件和两个非事件。 current 、 new 和 target 中任意两个 pandas Series 的索引必须完全相同；否则按位置对应。

levelfloat，默认 0.95

差值区间的置信水平，介于 0 和 1 之间。

weightsarray_like，可选

每个观测的非负频数权重，对应方式与 target 相同。权重为 \(w\) 的观测计为 \(w\) 个观测，因此整数权重与重复相应行的结果相同。每一类的权重之和必须大于 1。

返回值:
pandas.Series

current_auc 和 new_auc ：两个评分的 AUC； difference ： new_auc 减去 current_auc ； se ：差值的标准误； lower 和 upper ：差值在 level 下的区间上下限，截断到 -1 与 1 之间； z ：差值除以其标准误； p_value ： z 的双侧 p 值。

异常:
ValueError

如果输入为空或不是一维的，索引或长度不一致，target 含有 0 和 1 以外的标签，或在不使用 weights 时其中某一类少于两个，或 current 或 new 不是实数数值或含有缺失值、无穷值。此外，如果 level 不是介于 0 和 1 之间的数，或者 weights 不是数值、没有为每个观测给出一个有限非负的权重、索引与评分中某个 Series 的索引不同，或使某一类的权重之和不超过 1，也会引发此异常。

参见

roc_auc_interval

单个 AUC 的标准误和区间。

kivi.strategy.swap_set

两个评分在各自的截断点上决策不同的申请人。

说明

对每个评分分别计算 roc_auc_interval 中的位置值，设 \(D_{10,i}\) 为事件 \(i\) 在新评分下的位置值减去其在现行评分下的位置值， \(D_{01,j}\) 为非事件 \(j\) 的同一差值。它们的均值都等于两个 AUC 之差，其方差的估计为

\[\widehat{\mathrm{Var}}(\hat\theta_{\mathrm{new}} - \hat\theta_{\mathrm{current}}) = \frac{S^D_{10}}{n_1} + \frac{S^D_{01}}{n_0},\]

其中 \(S^D_{10}\) 和 \(S^D_{01}\) 分别是 \(D_{10,i}\) 在 \(n_1\) 个事件上的样本方差和 \(D_{01,j}\) 在 \(n_0\) 个非事件上的样本方差。它等于 DeLong 等人的对比方差，即两个方差之和减去两倍的协方差。在两个 AUC 相等的假设下， \(z\) 近似服从标准正态分布。

如需单侧检验新评分的排序是否更好，在 z 为正时把 p_value 减半。当两个评分对每一对事件与非事件的排序都相同时，差值及其标准误都为 0， z 和 p_value 为 NaN；使用非整数权重时，若差值和标准误都与 0 只差舍入误差，二者都按 0 处理。标准误为 0 而差值不为 0 时（例如常数评分与把两类完全分开的评分之间）， z 为无穷大， p_value 为 0。

权重的计法与 roc_auc_interval 相同，因此抽样比例的倒数会使标准误偏小。

参考文献

[1]

E. R. DeLong, D. M. DeLong and D. L. Clarke-Pearson, "Comparing the areas under two or more correlated receiver operating characteristic curves: a nonparametric approach", Biometrics, 44(3), pp. 837-845, 1988.

kivi.metrics.generalized_auc(estimated, realized, *, level=0.95, weights=None)#

衡量估计分段对实际分段的排序能力，并给出标准误。

欧洲央行的广义 AUC（gAUC） [1] 把 AUC 从二分类目标推广到有序目标，例如按分段划分的债项实际 LGD。它是这样一个概率：在估计分段不同的两个债项中，估计较高的那个实际也较高，平局计为一半。它的线性变换形式就是 Somers' D。

估计值在前、实际值在后，就像 roc_auc_interval 中评分在前、目标在后一样。

参数:
estimatedarray_like

每个观测的估计分段，例如 LGD 模型的债项等级，或切分成分段的 LGD 估计值：可以是有序分类变量（例如 pandas.cut 的结果，按类别顺序排列），也可以是数值（按数值大小排列）。每个不同取值对应列联表的一行。

realizedarray_like

每个观测的实际分段，例如切分成分段的实际 LGD，形式与 estimated 相同。如果 estimated 和 realized 都是 Series，二者的索引必须完全相同；否则按位置对应。

levelfloat，默认 0.95

区间的置信水平，介于 0 和 1 之间。

weightsarray_like，可选

每个观测的非负频数权重，对应方式与 realized 相同：整数权重与重复相应行的结果相同，标准误也是如此。

返回值:
pandas.DataFrame

两行 gauc 和 somers_d ，位于名为 statistic 的索引中；列为 estimate 、表示标准误的 se ，以及表示区间上下限的 lower 和 upper 。

异常:
ValueError

如果输入为空或不是一维的，索引或长度不一致，含有缺失值，或者既不是实数也不是有序分类变量，或者 estimated 中权重为正的不同取值少于两个。此外，如果 level 不是 0 与 1 之间的数，或者 weights 不是数值、没有为每个观测给出一个有限非负且总和为正的权重，或者索引与 estimated 不同，也会引发此异常。

参见

roc_auc_interval

二分类目标的 AUC 及其标准误。

kivi.calibration.backtest_table

回测连续型估计值的水平。

说明

设 \(a_{ij}\) 为估计分段 \(i\) 与实际分段 \(j\) 中的观测数，行合计为 \(r_i\) ，总数为 \(F\) 。对每个单元格， \(A_{ij}\) 统计与它顺序一致的观测， \(D_{ij}\) 统计与它顺序相反的观测：

\[A_{ij} = \sum_{k<i}\sum_{l<j} a_{kl} + \sum_{k>i}\sum_{l>j} a_{kl}, \qquad D_{ij} = \sum_{k>i}\sum_{l<j} a_{kl} + \sum_{k<i}\sum_{l>j} a_{kl}.\]

令 \(P = \sum_{ij} a_{ij} A_{ij}\) 、 \(Q = \sum_{ij} a_{ij} D_{ij}\) 、 \(w_r = F^2 - \sum_i r_i^2\) ，实际分段对估计分段的 Somers' D 为

\[D(C|R) = \frac{P - Q}{w_r}, \qquad \mathrm{gAUC} = \frac{D(C|R) + 1}{2},\]

gAUC 的标准误为

\[s = \frac{1}{w_r^2} \sqrt{\sum_{ij} a_{ij} \left(w_r d_{ij} - (P - Q)(F - r_i)\right)^2}, \qquad d_{ij} = A_{ij} - D_{ij},\]

即 Brown 和 Benedetti [2] 给出的 Somers' D 渐近标准误的一半，因为 gAUC 等于 Somers' D 的一半加二分之一。因此 somers_d 的标准误为 \(2 s\) 。区间为 \(\mathrm{gAUC} \pm z s\) ，截断到 0 与 1 之间，其中 \(z\) 是标准正态分布在 \((1 + \mathrm{level}) / 2\) 处的分位数；Somers' D 的区间上下限由此换算得到。

当 gAUC 接近 0 或 1，或者表中的观测很少时，正态近似较差。对于退化的表，即所有实际值都落在一个分段中，或者排序完全正确或完全相反时，标准误为 0，区间收缩为估计值本身： generalized_auc([1, 2, 3, 1], [5, 5, 5, 5]) 给出 0.5 的 gAUC、0 的标准误和区间 [0.5, 0.5]。

估计分段相同的观测对不计入，所以 gAUC 为 1 表示估计分段不同的每一对观测，其实际分段的顺序都与估计一致。AUC 则排除目标相同的观测对，因此把二分类目标放在行上的 generalized_auc(target, score) 给出评分的 AUC，不过其标准误不同于 roc_auc_interval 的 DeLong 标准误。列联表的每个单元格对应一对不同的取值，因此要先把连续值切分成分段，就像欧洲央行使用十二个 LGD 分段那样。

使用权重时，表中每个单元格是权重之和，因此标准误把总权重视为观测数。

参考文献

[1]

European Central Bank, "Instructions for reporting the validation results of internal models: IRB Pillar I models for credit risk", February 2019, sections 2.6.3.1 and 3.2.

[2]

M. B. Brown and J. K. Benedetti, "Sampling behavior of tests for correlation in two-way contingency tables", Journal of the American Statistical Association, 72(358), pp. 309-315, 1977.

示例

>>> from kivi.metrics import generalized_auc
>>> estimated = [1, 1, 1, 2, 2, 2, 3, 3]
>>> realized = [1, 1, 2, 1, 2, 3, 2, 3]
>>> generalized_auc(estimated, realized).round(4)
           estimate      se   lower   upper
statistic
gauc         0.7619  0.0902  0.5852  0.9386
somers_d     0.5238  0.1803  0.1704  0.8772

kivi.metrics.expected_maximum_profit(score, target, *, no_loss_share=0.55, full_loss_share=0.1, roi=0.2644, weights=None)#

计算信用评分的期望最大利润。

Verbraken、Bravo、Weber 和 Baesens [1] 提出的期望最大利润（expected maximum profit，EMP）是评分最优截断点下每位申请人的利润，并对不确定的违约损失取平均。拒绝一个违约者，可以省下它本会损失的那部分贷款；拒绝一个好客户，则放弃这笔贷款的回报，因此最优截断点取决于这项损失。

评分在前、目标在后，与 kivi.woe.woe_table 相同。

参数:
scorearray_like

有限的数值评分，风险越高，评分越高，例如 PD。评分卡分数越高表示风险越低，因此须取负后再传入。

targetarray_like

二分类标签，1 表示违约。两个类别都必须出现。如果 score 和 target 都是 pandas Series，二者的索引必须完全相同；否则按位置对应。

no_loss_sharefloat，默认 0.55

违约者没有任何损失的概率，即 [1] 中的 \(p_0\) 。必须介于 0 和 1 之间。

full_loss_sharefloat，默认 0.1

违约者损失全部贷款的概率，即 [1] 中的 \(p_1\) 。必须介于 0 和 1 之间，且与 no_loss_share 之和不超过 1。其余的概率均匀分布在从 0 到全部贷款之间的损失上。

roifloat，默认 0.2644

好客户贷款的投资回报率，以贷款金额的比例表示：拒绝一个好客户所放弃的利润。必须是有限的正数。

weightsarray_like，可选

每个观测的非负频数权重，例如其抽样比例的倒数，对应方式与 target 相同。每个计数都变为权重之和，因此整数权重与重复相应行的结果相同。

返回值:
pandas.Series

索引名为 statistic 的两个值： emp 是每位申请人的期望最大利润，以贷款金额的比例表示； rejected_share 是最优截断点拒绝的申请人比例，按同样的方式取平均。

异常:
ValueError

如果输入为空或不是一维的，索引或长度不一致，target 含有 0 和 1 以外的标签或缺少其中之一，或 score 不是实数数值或含有缺失值、无穷值。此外，如果 no_loss_share 或 full_loss_share 不是 0 到 1 之间的数或二者之和超过 1， roi 不是有限的正数，或 weights 不是数值、没有为每个观测给出一个有限非负的权重、索引与 score 不同，或使某一类没有权重，也会引发此异常。

参见

kivi.strategy.cutoff_table

每个截断点下通过客群的收益、损失和利润。

roc_table

ROC 曲线，其凸包上有最优截断点。

roc_auc

排序质量，对每个截断点一视同仁。

说明

设 \(\pi_d\) 为违约者的比例， \(\pi_g = 1 - \pi_d\) 为好客户的比例， \(F_d(t)\) 和 \(F_g(t)\) 为违约者和好客户中评分高于截断点 \(t\) 而被拒绝的比例。违约者损失其贷款的 \(\lambda\) 部分，好贷款赚取回报 \(\mathrm{ROI}\) ，二者都以贷款金额的比例表示。与全部通过相比，该截断点下每位申请人的利润为

\[P(t; \lambda) = \lambda \, \pi_d F_d(t) - \mathrm{ROI} \, \pi_g F_g(t).\]

损失 \(\lambda\) 以概率 \(p_0\) 为 0，以概率 \(p_1\) 为 1，其余情况下在 0 和 1 之间均匀分布，密度为 \(\alpha = 1 - p_0 - p_1\) 。EMP 按这一分布 \(H\) 对每个损失下最优截断点的利润取平均，

\[\mathrm{EMP} = \int_0^1 \max_t P(t; \lambda) \, dH(\lambda),\]

而 rejected_share 以同样的方式对最优截断点拒绝的比例 \(\pi_d F_d + \pi_g F_g\) 取平均。

最优截断点是 ROC 曲线上凸包的一个顶点；ROC 曲线由相邻的不同评分之间各截断点的点 \((F_g, F_d)\) 组成，因此相同的评分总是一起被拒绝。设 \((F_{g,i}, F_{d,i})\) 为从 (0, 0) 到 (1, 1) 的各个顶点，其中 \(i = 0, \ldots, m\) 。损失介于 \(\lambda_i\) 和 \(\lambda_{i+1}\) 之间时，顶点 \(i\) 是最优截断点，其中 \(\lambda_0 = 0\) ，且

\[\lambda_i = \frac{\mathrm{ROI} \, \pi_g \, (F_{g,i} - F_{g,i-1})} {\pi_d \, (F_{d,i} - F_{d,i-1})},\]

对没有违约者的线段，它为无穷大。设 \(k\) 为满足 \(\lambda_k < 1\) 的最后一个顶点，并把 \(\lambda_{k+1}\) 替换为 1，则

\[\mathrm{EMP} = \alpha \sum_{i=0}^{k} \left[ \pi_d F_{d,i} \frac{\lambda_{i+1}^2 - \lambda_i^2}{2} - \mathrm{ROI} \, \pi_g F_{g,i} (\lambda_{i+1} - \lambda_i) \right] + p_1 \left[ \pi_d F_{d,k} - \mathrm{ROI} \, \pi_g F_{g,k} \right],\]

rejected_share 则把每个利润换成同一顶点处被拒绝的比例 \(\pi_d F_{d,i} + \pi_g F_{g,i}\) ，在同样的损失区间上积分。违约者没有损失时，最优决策是谁也不拒绝，因此点质量 \(p_0\) 对两个值都没有贡献，EMP 也不会为负。[1] 的式 15 在顶点 \(k + 1\) 处计算 \(p_1\) 项；而全部损失时的最优截断点是顶点 \(k\) ，这与 R 包 EMP [2] 和 Python 包 empulse [3] 相同，本函数复现了它们的结果。

no_loss_share 、 full_loss_share 和 roi 的默认值取自这两个包，0.2644 的回报率来自 [1] 中的示例。两个包都与 kivi 一样，以 1 表示违约，评分随风险升高而增大。EMP 与 AUC 一样只取决于评分的顺序，但按各截断点赚取的利润为其加权。

参考文献

T. Verbraken, C. Bravo, R. Weber and B. Baesens, "Development and application of consumer credit scoring models using profit-based classification measures", European Journal of Operational Research, 238(2), pp. 505-513, 2014.

[2]

R package EMP, version 2.0.6, function empCreditScoring, 2025.

[3]
