图表#

用 matplotlib 绘制其他模块的结果表，每种表对应一个函数，例如 WOE 表用 woe_chart() ，ROC 表用 roc_chart() ，监控报告用 monitoring_chart() ，生存表用 survival_chart() ，含利润的截断点表用 profit_chart() 。每个函数在 ax 传入的 Axes 上作图，未传入时新建一个图形，并返回所用的 Axes。matplotlib 是可选依赖，用 pip install "kivi[plot]" 安装。

基于内置数据的示例见 图表 。

woe_chart(table, *[, line, ax])

绘制每个分组的样本占比，以及其事件率或 WOE。

correlation_chart(matrix, *[, ax])

把相关系数矩阵绘制成热力图，并在每个单元格中标出数值。

roc_chart(table, *[, ks, label, ax])

绘制 ROC 曲线，并标出两个比率之间的最大差距。

precision_recall_chart(table, *[, label, ax])

绘制评分每个阈值下的精确率相对于召回率的变化。

gains_chart(table, *[, ks, label, ax])

按评分段绘制事件与非事件的累计占比。

distribution_chart(table, *[, ax])

并排绘制每个分组占全部非事件和占全部事件的比例。

calibration_chart(table, *[, label, ax])

绘制每个分组的观测事件率与其平均预测 PD 的对比。

cutoff_chart(table, *[, label, ax])

绘制通过客群的事件率随通过率的变化。

psi_chart(table, *[, ax])

并排绘制每个分组的基准占比和当前占比。

monitoring_chart(table, *[, column, kind, ...])

逐期绘制监控报告中的一列。

vintage_chart(table, *[, ax])

为每个批次绘制一条按账龄变化的累计坏账率曲线。

survival_chart(table, *[, column, label, ax])

把生存表的累计 PD 或生存曲线绘制成阶梯线。

transition_chart(table, *[, ax])

把迁移矩阵绘制成热力图，并在每个单元格中标出数值。

rule_set_chart(table, *[, ax])

绘制每条规则拒绝的客群占比，以及该规则之后剩余的通过率。

profit_chart(table, *[, label, ax])

绘制利润随通过率的变化，并标出利润最高的截断点。

lgd_chart(table, *[, ax])

绘制每个分组的平均 LGD，以及零损失和全额损失的占比。
kivi.plotting.woe_chart(table, *, line='event_rate', ax=None)#

绘制每个分组的样本占比，以及其事件率或 WOE。

柱形在左侧 y 轴上表示 total_share ，即每个分组在样本中的占比；折线在右侧的第二个 y 轴上表示 event_rate 或 woe 。这是本模块中唯一带有两个 y 轴的图表，因此也是唯一返回两个 Axes 的图表。各分组保持表中的顺序，图例给出整张表的 IV。

参数:
tablepandas.DataFrame

由 kivi.woe.woe_table 得到的表，或 kivi.spec.BinningSpec 中的某张表。需要包含 total_share 、 iv 列以及 line 指定的列。

line{'event_rate', 'woe'}，默认 'event_rate'

绘制为折线的列。

axmatplotlib.axes.Axes，可选

绘制柱形的 Axes。未给出时新建一个图形。

返回值:
barsmatplotlib.axes.Axes

绘制柱形的 Axes；给出 ax 时即为 ax 。

linematplotlib.axes.Axes

绘制折线的 Axes，是与 bars 共用 x 轴的孪生坐标轴。

异常:
ImportError

如果未安装 matplotlib。

ValueError

如果 table 不是 DataFrame、缺少所需的列或没有任何行，所需的列不是数值， line 既不是 'event_rate' 也不是 'woe' ，或者 ax 不是 matplotlib 的 Axes。

参见

kivi.woe.woe_table

此图表所绘制的表。

psi_chart

比较两个样本在相同分组中的占比。

说明

刻度标签是索引中的分组标签，缺失值分组标为 NaN 。要按其他顺序绘制各分组，请先对表排序，例如使用 table.sort_index() 或 table.sort_values("woe") 。

每个 y 轴的标签使用其所示内容的颜色，WOE 为零的点线属于右侧坐标轴。两个坐标轴都在顶部为图例留出空间，使图例不遮挡任何柱形和点。

示例

>>> import pandas as pd
>>> from kivi.plotting import woe_chart
>>> from kivi.woe import woe_table
>>> groups = pd.Series(["a", "b", "b", "c", "c", "c"])
>>> target = pd.Series([1, 0, 1, 0, 0, 1])
>>> bars, line = woe_chart(woe_table(groups, target))
>>> [label.get_text() for label in bars.get_xticklabels()]
['a', 'b', 'c']
>>> line.get_ylabel()
'event_rate'
kivi.plotting.correlation_chart(matrix, *, ax=None)#

把相关系数矩阵绘制成热力图，并在每个单元格中标出数值。

正相关显示为蓝色，负相关显示为琥珀色，越接近 1 或 -1 颜色越深，这样在拟合模型之前就能看出哪些变量对携带相同的信息。

参数:
matrixpandas.DataFrame

相关系数方阵，其索引和列具有相同的标签且顺序相同，例如 WOE 编码后的候选变量 X 的 X.corr() 或 X.corr(method="spearman") 。

axmatplotlib.axes.Axes，可选

用于作图的 Axes。未给出时新建一个图形，其尺寸随变量个数而定。

返回值:
matplotlib.axes.Axes

所绘制的 Axes；给出 ax 时即为 ax 。

异常:
ImportError

如果未安装 matplotlib。

ValueError

如果 matrix 不是 DataFrame、没有任何行、索引与列的标签不同、有非数值的列或有超出 [-1, 1] 的值（例如协方差），或者 ax 不是 matplotlib 的 Axes。

参见

kivi.selection.correlation_filter

对每一对高度相关的变量，剔除其中一个。

kivi.selection.vif

每个变量的方差膨胀因子。

说明

无论取值如何，颜色都从 -1 覆盖到 1；缺失值（例如常数列的相关系数）所在的单元格留空。热力图即 ax.images[0] ，因此 ax.figure.colorbar(ax.images[0], ax=ax) 可以加上颜色条。

示例

>>> import pandas as pd
>>> from kivi.plotting import correlation_chart
>>> X = pd.DataFrame({"a": [1, 2, 3, 4], "b": [2, 1, 4, 3], "c": [4, 3, 2, 1]})
>>> ax = correlation_chart(X.corr())
>>> [label.get_text() for label in ax.get_yticklabels()]
['a', 'b', 'c']
>>> ax.texts[1].get_text()
'0.60'

用于作图的 Axes。未给出时新建一个图形。

返回值:
matplotlib.axes.Axes

所绘制的 Axes；给出 ax 时即为 ax 。

异常:
ImportError

如果未安装 matplotlib。

ValueError

如果 table 不是 DataFrame、缺少所需的列或没有任何行，所需的列不是数值， ks 不是 True 或 False，或者 ax 不是 matplotlib 的 Axes。

参见

kivi.metrics.roc_table

此图表所绘制的表。

kivi.metrics.roc_auc

曲线下面积。

gains_chart

以样本占比为横轴展示同样的区分能力。

说明

曲线使用 Axes 颜色循环中的下一种颜色，因此在同一个 ax 上绘制多个评分的 ROC 曲线时，可以通过颜色和 label 区分它们。KS 线段及其数值与所属曲线颜色相同。

示例

>>> from kivi.metrics import roc_table
>>> from kivi.plotting import roc_chart

>>> ax = roc_chart(table)

kivi.plotting.precision_recall_chart(table, *, label=None, ax=None)#

绘制评分每个阈值下的精确率相对于召回率的变化。

从最高的评分开始向下标记观测，曲线以阶梯的形式绘制 precision （被标记观测的事件率）相对于 true_positive_rate （被标记的事件占全部事件的比例，也称召回率）的变化，阶梯下的面积就是平均精确率。一条虚线标出样本的事件率，即随机排序评分的精确率。

参数:
tablepandas.DataFrame

由 kivi.metrics.roc_table 得到的表。需要包含 true_positive_rate 和 precision 列。

labelstr，可选

曲线在图例中的名称。只有当某条曲线带有标签时才绘制图例。

axmatplotlib.axes.Axes，可选

用于作图的 Axes。未给出时新建一个图形。

返回值:
matplotlib.axes.Axes

所绘制的 Axes；给出 ax 时即为 ax 。

异常:
ImportError

如果未安装 matplotlib。

ValueError

如果 table 不是 DataFrame、缺少所需的列或没有任何行，所需的列不是数值，没有一行有精确率，或者 ax 不是 matplotlib 的 Axes。

参见

kivi.metrics.roc_table

此图表所绘制的表。

roc_chart

真正例率相对于假正例率的变化。

kivi.strategy.confusion_table

所选截断点上的精确率和召回率。

说明

ROC 表的第一行位于阈值 inf ，不标记任何观测，没有精确率。曲线从召回率 0 开始，依次经过其余各行：从一行的召回率到下一行的召回率，曲线保持在下一行的精确率上。用直线连接各行会高估它们之间的精确率 [1] 。记第 n 行的召回率和精确率为 \(R_n\) 和 \(P_n\) ，并令 \(R_0 = 0\) ，则阶梯下的面积就是平均精确率

\[\mathrm{AP} = \sum_n (R_n - R_{n-1})\, P_n.\]

最后一行标记全部观测，其精确率就是事件率：曲线终止于虚线上，虚线左端标有该事件率。

曲线使用 Axes 颜色循环中的下一种颜色，因此在同一个 ax 上绘制多个评分的曲线时，可以通过颜色和 label 区分它们。虚线为灰色，与 roc_chart 的对角线相同，并且每个所示的事件率只画一次，因此同一样本的多个评分共用一条虚线，两个样本则各有一条。

参考文献

[1]

J. Davis and M. Goadrich, "The Relationship Between Precision-Recall and ROC Curves", Proceedings of the 23rd International Conference on Machine Learning, 233-240, 2006.

示例

>>> from kivi.metrics import roc_table
>>> from kivi.plotting import precision_recall_chart
>>> table = roc_table([0.1, 0.4, 0.35, 0.8], [0, 0, 1, 1])
>>> ax = precision_recall_chart(table)
>>> ax.get_xlabel(), ax.get_ylabel()
('true_positive_rate', 'precision')
>>> ax.texts[0].get_text()
'event_rate = 0.5'
kivi.plotting.gains_chart(table, *, ks=True, label=None, ax=None)#

按评分段绘制事件与非事件的累计占比。

从评分最高的评分段开始逐段向下审视，两条曲线分别表示已覆盖的事件和非事件占全部事件和全部非事件的比例，横轴是已审视的样本占比 cum_total_share 。设置 ks 时，一条竖直线段标出 ks （两条曲线之间的差距）最大的评分段。

参数:
tablepandas.DataFrame

由 kivi.metrics.gains_table 得到的表，评分最高的评分段在前。需要包含 cum_total_share 、 cum_event_share 、 cum_non_event_share 和 ks 列。

ksbool，默认 True

是否标出最大的 ks 。

labelstr，可选

评分的名称，附加在两条曲线的图例名称之后，例如 cum_event_share (label) 。

axmatplotlib.axes.Axes，可选

用于作图的 Axes。未给出时新建一个图形。

返回值:
matplotlib.axes.Axes

所绘制的 Axes；给出 ax 时即为 ax 。

异常:
ImportError

如果未安装 matplotlib。

ValueError

如果 table 不是 DataFrame、缺少所需的列或没有任何行，所需的列不是数值， ks 不是 True 或 False，或者 ax 不是 matplotlib 的 Axes。

参见

kivi.metrics.gains_table

此图表所绘制的表。

roc_chart

在所有阈值上展示同样的区分能力。

说明

两条曲线都从原点出发（此时尚未审视任何评分段），每个评分段增加一个点。对角线是随机排序评分的 cum_event_share 。

cum_event_share 曲线为实线， cum_non_event_share 曲线为虚线，两者都使用 Axes 颜色循环中的下一种颜色，因此在同一个 ax 上绘制多个评分的增益曲线时，可以通过颜色和 label 区分它们。KS 线段及其数值也使用该颜色。图例放在遮挡点最少的位置；有多个评分时，每个评分在图例中占两项，可以用 ax.legend(loc=...) 移动图例。

示例

>>> from kivi.metrics import gains_table
>>> from kivi.plotting import gains_chart
>>> score = [1, 2, 3, 3, 4, 5, 1, 2]
>>> target = [0, 0, 1, 0, 1, 1, 0, 0]
>>> ax = gains_chart(gains_table(score, target, bins=3))
>>> ax.get_xlabel()
'cum_total_share'
>>> ax.texts[0].get_text()
'ks = 0.800'
kivi.plotting.distribution_chart(table, *, ax=None)#

并排绘制每个分组占全部非事件和占全部事件的比例。

表中的每一行，例如增益表的一个评分段或 WOE 表的一个分箱，对应一对柱形：该行占表中全部非事件的比例和占全部事件的比例，由原始的 non_event 和 event 计数算出。两个分布相距越远，评分或变量区分两类的能力越强。

参数:
tablepandas.DataFrame

由 kivi.metrics.gains_table 或 kivi.woe.woe_table 得到的表，或 kivi.spec.BinningSpec 中的某张表。需要包含 non_event 和 event 列。

axmatplotlib.axes.Axes，可选

用于作图的 Axes。未给出时新建一个图形。

返回值:
matplotlib.axes.Axes

所绘制的 Axes；给出 ax 时即为 ax 。

异常:
ImportError

如果未安装 matplotlib。

ValueError

如果 table 不是 DataFrame、缺少所需的列或没有任何行，所需的列不是数值，某个计数为负数或不是有限值，表中没有事件或没有非事件，或者 ax 不是 matplotlib 的 Axes。

参见

kivi.metrics.gains_table

评分段，最高的评分段在前。

kivi.woe.woe_table

变量的分箱或分组。

gains_chart

相同评分段的累计占比。

psi_chart

两个样本在相同分组中的占比。

说明

柱形保持表的行顺序（增益表最高的评分段在前），并保留其中的空行，因此用相同边界分箱的两个样本的图表可以对齐。占比不做平滑，因此对于没有事件或没有非事件的分组，它们与 WOE 表的 event_share 和 non_event_share 列不同，后者给空单元格赋予平滑值。刻度标签是索引中的分组标签，缺失值分组标为 NaN 。

非事件为蓝色，事件为红色。y 轴在顶部为图例留出空间，使图例不遮挡任何柱形。

示例

>>> from kivi.metrics import gains_table
>>> from kivi.plotting import distribution_chart
>>> score = [1, 2, 3, 3, 4, 5, 1, 2]
>>> target = [0, 0, 1, 0, 1, 1, 0, 0]
>>> ax = distribution_chart(gains_table(score, target, bins=3))
>>> [label.get_text() for label in ax.get_xticklabels()]
['(3.0, inf]', '(2.0, 3.0]', '(-inf, 2.0]']
>>> [f"{bar.get_height():.2f}" for bar in ax.patches]
['0.00', '0.20', '0.80', '0.67', '0.33', '0.00']

matplotlib.axes.Axes

所绘制的 Axes；给出 ax 时即为 ax 。

异常:
ImportError

如果未安装 matplotlib。

ValueError

如果 table 不是 DataFrame、缺少所需的列或没有任何行，所需的列不是数值，或者 ax 不是 matplotlib 的 Axes。

参见

kivi.calibration.calibration_table

此图表所绘制的表。

kivi.calibration.binomial_test

检验每个等级的违约率。

说明

两个坐标轴都从 0 延伸到略高于 ax 上所绘的最大比率，使对角线保持 45 度。各点按表中的顺序连接，并使用 Axes 颜色循环中的下一种颜色，因此可以在同一个 ax 上比较多个模型的 PD，或同一组 PD 校正前后的结果。

kivi.plotting.cutoff_chart(table, *, label=None, ax=None)#

matplotlib.axes.Axes

说明
