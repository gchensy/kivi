评分卡#

把基于 WOE 的逻辑回归转换为分值。 score_scaling() 、 pd_to_score() 和 score_to_pd() 设定并应用刻度， points_table() 和 woe_to_points() 给出分值， reason_codes() 列出使评分降低最多的变量。 ScorecardSpec 把分箱、分值、刻度、校准和主标尺放在一起，用它们为任意样本评分、校准和分级，并保存为带版本号的 JSON。

基于内置数据构建的评分卡见 评分卡 。

返回把对数几率转换为分数的因子（factor）和偏移量（offset）。

把事件概率转换为评分卡分数。

score_to_pd(score, *, pdo, base_score, base_odds)

把评分卡分数转换为事件概率。

points_table(tables, coefficients, ...)

把基于 WOE 的逻辑回归转换为每个分组的分值。

woe_to_points(woe, coefficients, intercept, ...)

根据 WOE 值给出每个申请人在各变量上的分值。

完整的评分卡，用同样的方式为任意样本评分、校准和分级。
kivi.scorecard.score_scaling(*, pdo, base_score, base_odds)#

返回把对数几率转换为分数的因子（factor）和偏移量（offset）。

评分卡分数与好坏比（good:bad odds）的对数呈线性关系。几率为 base_odds 时分数等于 base_score ，几率每翻一倍，分数增加 pdo 分。

参数:
pdofloat

几率翻倍所需增加的分数（PDO），必须为正数。

base_scorefloat

基准几率对应的分数。

base_oddsfloat

基准分数对应的好坏比，例如 50 表示每个事件对应 50 个非事件。必须为正数。

返回值:
factorfloat

对数几率每增加一个单位对应的分数，即 pdo / ln 2 。

offsetfloat

几率为 1:1 时的分数，即 base_score - factor * ln(base_odds) 。

异常:
ValueError

如果某个参数不是有限数值，或者 pdo 或 base_odds 不是正数。

参见

pd_to_score

把事件概率转换为分数。

score_to_pd

把分数转换为事件概率。

说明

对事件概率 \(p\) ，记几率 \(o = (1 - p) / p\) ，则

\[ \begin{align}\begin{aligned}\mathrm{score} = \mathrm{offset} + \mathrm{factor} \cdot \ln o,\\\mathrm{factor} = \frac{\mathrm{pdo}}{\ln 2}, \qquad \mathrm{offset} = \mathrm{base\_score} - \mathrm{factor} \cdot \ln \mathrm{base\_odds}.\end{aligned}\end{align} \]

示例

>>> from kivi.scorecard import score_scaling
>>> factor, offset = score_scaling(pdo=20, base_score=600, base_odds=50)
>>> print(f"factor = {factor:.4f}, offset = {offset:.4f}")
factor = 28.8539, offset = 487.1229
kivi.scorecard.pd_to_score(probability, *, pdo, base_score, base_odds)#

把事件概率转换为评分卡分数。

事件（例如违约）的概率越低，分数越高。刻度由 pdo 、 base_score 和 base_odds 决定，与 score_scaling 相同。

参数:
probabilityarray_like

严格介于 0 与 1 之间的事件概率。缺失值对应的分数也为缺失。

pdofloat

几率翻倍所需增加的分数（PDO），必须为正数。

base_scorefloat

基准几率对应的分数。

base_oddsfloat

基准分数对应的好坏比，必须为正数。

返回值:
float、pandas.Series 或 numpy.ndarray

分数，形状与 probability 相同。输入为 Series 时返回 Series，索引和名称保持不变；输入为标量时返回 float。

异常:
ValueError

如果 probability 不是实数数值或含有开区间 (0, 1) 以外的值，或者刻度参数无效。

参见

score_to_pd

反向转换。

score_scaling

刻度的因子和偏移量。

说明

分数为 offset + factor * ln((1 - probability) / probability) 。概率恰好为 0 或 1 时没有有限的分数，会引发错误；哪些分数对应的概率会舍入为 1，参见 score_to_pd 。

示例

>>> from kivi.scorecard import pd_to_score
>>> scale = dict(pdo=20, base_score=600, base_odds=50)
>>> pd_to_score([1 / 51, 1 / 101, 0.1], **scale).round(2)
array([600.  , 620.  , 550.52])
kivi.scorecard.score_to_pd(score, *, pdo, base_score, base_odds)#

把评分卡分数转换为事件概率。

在相同刻度下，这是 pd_to_score 的逆运算，给出每个分数所隐含的事件概率。

参数:
scorearray_like

分数。缺失值对应的概率也为缺失。

pdofloat

几率翻倍所需增加的分数（PDO），必须为正数。

base_scorefloat

基准几率对应的分数。

base_oddsfloat

基准分数对应的好坏比，必须为正数。

返回值:
float、pandas.Series 或 numpy.ndarray

事件概率，形状与 score 相同。输入为 Series 时返回 Series，索引和名称保持不变；输入为标量时返回 float。

异常:
ValueError

如果 score 不是实数数值，或者刻度参数无效。

参见

pd_to_score

反向转换。

score_scaling

刻度的因子和偏移量。

说明

概率为 1 / (1 + exp((score - offset) / factor)) ，计算方式保证极端分数也不会溢出。在双精度下，比偏移量低约 36.7 * factor 以上的分数（示例刻度下为 -572）对应的概率会舍入为 1，而 pd_to_score 不接受这样的概率。在实际使用的刻度上不会出现这么低的分数。

示例

>>> from kivi.scorecard import score_to_pd
>>> scale = dict(pdo=20, base_score=600, base_odds=50)
>>> score_to_pd([580, 600, 620], **scale).round(5)
array([0.03846, 0.01961, 0.0099 ])
kivi.scorecard.points_table(tables, coefficients, intercept, *, pdo, base_score, base_odds)#

把基于 WOE 的逻辑回归转换为每个分组的分值。

申请人在各变量上所属分组的分值（每个变量一个）之和，等于 pd_to_score 对模型概率给出的分数。截距平均分摊到各个变量。

参数:
tablesmapping

每个变量对应其 kivi.woe.woe_table 结果，或以分组为索引的 WOE 值 Series。没有系数的变量的表会被忽略。

coefficientsmapping 或 pandas.Series

事件概率模型中各变量 WOE 的逻辑回归系数。结果各行按此顺序排列。

interceptfloat

同一模型的截距。

pdofloat

几率翻倍所需增加的分数（PDO），必须为正数。

base_scorefloat

基准几率对应的分数。

base_oddsfloat

基准分数对应的好坏比，必须为正数。

返回值:
pandas.DataFrame

每个变量的每个分组一行，以 variable 为索引，列出分组标签 bin 以及该组的 woe 和 points 。用 table.loc[[variable]] 选出某个变量的各行。

异常:
ValueError

如果 tables 不是映射或缺少 coefficients 中的某个变量、某张表没有 woe 列、有重复分组或含有非有限的 WOE 值、系数为空、重复、不是有限数值或包含截距，或者刻度参数无效。

参见

woe_to_points

每个申请人的分值。

reason_codes

让申请人失分最多的变量。

kivi.woe.woe_table

拟合每个分组的 WOE。

说明

kivi 的 WOE 为 \(\ln(p_i / q_i)\) ，其中 \(p_i\) 和 \(q_i\) 分别为事件占比和非事件占比，模型为 \(\ln \frac{\mathrm{PD}}{1 - \mathrm{PD}} = \beta_0 + \sum_j \beta_j \mathrm{WOE}_j\) 。WOE 越高表示风险越高；系数为正时，分值越低。共有 \(m\) 个变量时，变量 \(j\) 的第 \(i\) 组得到

\[\mathrm{points}_{ij} = \frac{\mathrm{offset} - \mathrm{factor} \cdot \beta_0}{m} - \mathrm{factor} \cdot \beta_j \, \mathrm{WOE}_{ij},\]

其中因子和偏移量来自 score_scaling 。每个变量分摊相同份额的截距和偏移量，因此同一变量各分组的分值只在 WOE 项上有差别。

分组标签放在列中而不是索引层级中，因此不同变量中比较结果相等的标签（例如 True 和 1 ）仍保留各自的取值。

参考文献

[1]

N. Siddiqi, "Credit Risk Scorecards: Developing and Implementing Intelligent Credit Scoring", Wiley, 2006.

示例

>>> import pandas as pd
>>> from kivi.scorecard import points_table
>>> tables = {
...     "housing": pd.Series({"no": -0.4, "yes": 0.3}),
...     "contact": pd.Series({"cellular": -0.2, "unknown": 0.6}),
... }
>>> coefficients = {"housing": 0.8, "contact": 0.5}
>>> points_table(tables, coefficients, -2.0, pdo=20, base_score=600, base_odds=50).round(2)
               bin  woe  points
variable
housing         no -0.4  281.65
housing        yes  0.3  265.49
contact   cellular -0.2  275.30
contact    unknown  0.6  263.76
kivi.scorecard.woe_to_points(woe, coefficients, intercept, *, pdo, base_score, base_odds)#

根据 WOE 值给出每个申请人在各变量上的分值。

对相同的模型和刻度，这些分值与 points_table 一致。每行之和即为分数，等于 pd_to_score 对模型概率给出的结果。

参数:
woepandas.DataFrame 或 mapping

WOE 值，每个变量一列，例如对每个变量调用 kivi.woe.woe_transform 的结果。没有系数的列会被忽略。映射中的 Series 必须具有相同的索引；其他值按位置匹配。

coefficientsmapping 或 pandas.Series

事件概率模型中各变量 WOE 的逻辑回归系数。结果各列按此顺序排列。

interceptfloat

同一模型的截距。

pdofloat

几率翻倍所需增加的分数（PDO），必须为正数。

base_scorefloat

基准几率对应的分数。

base_oddsfloat

基准分数对应的好坏比，必须为正数。

返回值:
pandas.DataFrame

分值，索引与 woe 相同，每个变量一列。

异常:
ValueError

如果 woe 不是 DataFrame 或映射、缺少或重复 coefficients 中的某个变量、含有非有限值或是由索引不同的 Series 组成的映射、系数为空、重复、不是有限值或包含截距，或者刻度参数无效。

参见

points_table

每个分组的分值。

reason_codes

让申请人失分最多的变量。

说明

共有 \(m\) 个变量时，变量 \(j\) 的分值为 \((\mathrm{offset} - \mathrm{factor} \cdot \beta_0) / m - \mathrm{factor} \cdot \beta_j \, \mathrm{WOE}_j\) ，与 points_table 相同。两者的计算方式完全一致，因此取整后得到相同的分值。

示例

>>> import pandas as pd
>>> from kivi.scorecard import woe_to_points
>>> woe = pd.DataFrame({"housing": [-0.4, 0.3], "contact": [0.6, -0.2]})
>>> points = woe_to_points(
...     woe, {"housing": 0.8, "contact": 0.5}, -2.0, pdo=20, base_score=600, base_odds=50
... )
>>> points.round(2)
   housing  contact
0   281.65   263.76
1   265.49   275.30
>>> points.sum(axis=1).round(2).tolist()
[545.41, 540.79]
kivi.scorecard.reason_codes(points, table, *, top=3, atol=0.0001, unseen_points=None)#

列出让每个申请人失分最多的变量。

某个变量让申请人损失的分数，是该变量最佳分组的分值与申请人所在分组的分值之差。变量按损失从大到小列出；没有造成损失的变量不列出。

参数:
pointspandas.DataFrame

每个申请人的分值，即 woe_to_points 的返回结果。

tablepandas.DataFrame

相同模型和刻度下 points_table 的结果。

topint，默认 3

每个申请人列出的原因个数。

atolfloat，默认 1e-4

申请人分值与某个分组分值之间允许的最大差值（以分计），差值不超过它时即认为申请人属于该分组。它可以吸收舍入误差，例如以六位小数存储的 WOE 值带来的误差。

unseen_pointsfloat、mapping 或 pandas.Series，可选

kivi.woe.woe_transform 用 unseen 编码的分组中申请人的分值，可以是所有变量共用的一个值，也可以按变量给出。与任何分组都不匹配、但与其变量的 unseen_points 相差不超过 atol 的分值视为没有造成损失，因此该变量不会成为这些申请人的原因。这些分值就是对 unseen 所给 WOE 调用 woe_to_points 的结果；参见示例。默认情况下，每个分值都必须匹配某个分组。

返回值:
pandas.DataFrame

变量名位于 reason_1 到 reason_<top> 各列，索引与 points 相同。造成损失的变量较少的申请人，其余各列为 None。

异常:
ValueError

如果 points 不是 DataFrame、有重复的列或含有非有限值、 table 不是 points_table 的结果、缺少 points 中的某个变量或该变量的分值不是有限数、某些分值与其变量的所有分组以及其 unseen_points 相差都超过 atol 、 top 不是正整数、 atol 不是有限正数，或者 unseen_points 既不是有限数，也不是由有限数组成的映射或 Series。

参见

points_table

每个分组的分值。

woe_to_points

每个申请人的分值。

说明

每个申请人的分值会匹配到 table 中该变量最接近的分组，损失分数是 table 中各分组分值之差。相差不到约 atol 的损失视为相等，因此这些变量保持 points 中的列顺序；低于约 atol 的损失视为没有损失。

与任何分组都不匹配的分值（例如来自不同截距或刻度的分值，或 WOE 的舍入比 atol 允许的更粗）会引发错误，而不是给出针对错误分组的原因。默认情况下，开发样本中没有观测的分组（例如新类别）里的申请人也是如此：其 WOE 来自 kivi.woe.woe_transform 中的 unseen 。这个 WOE 是为该分组选定的取值，并不是关于申请人的证据，因此给出 unseen_points 时，这些分值不产生原因，而不是按它与最佳分组的差距给出原因。只有接近 unseen_points 的分值才会豁免；其他任何不匹配仍会引发错误。与某个分组相差不超过 atol 的分值会匹配到该分组，即使其 WOE 来自 unseen 。

示例

>>> import pandas as pd
>>> from kivi.scorecard import points_table, reason_codes, woe_to_points
>>> tables = {
...     "housing": pd.Series({"no": -0.4, "yes": 0.3}),
...     "contact": pd.Series({"cellular": -0.2, "unknown": 0.6}),
... }
>>> model = ({"housing": 0.8, "contact": 0.5}, -2.0)
>>> scale = dict(pdo=20, base_score=600, base_odds=50)
>>> table = points_table(tables, *model, **scale)
>>> woe = pd.DataFrame({"housing": [-0.4, 0.3, 0.3], "contact": [-0.2, 0.6, -0.2]})
>>> reason_codes(woe_to_points(woe, *model, **scale), table, top=2)
  reason_1 reason_2
0     None     None
1  housing  contact
2  housing     None

某个申请人的住房状况在开发样本中从未出现，因此用 woe_transform(..., unseen=0.0) 编码。WOE 为 0 时的分值，就是对一行全零调用 woe_to_points 的结果，每个变量都是相同的基础分值。把这些分值作为 unseen_points 传入后，housing 不在该申请人的原因之中：

>>> zero = woe_to_points(pd.DataFrame({"housing": [0.0], "contact": [0.0]}), *model, **scale)
>>> zero.round(2)
   housing  contact
0   272.42   272.42
>>> new = pd.DataFrame({"housing": [0.0], "contact": [0.6]})
>>> reason_codes(
...     woe_to_points(new, *model, **scale), table, top=2, unseen_points=zero.iloc[0]
... )
  reason_1 reason_2
0  contact     None
class kivi.scorecard.ScorecardSpec(binning, table, *, pdo, base_score, base_odds, unseen_points=None, calibration=None, scale=None, kivi_version=None)#

完整的评分卡，用同样的方式为任意样本评分、校准和分级。

评分卡方案包含生产环境评分所需的一切：对每个特征分组和编码的 kivi.spec.BinningSpec 、每个分组的分值、评分的刻度、所在分组在开发样本中没有出现的取值的分值，以及可选的概率校准和主标尺。 points 、 score 、 probability 、 grade 和 reason_codes 把它应用于任意样本， to_json 和 from_json 保存并加载它。可以用 from_model 由基于 WOE 值的逻辑回归构建方案，也可以用构造函数由分值经过取整或调整的分值表构建方案。

评分卡方案不可变。 table 和 scale 每次访问都返回新副本， unseen_points 和 calibration 是只读映射。若要修改某个字段，请使用 dataclasses.replace ，它会重新校验结果。

参数:
binningkivi.spec.BinningSpec

评分卡各特征的分箱和 WOE，不含其他列，例如 kivi.spec.BinningSpec.select 的结果。

tablepandas.DataFrame

每个分组的分值，即 points_table 对 binning 的各表返回的结果：索引为 variable ，列为 bin 、 woe 和 points 。分值可以取整或修改，但 bin 和 woe 必须逐行等于 binning 的分组和 WOE，变量按其列的顺序排列。

pdofloat

几率翻倍所需增加的分数（PDO），必须为正数。

base_scorefloat

基准几率对应的分数。

base_oddsfloat

基准分数对应的好坏比，必须为正数。

unseen_pointsmapping 或 pandas.Series，可选

所在分组不在其列的表中的取值的分值：只为 binning 中未见分组策略为 WOE 的列给出，且每个这样的列都要给出。策略为 "raise" 的列遇到这类取值会报错，策略指定某个分组的列则给这类取值该分组的分值。

calibrationmapping，可选

probability 的校准，取 {"kind": "shift", "shift": shift} 、 {"kind": "platt", "slope": slope, "intercept": intercept} 和 {"kind": "isotonic", "edges": edges, "probability": probability} 之一；见“说明”。默认的概率是刻度为评分给出的概率。

scalepandas.DataFrame，可选

grade 使用的主标尺，即 kivi.calibration.master_scale 返回的结果。

kivi_versionstr，可选

构建该方案的 kivi 版本。默认或为 None 时取已安装的版本。

属性:
FORMAT_VERSIONint

to_json 写出的 JSON 格式的版本，也是 from_json 能读取的最新版本。

异常:
ValueError

如果 binning 不是 kivi.spec.BinningSpec ；如果 table 不是 points_table 的结果，没有按 binning 的列顺序为其每一列的每个分组各给一行并带有 binning 的分组和 WOE，或含有不是有限数值的分值；如果刻度参数无效；如果 unseen_points 缺少某个未见分组策略为 WOE 的列、含有其他列，或含有不是有限数值的分值；如果 calibration 不是三种校准之一，或者其参数不是有限的数、斜率为负，或对 "isotonic" 而言，边界不是从 -inf 到 inf 、概率不在 0 到 1 之间或随评分上升；如果 scale 不是带有 lower 、 probability 和 upper 列、标签为字符串、整数、有限浮点数或布尔值的主标尺；或者如果 kivi_version 不是字符串。

参见

from_model

由逻辑回归构建方案。

points_table

每个分组的分值。

kivi.spec.BinningSpec

分箱方案，评分卡方案包含它。

说明

设 score_scaling 的因子和偏移量，评分 \(s\) 代表事件的对数几率

\[\ell = \frac{\mathrm{offset} - s}{\mathrm{factor}},\]

probability 直接由评分计算它，因此不会先把接近 0 或 1 的 PD 舍入。不校准时，概率为 \(\sigma(\ell) = 1 / (1 + e^{-\ell})\) ，即 score_to_pd 的结果。各种校准给出

  • "shift" ： \(\sigma(\ell + \Delta)\) ，其中平移量 \(\Delta\) 由 kivi.calibration.central_tendency_shift 对未校准的概率拟合得到；

  • "platt" ： \(\sigma(a \ell + b)\) ，其中斜率 \(a\) 和截距 \(b\) 由 kivi.calibration.platt_fit 或 kivi.calibration.quasi_moment_fit 对对数几率 \(\ell\) 拟合得到，与 kivi.calibration.platt_predict 给出的相同；

  • "isotonic" ：评分所在分段的概率，与 kivi.calibration.isotonic_predict 按 kivi.calibration.isotonic_fit 以 increasing=False 在评分上拟合的边界和概率给出的相同，因为评分越高风险越低。

方案保存的是分值而不是系数：分值表就是生产环境使用的评分卡，分值一旦取整，概率就由取整后的评分得出，与生产环境一致。 kivi.features.FeatureSpec 等特征定义不在其中，因为特征在评分卡评分之前由其他表计算；请把两个方案并列保存。

当 to_json 为两个评分卡方案给出相同的文本时，二者相等；文本中包含 kivi_version 。

reason_codes(frame, *, top=3, atol=0.0001)#

列出让样本每一行失分最多的列。

某一列给一行造成的失分，是该列最佳分组的分值与该行所在分组的分值之差；各列按失分从大到小排列，与模块函数 reason_codes 相同。在有 unseen_points 的列中，所在分组在开发样本中没有出现的取值不失分，即使这些分值等于某个分组的分值也是如此，因此该列不是它的原因。

以分计的容差：相差不到约 atol 的失分视为相等，并保持列的顺序；低于约 atol 的失分视为没有失分。
