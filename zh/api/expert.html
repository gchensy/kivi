专家评分卡#

像层次分析法（AHP）那样，根据两两比较确定专家评分卡中各因子的权重。 ahp_weights() 把比较矩阵转换为权重， ahp_consistency() 度量各项比较的一致程度， combine_weights() 把因子和子因子的权重合成为全局权重。

示例和一致性比率的解读见 专家评分卡 。

kivi.expert.ahp_weights(matrix, *, method='eigenvector', rtol=0.001)#

像层次分析法那样，根据两两比较矩阵确定各因子的权重。

矩阵的元素 \(a_{ij}\) 按 Saaty 标度（从 1 表示同等重要到 9 表示极端重要）表示因子 \(i\) 比因子 \(j\) 重要多少倍，反过来则取其倒数 \(a_{ji} = 1 / a_{ij}\) 。权重与矩阵的主特征向量或各行的几何平均数成正比，且总和为 1。

参数:
matrixpandas.DataFrame 或 array_like

两两比较的方阵，对角线为 1，元素互为倒数，即 \(a_{ij} a_{ji} = 1\) ，满足相对容差 rtol 。DataFrame 以其索引作为因子名称，索引必须与列相同；数组则把因子从 0 起编号。

method{"eigenvector", "geometric"}，默认 "eigenvector"

"eigenvector" 是 Saaty 的主特征向量法。 "geometric" 取每一行的几何平均数，对一致矩阵给出相同的权重，且无需计算特征值。

rtolfloat，默认 1e-3

检查对角线为 1、以及 \(a_{ij} a_{ji}\) 为 1 的相对容差。默认值可接受四舍五入到四位小数的倒数，例如用 0.3333 代替 1 / 3，或用 0.1429 代替 1 / 7；四舍五入到两位小数的元素，例如 0.14，需要更大的值，或者直接写成分数。必须为有限的非负数。矩阵按给定的值使用，因此不是精确倒数的元素会使权重发生与其偏差大致相同的变化。

返回值:
pandas.Series

权重，名为 weight ，以因子为索引，索引名为 factor 。权重均为正数，总和为 1。

异常:
ValueError

如果 matrix 不是由有限正数构成、对角线为 1 且元素互为倒数的方阵，DataFrame 的索引与列不一致、标签重复或构成 MultiIndex， method 不是这两个名称之一，或者 rtol 不是有限的非负数。

参见

ahp_consistency

检查矩阵中各项判断的一致程度。

combine_weights

为层次结构中的子因子确定权重。

说明

对一致矩阵， \(a_{ij} = w_i / w_j\) ，两种方法都给出 \(w\) 。否则，特征向量法求解 \(A w = \lambda_{\max} w\) ，几何法则取

\[w_i = \frac{\left(\prod_j a_{ij}\right)^{1/n}} {\sum_k \left(\prod_j a_{kj}\right)^{1/n}}.\]

对两个或三个因子，两种方法对任何互反矩阵都给出相同的权重；从四个因子起，若判断不一致，两者会略有差异。旧的 0.2.x AHP 类使用几何法。

示例

>>> import pandas as pd
>>> from kivi.expert import ahp_weights
>>> factors = ["sales", "margin", "leverage"]
>>> matrix = pd.DataFrame(
...     [[1, 2, 4], [1 / 2, 1, 2], [1 / 4, 1 / 2, 1]], index=factors, columns=factors
... )
>>> ahp_weights(matrix).round(4)
factor
sales       0.5714
margin      0.2857
leverage    0.1429
Name: weight, dtype: float64
kivi.expert.ahp_consistency(matrix, *, rtol=0.001)#

度量两两比较矩阵中各项判断的一致程度。

各项判断相互吻合时即为一致：如果因子 A 的重要性是 B 的 2 倍，B 又是 C 的 2 倍，那么 A 应是 C 的 4 倍。一致性比率把矩阵的不一致程度与随机判断的不一致程度相比。

参数:
matrixpandas.DataFrame 或 array_like

比较至多 15 个因子的方阵，要求与 ahp_weights 相同。

rtolfloat，默认 1e-3

检查对角线为 1、互为倒数的元素之积为 1 的相对容差，与 ahp_weights 相同。

返回值:
pandas.Series

统计量，以 lambda_max 、 ci 、 ri 和 cr 为索引，索引名为 statistic ：

  • lambda_max ，矩阵的主特征值，不小于因子数 \(n\) ；

  • ci ，一致性指标，判断一致时为零；

  • ri ， \(n\) 对应的 Saaty 随机一致性指标；

  • cr ，一致性比率 ci / ri 。

异常:
ValueError

如果 matrix 不是有效的比较矩阵，或者 rtol 不是有限的非负数（要求与 ahp_weights 相同），或者 matrix 比较的因子超过 15 个，即超过有随机一致性指标表的最大阶数。

参见

ahp_weights

该矩阵给出的权重。

说明

有 \(n\) 个因子时，

\[\mathrm{CI} = \frac{\lambda_{\max} - n}{n - 1}, \qquad \mathrm{CR} = \frac{\mathrm{CI}}{\mathrm{RI}}.\]

Saaty 建议，CR 高于 0.1 的判断应当复核，后来（1994 年）又把限值收紧为：三个因子 0.05，四个因子 0.08。这些只是经验法则而不是检验，CR 更大时函数也不会报错。一个或两个因子的矩阵必然一致，因此其 ci 、 ri 和 cr 均为 0。对互反矩阵 \(\lambda_{\max} \ge n\) ；若舍入使计算值低于 \(n\) ，则取 \(n\) 。

随机一致性指标是 Saaty 标度下随机互反矩阵的平均 CI。3 到 15 个因子的表是 K. Tone 的 The Analytic Hierarchy Process: Decision Making （日文，1986 年）中的表，这里取自 T. Obata 和 S. Shiraishi 在 arXiv:2607.07950 表 2 中的列出。Saaty 的著作中 12 个因子的数值印的是 1.48 而不是 1.53，一般认为这是印刷错误。旧的 0.2.x 类用几何平均权重下 \((A w)_i / w_i\) 的均值来估计 \(\lambda_{\max}\) ，在不超过三个因子时它等于精确值，并且使用了几乎相同的随机一致性指标。

示例

>>> import numpy as np
>>> from kivi.expert import ahp_consistency
>>> matrix = np.array([[1, 3, 5], [1 / 3, 1, 3], [1 / 5, 1 / 3, 1]])
>>> ahp_consistency(matrix).round(4)
statistic
lambda_max    3.0385
ci            0.0193
ri            0.5800
cr            0.0332
dtype: float64
kivi.expert.combine_weights(parent, children)#

把因子及其子因子的权重合成为全局权重。

在层次结构中，每个因子被拆分为若干子因子，子因子之间再相互比较权重。子因子的全局权重等于其所属因子的权重乘以它在该因子内的权重，因此所有子因子的全局权重之和仍为 1。

参数:
parentpandas.Series

各因子的权重，例如 ahp_weights 的结果。必须为有限的非负数，总和为 1，相对容差为 1e-6。

childrenmapping

对 parent 的每个因子，给出其子因子权重的 Series，以子因子标签为索引，例如 ahp_weights 的结果。每个 Series 的权重必须为有限的非负数且总和为 1，每个子因子只能出现一次。 parent 的每个因子都需要一个条目，且不允许有其他的键：没有子因子的因子对应只含一个标签、权重为 1 的 Series。

返回值:
pandas.Series

全局权重，名为 weight ，以 factor 和 sub_factor 为索引，先按 parent 的顺序，再按各因子的子因子顺序排列。

异常:
ValueError

如果 parent 不是 Series， children 不是由 Series 构成的映射，其键不是 parent 的因子，或者某组权重不是有限的非负数、总和不为 1。

参见

ahp_weights

为各因子及每个因子的子因子确定权重。

说明

该函数合并两层，即因子及其子因子。对于更多层的层次结构，请逐层合并：把去掉 factor 层的全局权重 weights.droplevel("factor") 作为下一次调用的 parent ，其结果则给出最后两层的名称。这要求不同因子的子因子名称互不相同，因为 parent 的标签必须互不重复。

示例

>>> import pandas as pd
>>> from kivi.expert import combine_weights
>>> parent = pd.Series({"finance": 0.75, "market": 0.25})
>>> children = {
...     "finance": pd.Series({"leverage": 0.6, "margin": 0.4}),
...     "market": pd.Series({"position": 1.0}),
... }
>>> combine_weights(parent, children)
factor   sub_factor
finance  leverage     0.45
         margin       0.30
market   position     0.25
Name: weight, dtype: float64
