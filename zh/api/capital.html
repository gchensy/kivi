监管资本#

按内部评级法计算信用风险敞口的监管资本。 asset_correlation() 和 capital_requirement() 计算巴塞尔框架和中国 2023 年资本规则的风险权重函数， conditional_pd() 、 systematic_factor() 和 vasicek_fit() 处理其背后的单因子模型， most_prudent_pd() 给出违约很少的组合的 PD 上界。

示例和两地的参数见 监管资本 。

asset_correlation(probability, *, asset_class)

计算内部评级法风险权重函数中的资产相关系数。

capital_requirement(probability, lgd, *, ...)

计算内部评级法的资本要求 K，以占敞口的比例表示。

conditional_pd(probability, *, correlation)

计算单因子模型在给定经济状态下的 PD。

systematic_factor(default_rate, probability, ...)

计算观察到的违约率所对应的系统因子。

vasicek_fit(default_rate)

由一段违约率序列估计长期 PD 和资产相关系数。

most_prudent_pd(event, total, *[, level, ...])

计算 Pluto 和 Tasche 的最审慎估计：每个等级 PD 的上界。
kivi.capital.asset_correlation(probability, *, asset_class, turnover=None, turnover_range=(5.0, 50.0), financial=False)#

计算内部评级法风险权重函数中的资产相关系数。

资产相关系数 \(R\) 是借款人资产的方差中由整体经济解释的比例。内部评级法按资产类别规定它；公司敞口和其他零售敞口的相关系数随 PD 上升而下降。

参数:
probabilityarray_like

违约概率，取值在 0 与 1 之间。缺失值得到缺失的相关系数。

asset_class{"corporate", "hvcre", "mortgage", "revolving", "other_retail"}

"corporate" 表示公司、主权和银行敞口， "hvcre" 表示高波动商业房地产， "mortgage" 表示个人住房抵押贷款， "revolving" 表示合格循环零售敞口， "other_retail" 表示其他零售敞口。

turnoverarray_like，可选

每个公司借款人的年销售额，单位与 turnover_range 相同，例如百万欧元。低于区间上限的值会降低相关系数，用于中小企业； numpy.inf 表示不做这项调整的借款人。只适用于 asset_class="corporate" ；不能缺失。

turnover_rangetuple of float，默认 (5.0, 50.0)

营业收入调整的下限和上限。默认值是巴塞尔的区间，单位为百万欧元；中国的规则使用 (3.0, 30.0)，单位为千万元人民币。

financialbool，默认 False

借款人是否为相关系数乘以 1.25 的金融机构。只适用于 asset_class="corporate" ，且不能与低于 turnover_range 上限的营业收入同时给出。

返回值:
float、pandas.Series 或 numpy.ndarray

相关系数，形状为 probability 与 turnover 广播后的形状。若某个输入是 Series，结果是带有其索引、名为 correlation 的 Series；标量输入得到 float。

异常:
ValueError

如果 asset_class 不是五个类别之一， probability 不是实数数值或超出 [0, 1]，或者输入无法一起广播或 Series 索引不同。此外，如果对 "corporate" 以外的类别给出 turnover 或 financial ， turnover 缺失、为负或不是数值， turnover_range 不是满足 0 <= lower < upper 的两个有限数， financial 不是布尔值，或者 financial 与低于上限的营业收入同时给出，也会引发此异常。

参见

capital_requirement

使用该相关系数的资本要求。

conditional_pd

单因子模型在给定经济状态下的 PD。

说明

公司敞口的相关系数如下；其他零售敞口把权重中的 50 换成 35，界限换成 0.03 和 0.16：

\[w = \frac{1 - e^{-50\,\mathrm{PD}}}{1 - e^{-50}}, \qquad R = 0.12\,w + 0.24\,(1 - w).\]

高波动商业房地产用 0.30 代替 0.24，个人住房抵押贷款 \(R = 0.15\) ，合格循环零售敞口 \(R = 0.04\) 。区间为 \([l, u]\) 时，营业收入 \(S\) 使公司敞口的相关系数降低 \(0.04\,(1 - (\min(\max(S, l), u) - l) / (u - l))\) ，在 \(S \le l\) 时为 0.04，在 \(S \ge u\) 时为 0；financial 使其乘以 1.25（巴塞尔 CRE31.5–31.16；中国，附件 6 和附件 8）。

示例

>>> from kivi.capital import asset_correlation
>>> asset_correlation([0.0003, 0.01, 0.2], asset_class="corporate").round(4)
array([0.2382, 0.1928, 0.12  ])
>>> print(f"{asset_correlation(0.01, asset_class='corporate', turnover=5.0):.4f}")
0.1528
kivi.capital.capital_requirement(probability, lgd, *, asset_class, maturity=None, turnover=None, turnover_range=(5.0, 50.0), financial=False, correlation=None, level=0.999, scaling=1.0)#

计算内部评级法的资本要求 K，以占敞口的比例表示。

K 覆盖未违约敞口的非预期损失：单因子模型在 level 分位数处的损失减去预期损失。风险加权资产为 12.5 * K * EAD ，风险权重为 12.5 * K 。

参数:
probabilityarray_like

违约概率，严格介于 0 与 1 之间，已施加 PD 下限。缺失值得到缺失的资本要求。

lgdarray_like

违约损失率，即损失占敞口的比例，取值在 0 与 1 之间。缺失值得到缺失的资本要求。

asset_class{"corporate", "hvcre", "mortgage", "revolving", "other_retail"}

资产类别，同 asset_correlation 。它也决定是否做期限调整： "corporate" 和 "hvcre" 做，三个零售类别不做。

maturityarray_like，可选

有效期限，单位为年，必须为正且有限，只适用于 "corporate" 和 "hvcre" 。默认为 2.5 年。它不会被截到 1 至 5 年的区间，因为短期敞口有例外；不能缺失。

turnoverarray_like，可选

公司借款人的年销售额，同 asset_correlation 。

turnover_rangetuple of float，默认 (5.0, 50.0)

营业收入调整的界限，同 asset_correlation 。

financialbool，默认 False

是否对金融机构乘以 1.25，同 asset_correlation 。

correlationarray_like，可选

取值从 0 到 1（不含 1）的资产相关系数，用来替代公式中的相关系数，例如用于经济资本；此时不能给出 turnover 和 financial 。不能缺失。

levelfloat，默认 0.999

单因子模型的置信水平，严格介于 0 与 1 之间。

scalingfloat，默认 1.0

乘在 K 上的正数因子。只有 2006 年的巴塞尔 II 框架把风险加权资产乘以 1.06；现行巴塞尔框架和中国 2023 年的规则都不乘。

返回值:
float、pandas.Series 或 numpy.ndarray

资本要求，形状为输入广播后的形状。若某个输入是 Series，结果是带有其索引、名为 capital_requirement 的 Series；标量输入得到 float。

异常:
ValueError

如果某个输入不是实数数值，输入无法一起广播或 Series 索引不同， probability 超出开区间 (0, 1)，或者对 "corporate" 或 "hvcre" 不高于约 2.927e-6，或者 lgd 超出 [0, 1]。此外，如果对零售类别给出 maturity ，或其缺失、非正或非有限， correlation 缺失、超出 [0, 1) 或与 turnover 或 financial 同时给出， level 超出 (0, 1)， scaling 不是正的有限数，或者某个参数像 asset_correlation 中那样无效，也会引发此异常。

参见

asset_correlation

每个资产类别的相关系数。

conditional_pd

单因子模型在该置信水平下的 PD。

kivi.strategy.expected_loss

K 所不包含的预期损失 PD x LGD x EAD。

说明

记 \(\Phi\) 为标准正态分布函数， \(\Phi^{-1}\) 为其分位数函数， \(R\) 为 asset_correlation 的相关系数， \(q\) 为置信水平，

\[K = \mathrm{LGD} \left[ \Phi\!\left( \frac{\Phi^{-1}(\mathrm{PD}) + \sqrt{R}\,\Phi^{-1}(q)}{\sqrt{1 - R}} \right) - \mathrm{PD} \right] \frac{1 + (M - 2.5)\,b}{1 - 1.5\,b}, \qquad b = (0.11852 - 0.05478 \ln \mathrm{PD})^2,\]

其中期限因子只适用于 "corporate" 和 "hvcre" （巴塞尔 CRE31.5–31.16；中国，附件 6）。然后 K 乘以 scaling 。

期限因子要除以 \(1 - 1.5\,b\) ，它在 PD 约为 2.927e-6 时等于 0，因此这些 PD 会报错；在此之前，PD 低于约 1e-5 时，该因子增长很快，风险权重随 PD 下降反而上升。0.05% 的 PD 下限（巴塞尔 CRE32.4，中国第九十一条）高于这两个值；只有主权敞口没有下限。

已违约敞口（PD = 1）也会报错：它的资本要求是 \(\max(0, \mathrm{LGD} - \mathrm{ELBE})\) ，其中用到其预期损失的最佳估计（巴塞尔 CRE31.3；中国，附件 6 第二部分）。

示例

>>> from kivi.capital import capital_requirement
>>> k = capital_requirement(0.01, 0.45, asset_class="corporate")
>>> print(f"K = {k:.6f}, risk weight = {12.5 * k:.4%}")
K = 0.073853, risk weight = 92.3168%
>>> rw = 12.5 * capital_requirement([0.01, 0.01], [0.45, 0.25], asset_class="other_retail")
>>> rw.round(4)
array([0.4577, 0.2543])
kivi.capital.conditional_pd(probability, *, correlation, factor=None, level=None)#

计算单因子模型在给定经济状态下的 PD。

内部评级法风险权重函数背后是 Vasicek 的单因子模型：借款人的资产低于由其长期 PD 决定的阈值时违约，所有借款人的资产共享一个系统因子。给定该因子时，违约相互独立，按条件 PD 发生。它把跨周期（TTC）PD 转换为某个经济情景下的时点（PIT）PD，并在其置信水平下给出 capital_requirement 中的压力 PD。

参数:
probabilityarray_like

长期（无条件）违约概率，严格介于 0 与 1 之间。缺失值得到缺失的 PD。

correlationarray_like

取值从 0 到 1（不含 1）的资产相关系数，例如 asset_correlation 的结果。不能缺失。

factorarray_like，可选

标准正态的系统因子取值，必须有限；正值表示经济好于平均，得到低于长期 PD 的 PD。缺失值得到缺失的 PD。

levelarray_like，可选

代替 factor ：经济好于该情景的概率，严格介于 0 与 1 之间；因子是下侧 1 - level 分位数 -Phi^-1(level) 。缺失值得到缺失的 PD。 factor 和 level 必须恰好给出一个。

返回值:
float、pandas.Series 或 numpy.ndarray

条件 PD，形状为输入广播后的形状。若某个输入是 Series，结果是带有其索引、名为 conditional_pd 的 Series；标量输入得到 float。

异常:
ValueError

如果没有恰好给出 factor 和 level 中的一个，某个输入不是实数数值，输入无法一起广播或 Series 索引不同， probability 或 level 超出开区间 (0, 1)， correlation 缺失或超出 [0, 1)，或者 factor 为无穷。

参见

systematic_factor

违约率所对应的因子，即本函数的逆运算。

vasicek_fit

由违约率估计长期 PD 和相关系数。

capital_requirement

资本要求，它使用置信水平 0.999 下的 PD。

说明

记标准正态分布函数为 \(\Phi\) ，相关系数为 \(\rho\) ，因子为 \(z\) ，

\[\mathrm{PD}(z) = \Phi\!\left( \frac{\Phi^{-1}(\mathrm{PD}) - \sqrt{\rho}\,z}{\sqrt{1 - \rho}} \right),\]

level \(q\) 相当于 \(z = -\Phi^{-1}(q)\) ，因此 level=0.999 给出内部评级法公式中的 PD。对标准正态的 \(z\) 取平均，条件 PD 等于长期 PD。

示例

>>> from kivi.capital import conditional_pd
>>> conditional_pd(0.01, correlation=0.12, factor=[2.0, 0.0, -2.0]).round(5)
array([0.00064, 0.00657, 0.04081])
>>> print(f"{conditional_pd(0.01, correlation=0.12, level=0.999):.4%}")
9.0326%
kivi.capital.systematic_factor(default_rate, probability, *, correlation)#

计算观察到的违约率所对应的系统因子。

本函数是 conditional_pd 的逆运算：给出使条件 PD 等于违约率（例如某组合每年的违约率）的系统因子取值。因子为负表示该年差于平均。

参数:
default_ratearray_like

观察到的违约率，严格介于 0 与 1 之间。缺失值得到缺失的因子。

probabilityarray_like

长期违约概率，严格介于 0 与 1 之间，例如 vasicek_fit 的第一个结果。缺失值得到缺失的因子。

correlationarray_like

资产相关系数，严格介于 0 与 1 之间，例如 vasicek_fit 的第二个结果。不能缺失。

返回值:
float、pandas.Series 或 numpy.ndarray

因子，形状为输入广播后的形状。若某个输入是 Series，结果是带有其索引、名为 factor 的 Series；标量输入得到 float。

异常:
ValueError

如果某个输入不是实数数值，输入无法一起广播或 Series 索引不同， default_rate 或 probability 超出开区间 (0, 1)，或者 correlation 缺失或超出 (0, 1)。违约率为 0 或 1 时没有有限的因子。

参见

conditional_pd

给定因子时的 PD，即本函数的逆运算。

vasicek_fit

由违约率估计长期 PD 和相关系数。

说明

记违约率为 \(\mathrm{DR}\) ，

\[z = \frac{\Phi^{-1}(\mathrm{PD}) - \sqrt{1 - \rho}\,\Phi^{-1}(\mathrm{DR})}{\sqrt{\rho}}.\]

示例

>>> from kivi.capital import conditional_pd, systematic_factor
>>> systematic_factor([0.004, 0.01, 0.03], 0.01, correlation=0.12).round(4)
array([ 0.4663, -0.4158, -1.6224])
>>> print(f"{conditional_pd(0.01, correlation=0.12, factor=-1.6224):.4f}")
0.0300
kivi.capital.vasicek_fit(default_rate)#

由一段违约率序列估计长期 PD 和资产相关系数。

在单因子模型中，大型组合的违约率随系统因子逐年变化，其方差随资产相关系数增大。矩估计使观察到的违约率的均值和方差得到匹配。违约率为 0 的年份（没有违约的年份）也计入。

参数:
default_ratearray_like

一个组合在连续各期（例如各年）的违约率，取值在 0 与 1 之间，至少两个，且没有缺失值。

返回值:
probabilityfloat

长期 PD，即违约率的均值。

correlationfloat

资产相关系数，取值在 0 与 1 之间。常数序列得到 0。

异常:
ValueError

如果 default_rate 不是实数数值、不是一维、少于两个值、有缺失值或超出 [0, 1] 的值，其均值为 0 或 1，或者其方差不小于 mean * (1 - mean) ，即相关系数为 1 时的方差。

参见

conditional_pd

给定因子时的 PD，使用拟合的参数。

systematic_factor

每一期的因子，使用拟合的参数。

说明

记违约率的均值为 \(m\) 、方差为 \(s^2\) （ ddof=1 ），相关系数 \(\rho\) 满足

\[\Phi_2\!\left(\Phi^{-1}(m), \Phi^{-1}(m); \rho\right) - m^2 = s^2,\]

其中 \(\Phi_2\) 是二元标准正态分布函数：组合中两个借款人同时违约的概率为 \(\Phi_2\) 。左边随 \(\rho\) 从 0 增大到 \(m (1 - m)\) ，用二分法求解。这些矩描述的是足够大、违约率等于条件 PD 的组合，因此小组合的二项噪声会使估计偏高。

示例

>>> from kivi.capital import vasicek_fit
>>> probability, correlation = vasicek_fit([0.004, 0.012, 0.0, 0.031, 0.008, 0.015])
>>> print(f"PD = {probability:.4f}, correlation = {correlation:.4f}")
PD = 0.0117, correlation = 0.0994
kivi.capital.most_prudent_pd(event, total, *, level=0.95, correlation=0.0)#

计算 Pluto 和 Tasche 的最审慎估计：每个等级 PD 的上界。

违约很少或没有违约的组合（例如银行或大型企业）的违约率太小，无法据以校准 PD。一个等级的最审慎估计，是该等级及所有更差等级中观察到的违约在置信水平 level 下不会拒绝的最大 PD，其前提是 PD 从一个等级到下一个更差等级不会下降。

参数:
eventarray_like

每个等级的违约数，为非负整数，等级按风险从低到高排列。不能缺失。

totalarray_like

每个等级的债务人数，为不小于 event 的整数；按位置对应，两者都是 Series 时按相同的索引对应。

levelfloat，默认 0.95

置信水平，严格介于 0 与 1 之间。

correlationfloat，默认 0.0

单因子模型的资产相关系数，取值从 0 到 1（不含 1）。为 0 时违约相互独立；正的相关系数使同样的违约与更高的 PD 相容。

返回值:
pandas.Series 或 numpy.ndarray

每个等级 PD 的上界。若某个输入是 Series，结果是带有其索引、名为 most_prudent_pd 的 Series。

异常:
ValueError

如果 event 或 total 不是实数数值、不是一维、为空或长度不同，它们的 Series 索引不同，某个计数缺失或不是非负整数， event 超过 total ， level 超出 (0, 1)，或者 correlation 超出 [0, 1)。

参见

kivi.calibration.binomial_test

检验每个等级的 PD 与其违约数是否相符。

conditional_pd

单因子模型在给定因子下的 PD。

说明

等级 \(k\) 合并它自身及所有更差等级的债务人 \(n_k = \sum_{i \ge k} N_i\) 和违约 \(d_k = \sum_{i \ge k} D_i\) 。它的上界 \(p_k\) 是置信水平 \(q\) 下满足 \(P(D \le d_k) \ge 1 - q\) 的最大 PD。违约相互独立时， \(D\) 服从参数为 \(n_k\) 和 \(p_k\) 的二项分布，因此 \(p_k\) 是参数为 \(d_k + 1\) 和 \(n_k - d_k\) 的贝塔分布的 \(q\) 分位数；没有违约时 \(p_k = 1 - (1 - q)^{1/n_k}\) 。相关系数为 \(\rho\) 时，给定因子的违约服从二项分布，

\[P(D \le d_k) = \int P\left(\mathrm{Bin}(n_k, \mathrm{PD}(z)) \le d_k\right) \varphi(z) \, dz,\]

其中条件 PD 来自 conditional_pd ；积分在因子的 -9 到 9 之间用复合 Gauss-Legendre 求积（64 段，每段 8 个节点），再用二分法求解。合并后的债务人全部违约或没有债务人的等级得到 1。这些上界针对单期；若因子在多年间相关，就需要模拟，kivi 不做。Pluto 和 Tasche [1] 对其算例算出了同样的上界，相关的算例取相关系数 0.12。

参考文献

[1]

K. Pluto and D. Tasche, "Estimating probabilities of default for low default portfolios", arXiv:cond-mat/0411699, 2004; also "Thinking positively", Risk 18 (8), 2005, pp. 72-78.

示例

>>> from kivi.capital import most_prudent_pd
>>> (100 * most_prudent_pd([0, 0, 0], [100, 400, 300], level=0.9)).round(2)
array([0.29, 0.33, 0.76])
