LGD 与 EAD#

度量违约贷款的违约损失率和信用转换系数并为其建模。 workout_lgd() 把每笔清收的回收和费用折现到违约日， conversion_factor() 给出授信额度的实际 CCF， lgd_table() 按分组汇总实际 LGD， fractional_regression() 对 LGD 及其驱动因素拟合分数 logit。

示例以及巴塞尔框架、EBA 和中国资本管理办法的规则见 LGD 与 EAD 。

workout_lgd(loan, default_date, ead, ...)

由清收现金流计算违约贷款的实际 LGD。

计算每个授信额度的实际信用转换系数。

lgd_table(groups, lgd, *[, floor, weights])

按分组汇总实际 LGD。

fractional_regression(X, response, *[, weights])

对取值在 0 到 1 之间的响应拟合分数 logit 回归。
kivi.lgd.workout_lgd(loan, default_date, ead, flow_loan, flow_date, flow_amount, *, rate)#

由清收现金流计算违约贷款的实际 LGD。

违约贷款的经济损失是其违约风险敞口加上清收费用、减去回收，全部折现到违约日。它与违约风险敞口之比就是清收法下的实际违约损失率。

参数:
loanarray_like

违约贷款，每笔一次。结果每笔贷款一行，顺序与此相同。

default_datearray_like

每笔贷款的违约日，可以是日期，也可以是 pandas.to_datetime 能读取的日期字符串。时刻会被忽略。

eadarray_like

每笔贷款的违约风险敞口，为有限正数：违约时的未偿金额，包括应计利息和费用，再加上违约时或违约前核销的金额。

flow_loanarray_like

清收中每笔现金流所属的贷款。每一笔都必须是 loan 中的贷款；没有现金流的贷款视为没有任何回收。现金流无需排序，其 Series 可以有任意索引。

flow_datearray_like

每笔现金流的日期，读法与 default_date 相同。

flow_amountarray_like

每笔现金流的金额，为有限值：回收为正，例如还款、处置押品所得或治愈；清收费用或违约后的追加提款为负。费用可以早于违约日，回收不可以。

ratefloat 或 array_like

年折现率，大于 -1；可以为所有贷款给出一个利率，也可以每笔贷款一个，与 loan 的对应方式和 ead 相同，例如违约日的 3 个月银行间利率加 5 个百分点。

返回值:
pandas.DataFrame

每笔贷款一行，以 loan 为索引，索引名为 loan ，列为 ead ； recovery ，正现金流的现值； cost ，负现金流的现值，记为正数；以及 lgd ，等于 (ead + cost - recovery) / ead 。

异常:
ValueError

如果贷款的输入或现金流的输入不是一维的、长度不同或是索引不同的 Series，或者 loan 为空。另外，如果贷款或日期缺失或贷款重复，日期无法读取， ead 缺失或不是有限正数，金额缺失、无穷或不是数值，某笔现金流所属的贷款不在 loan 中，回收早于其贷款的违约日，或者 rate 缺失、不是有限值、不大于 -1，或既不是一个利率也不是每笔贷款一个利率，也会引发此异常。布尔值不能作为金额或利率。

参见

lgd_table

按分组的长期平均 LGD。

fractional_regression

对 LGD 及其驱动因素建模。

kivi.calibration.backtest_table

用实际 LGD 回测 LGD 估计值。

kivi.vintage.delinquency_panel

以同样的方式读取日期。

说明

违约日为 \(t_D\) 、年利率为 \(r\) 的贷款在日期 \(t_j\) 发生的金额为 \(a_j\) 的现金流，其现值为

\[\mathrm{PV}_j = a_j \, (1 + r)^{-(t_j - t_D) / 365},\]

天数按 ACT/365 计算。违约日之前的费用指数为负，即复利计算到违约日。记正现金流现值之和为 \(R\) ，负现金流现值之和（记为正数）为 \(C\) ，则

\[\mathrm{LGD} = \frac{\mathrm{EAD} + C - R}{\mathrm{EAD}}.\]

这就是 [1] 第 131 至 146 段和巴塞尔框架 CRE36.76 中的经济损失。LGD 不截断到 [0, 1]：回收超过敞口与费用之和时为负，费用超过回收时大于 1。计算长期平均时 lgd_table 把它的下限设为 0（ [1] 第 160 段）。

函数不知道清收是否已经结束，给出的是到目前为止的现金流造成的损失：没有现金流的贷款 LGD 为 1。实际 LGD 只对已结案的清收成立（ [1] 第 154 段； [2] 第 2.6.1 节），因此在求平均或回测之前，应按银行对清收结束的定义筛选出回收过程已结案的贷款。

现金流由调用者选定：

  • 违约后的追加提款是负现金流，与费用相同，从而计入损失（ [1] 第 142 段）。若信用转换系数包含追加提款， [1] 第 140 段把它们也计入敞口：此时把它们的现值加到 ead 上，而不是作为现金流传入，因为 ead 也计入损失。只传入追加提款（取相反数）调用一次所得的 cost 就是这一现值。

  • 违约时或违约前核销的金额属于 ead ，从而同时计入损失和敞口（ [1] 第 134 段）。

  • 治愈是一笔回收，金额为治愈日的未偿金额（ [1] 第 135 段）。

  • 违约后资本化的利息和费用不是现金流（ [1] 第 137 和 138 段），但它们的回收是。

参考文献

[1] (1,2,3,4,5,6,7,8)

European Banking Authority, "Guidelines on PD estimation, LGD estimation and the treatment of defaulted exposures", EBA/GL/2017/16, 2017 年 11 月 20 日，第 131 至 163 段。

[2]

European Central Bank, "Instructions for reporting the validation results of internal models: IRB Pillar I models for credit risk", 2019 年 2 月，第 2.6.1 节。

示例

三笔贷款于 2023 年 1 月 1 日违约。贷款 A 一年后回收 55、发生费用 11；贷款 B 在违约当天回收了全部敞口，此前一年发生了 5 的法律费用；贷款 C 还没有现金流：

>>> from kivi.lgd import workout_lgd
>>> workout_lgd(
...     ["A", "B", "C"],
...     ["2023-01-01"] * 3,
...     [100.0, 200.0, 50.0],
...     ["A", "A", "B", "B"],
...     ["2024-01-01", "2024-01-01", "2022-01-01", "2023-01-01"],
...     [55.0, -11.0, -5.0, 200.0],
...     rate=0.1,
... ).round(4)
        ead  recovery  cost     lgd
loan
A     100.0      50.0  10.0  0.6000
B     200.0     200.0   5.5  0.0275
C      50.0       0.0   0.0  1.0000

按每年 10%，A 在违约一年后的现金流价值为 55 / 1.1 = 50 和 11 / 1.1 = 10；B 在违约前一年的费用折算到违约日为 5 × 1.1 = 5.5。

kivi.lgd.conversion_factor(ead, drawn, limit)#

计算每个授信额度的实际信用转换系数。

信用转换系数（CCF）是授信额度在参考日的未提用部分中，借款人到违约时已提用的比例。

参数:
eadarray_like

违约时的提用金额，即实际违约风险敞口。

drawnarray_like

参考日的提用金额。

limitarray_like

参考日的授信额度。Series 输入必须有相同的索引；否则输入一起广播。

返回值:
float、pandas.Series 或 numpy.ndarray

实际 CCF，形状为各输入广播后的形状：额度在参考日已满额使用（ limit 不大于 drawn ）或某个输入缺失时为 NaN。若某个输入是 Series，结果是带其索引、名为 ccf 的 Series；标量输入得到 float。

异常:
ValueError

如果某个输入不是实数数值或含有无穷值，各输入无法一起广播，或 Series 输入的索引不同。布尔值不能作为金额。

参见

workout_lgd

同一批违约的实际 LGD。

lgd_table

用 floor=None 按分组汇总实际 CCF。

kivi.calibration.backtest_table

用实际 CCF 回测 CCF 估计值。

说明

记违约时的提用金额为 \(E\) ，参考日的提用金额为 \(D\) 、额度为 \(L\) ，则

\[\mathrm{CCF} = \frac{E - D}{L - D}, \qquad L > D.\]

这就是巴塞尔框架 CRE36.95 和 EBA CCF 估计征求意见稿 [1] 第 61(a) 段中的实际 CCF。固定期限法的参考日在违约前 12 个月（CRE36.93；CRR3 第 182(1)(g) 条），额度取该日已告知额度与未告知额度中的较大者：之后提高的额度不进入分母，因此 CCF 可以超过 1。

参考日已满额或超额使用的额度没有未提用部分，其 CCF 为 NaN，而不是超额额度符号相反的比值。征求意见稿用 ead / limit 度量这类额度（第 61(b) 段），ECB 的验证报告则改为回测它们的 EAD，而不是 CCF。

CCF 不截断。参考日之后还款的额度给出负值，这些值仍能区分风险，但量化时记为 0（CRR3 第 182(1) 条），正如 numpy.maximum(ccf, 0) 所做的；大于 1 的值保留，因为 CCF 不得封顶（CRE36.95-96）。

参考文献

[1]

European Banking Authority, "Consultation paper on draft guidelines on CCF estimation", EBA/CP/2025/10, 2025 年 7 月 2 日。

示例

>>> from kivi.lgd import conversion_factor
>>> conversion_factor([600.0, 800.0, 300.0, 900.0], [400.0, 400.0, 500.0, 1000.0], 1000.0)
array([ 0.33333333,  0.66666667, -0.4       ,         nan])

第一个额度提用了 600 未提用部分中的 200；第三个偿还了 500 未提用部分中的 200；第四个在参考日已满额使用。

kivi.lgd.lgd_table(groups, lgd, *, floor=0.0, weights=None)#

按分组汇总实际 LGD。

这张表给出每个分组的违约数、平均 LGD、其离散程度以及无损失违约和全额损失违约的份额，分组可以是分段、债项等级或某个驱动因素的箱：即每个分组的长期平均 LGD 以及组内 LGD 的双峰形状。

参数:
groupsarray_like

分组标签，例如债项等级，或用 kivi.binning.cut 切分的驱动因素的箱。缺失值单独成组。

lgdarray_like

每笔违约的实际 LGD，例如 workout_lgd 的 lgd 列，为有限值且没有缺失值。若 groups 和 lgd 都是 Series，它们必须有相同的索引；否则按位置对应。

floorfloat 或 None，默认 0.0

在计算任何列之前施加于 LGD 的下限：默认把负的 LGD 记为 0，这是监管对长期平均的要求。None 保留 LGD 原值，适合分析驱动因素。

weightsarray_like，可选

每笔违约的非负频数权重，对应方式与 lgd 相同：整数权重与重复行得到相同的表，权重之和为零的分组被略去。关于按敞口加权见“说明”。

返回值:
pandas.DataFrame

每个分组一行，索引名为 bin ，各列见“说明”。

异常:
ValueError

如果输入不是一维的、为空，或者索引或长度不一致， lgd 不是实数数值或含有缺失值或无穷值，或者 floor 既不是 None 也不是有限数。另外，如果 weights 不是数值，没有为每笔违约给出一个有限非负的权重且总和为正，或其索引与 groups 不同，也会引发此异常。

参见

workout_lgd

由清收现金流计算实际 LGD。

fractional_regression

同时对 LGD 及其多个驱动因素建模。

kivi.woe.woe_table

二元目标的对应表。

kivi.calibration.backtest_table

按分组回测 LGD 估计值。

说明

对分组中的违约 \(i\) ，记权重为 \(w_i\) （没有 weights 时为 1），在下限 \(f\) 处的 LGD 为 \(x_i = \max(\mathrm{LGD}_i, f)\) ，各列为：

  • total ：违约数， \(n = \sum_i w_i\) ；

  • total_share ： total 除以全部违约数；

  • mean ：平均 LGD， \(\bar x = \sum_i w_i x_i / n\) ；

  • std ：样本标准差， \(\sqrt{\sum_i w_i (x_i - \bar x)^2 / (n - 1)}\) ，总权重不超过 1 的分组为 NaN；

  • min 和 max ：权重为正的最小和最大 LGD；

  • zero_share ： \(x_i \le 0\) 即无损失的违约所占份额；

  • full_share ： \(x_i \ge 1\) 即全额损失的违约所占份额。

平均值中每笔违约计一次，即 [1] 第 150 段、巴塞尔框架 CRE36.83 以及中国 2023 年资本管理办法附件 5 六（四）中的违约加权平均，这些规则也把负的 LGD 记为 0（ [1] 第 160 段；该附件六（四）15）。按违约风险敞口加权得到的是敞口加权平均，不是监管所指的长期平均；应使用计数违约的权重，例如抽样比例的倒数。

分组的计数方式与 kivi.woe.woe_table 相同：分类型分组（例如 pandas.cut 的结果）按类别顺序排列，缺失值在最后；其他分组按首次出现的顺序排列。从未出现的类别被略去。

参考文献

[1] (1,2)

European Banking Authority, "Guidelines on PD estimation, LGD estimation and the treatment of defaulted exposures", EBA/GL/2017/16, 2017 年 11 月 20 日，第 150 至 162 段。

示例

>>> from kivi.lgd import lgd_table
>>> grade = ["F1"] * 4 + ["F2"] * 3
>>> lgd = [-0.05, 0.0, 0.10, 0.35, 0.80, 1.0, 1.2]
>>> lgd_table(grade, lgd).round(4)
     total  total_share    mean     std  min   max  zero_share  full_share
bin
F1       4       0.5714  0.1125  0.1652  0.0  0.35         0.5      0.0000
F2       3       0.4286  1.0000  0.2000  0.8  1.20         0.0      0.6667

等级 F1 中 -0.05 的 LGD 来自超过敞口的回收，记为 0，因此 F1 的违约有一半没有损失；F2 的三笔违约中有两笔损失了全部敞口或更多。

kivi.lgd.fractional_regression(X, response, *, weights=None)#

对取值在 0 到 1 之间的响应拟合分数 logit 回归。

Papke 和 Wooldridge [1] 的模型把取值在 0 到 1 之间的响应（例如实际 LGD 或回收率）的均值表示为 X 各列线性组合的 logistic 函数。其系数使伯努利拟似然最大，标准误是稳健标准误，因此模型无需对响应在均值周围的分布作任何假定。

参数:
Xpandas.DataFrame 或 array_like

二维数值，每个驱动因素一列，例如贷款价值比或分段的虚拟变量。

responsearray_like

每一行的响应，取值在 0 到 1 之间，可以恰为 0 或 1，例如下限设为 0、上限设为 1 的实际 LGD。若 X 是 DataFrame 而 response 是 Series，它们必须有相同的索引；否则按位置对应。

weightsarray_like，可选

每一行的非负频数权重，对应方式与 response 相同：整数权重与重复行得到相同的估计值、标准误和拟对数似然。权重为零的行不参与拟合。

返回值:
pandas.DataFrame

截距一行，标签为 intercept ， X 的每一列各一行，列为系数 coef 、其稳健标准误 se 、z 统计量 z 及其双侧 p 值 p_value ，索引名为 variable ，与 kivi.selection.logistic_regression 给出的相同。 attrs["log_likelihood"] 是最大化的拟对数似然， attrs["converged"] 表示拟合是否收敛。

异常:
kivi.selection.SeparationError

如果各列把响应为 0 的行与响应为 1 的行分开，而没有介于二者之间的响应阻止系数无限增长，因而估计值不存在。

ValueError

如果 X 不是二维的，少于 2 行或没有列，列标签重复，有标签为 intercept 的列，或者某列不是数值、含有缺失值或无穷值、为常数、是截距和它前面各列的线性组合，或者接近线性组合到无法估计其系数；如果 response 不是一维的，其索引或长度与 X 不一致，不是实数数值，含有缺失值或 [0, 1] 之外的值，或者每一行都为 0 或每一行都为 1；或者如果 weights 不是数值，或没有为每一行给出一个有限非负的权重且总和为正。有 weights 时，常数列、线性组合以及响应每一行都为 0 或 1 的检查只针对权重为正的行。

警告:
RuntimeWarning

如果拟合因分离以外的原因未能收敛。

参见

kivi.selection.logistic_regression

二元目标的同一模型。

lgd_table

按一个驱动因素分组的实际 LGD。

workout_lgd

由清收现金流计算实际 LGD。

说明

模型为

\[E(y \mid x) = \frac{1}{1 + e^{-\eta}}, \qquad \eta = \beta_0 + \sum_j \beta_j x_j,\]

估计值使拟对数似然最大：

\[\ell(\beta) = \sum_i w_i \left[ y_i \ln p_i + (1 - y_i) \ln(1 - p_i) \right],\]

对二元响应，这就是 kivi.selection.logistic_regression 的对数似然，因此只含 0 和 1 的响应得到它的系数。拟合使用同样的迭代重加权最小二乘法。只要均值模型正确，均值就能一致地估计，但 Fisher 信息低估了分数响应的方差，因此协方差取 HC0 夹心估计

\[\hat V = A^{-1} B A^{-1}, \qquad A = \sum_i w_i p_i (1 - p_i) x_i x_i^\top, \qquad B = \sum_i w_i (y_i - p_i)^2 x_i x_i^\top,\]

其中 \(x_i\) 包括截距的 1，与 statsmodels 的 GLM(family=Binomial(), freq_weights=w).fit(cov_type="HC0") 给出的相同。z 统计量为 \(\hat\beta / \mathrm{se}\) ，p 值为 \(P(|Z| > |z|)\) ，其中 \(Z\) 服从标准正态分布。对二元响应，稳健标准误与 kivi.selection.logistic_regression 基于模型的标准误不同。

分数响应在两个方向上都约束线性预测值，因此只要不存在这样的列组合：它把恰为 0 的响应与恰为 1 的响应分开，并且使每个介于二者之间的响应的线性预测值保持不变，估计值就存在。

参考文献

[1]

L. E. Papke and J. M. Wooldridge, "Econometric methods for fractional response variables with an application to 401(k) plan participation rates", Journal of Applied Econometrics, 11(6), pp. 619-632, 1996.

示例

只有一个虚拟变量时，拟合均值就是其两组的平均响应：有押品贷款为 0.2，无押品贷款为 0.65：

>>> import pandas as pd
>>> from kivi.lgd import fractional_regression
>>> X = pd.DataFrame({"unsecured": [0, 0, 0, 0, 1, 1, 1, 1]})
>>> lgd = pd.Series([0.0, 0.1, 0.5, 0.2, 0.3, 0.9, 0.4, 1.0])
