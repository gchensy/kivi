安装#

kivi 需要 Python 3.11 或更高版本、NumPy 1.24 或更高版本，以及 pandas 2.0 或更高版本。pip 会自动安装 NumPy 和 pandas。从 kivi 1.0 起，最低版本只会在次版本中提高，并在前一个版本的版本说明中预先公布；参见 兼容性 。

安装最新发布版本：

python -m pip install kivi

直接从仓库安装开发版：

python -m pip install "git+https://github.com/gchensy/kivi"

克隆仓库后从本地安装：

git clone https://github.com/gchensy/kivi.git
cd kivi
python -m pip install .

检查已安装的版本：

python -c "import kivi; print(kivi.__version__)"

kivi.plotting 的图表需要 matplotlib 3.7 或更高版本。可通过 plot 附加依赖与 kivi 一起安装；其他模块从不导入 matplotlib。

python -m pip install "kivi[plot]"

如需参与 kivi 开发，请使用可编辑安装并加装测试和文档依赖，详见 开发。

备注

0.2.x 版本的 API 与当前版本不同。升级已有代码前，请先阅读 迁移指南。
