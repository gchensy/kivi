API 参考#

请从各自所在的模块导入函数，例如 from kivi.woe import woe_table 。 约定 说明所有函数在参数、结果和错误方面共同遵守的规则， 兼容性 说明一个版本可以改变什么以及如何预告这些改变， 术语表 给出各篇指南所用术语的定义。其余每一页对应一个模块，按用户指南的顺序排列。
