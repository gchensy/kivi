变量筛选#

评分卡是基于少量 WOE 编码变量的逻辑回归。 kivi.selection 涵盖了从候选变量到入选名单的常用步骤：对每一对强相关的变量剔除其中一个，检查其余变量的共线性，按 p 值筛选变量，并解读拟合的模型。每个函数都接收一个每个变量一列 WOE 编码值的 DataFrame，例如 woe_transform() 的输出；拟合模型的函数还需要 0/1 目标变量。

变量筛选位于 证据权重与信息值 之后（后者对候选变量编码），位于 拒绝推断 和 评分卡 之前（它们重新拟合所选模型并进行刻度）。 correlation_filter() 剔除相关变量， vif() 衡量共线性， logistic_regression() 拟合模型， stepwise() 筛选模型变量。

准备候选变量#

按 风控建模流程 中的方式对每个候选变量分组：多数数值变量使用分位数分箱，重复值会使分位数重合的变量使用显式边界，类别变量直接使用原始标签。然后在开发样本上为每个变量拟合一张 WOE 表，按 IV 排序，并对 IV 不低于 0.02 的变量做 WOE 编码。

>>> import numpy as np
>>> import pandas as pd
>>> from kivi.binning import bin_edges
>>> from kivi.datasets import Dataset
>>> from kivi.selection import correlation_filter, logistic_regression, stepwise, vif
>>> from kivi.woe import woe_table, woe_transform
>>> data = Dataset.bank_data()
>>> development = data.iloc[:3000]
>>> target = development["target"]
>>> edges = {
...     "age": bin_edges(development["age"], bins=5),
...     "balance": bin_edges(development["balance"], bins=5),
...     "day": bin_edges(development["day"], bins=5),
...     "campaign": [-np.inf, 1, 2, 3, np.inf],
...     "pdays": [-np.inf, -1, 100, 200, 300, np.inf],
...     "previous": [-np.inf, 0, 1, 3, np.inf],
... }
>>> groups = pd.DataFrame({
...     column: pd.cut(development[column], column_edges) for column, column_edges in edges.items()
... })
>>> for column in ["job", "marital", "education", "default", "housing", "loan", "contact", "poutcome"]:
...     groups[column] = development[column]
>>> tables = {column: woe_table(groups[column], target) for column in groups}
>>> iv = pd.Series({column: table["iv"].sum() for column, table in tables.items()})
>>> iv = iv.sort_values(ascending=False)
>>> iv.round(3)
poutcome     0.423
pdays        0.360
previous     0.234
contact      0.215
job          0.137
housing      0.108
balance      0.099
loan         0.059
education    0.050
marital      0.049
campaign     0.025
age          0.019
day          0.011
default      0.000
dtype: float64
>>> candidates = iv.index[iv >= 0.02]
>>> X = pd.DataFrame({column: woe_transform(groups[column], tables[column]) for column in candidates})
>>> X.shape
(3000, 11)

相关变量#

描述同一行为的变量会重复携带相同的信息。 poutcome 、 pdays 和 previous 都描述上一次营销活动：

>>> X[["poutcome", "pdays", "previous"]].corr().round(2)
          poutcome  pdays  previous
poutcome      1.00   0.68      0.67
pdays         0.68   1.00      0.71
previous      0.67   0.71      1.00

correlation_filter() 按 priority 从高到低依次考察各变量，若某变量与已保留变量的相关系数绝对值超过 threshold （默认 0.7）则将其剔除，否则保留。把 IV 作为优先级传入，两个相关变量中预测力更强的一个就会被保留：

>>> kept = correlation_filter(X, priority=iv)
>>> X.columns.difference(kept).tolist()
['previous']

previous 因与 IV 更高的 pdays 相关而被剔除。 poutcome 与 pdays 的相关系数为 0.68，低于阈值，因此二者都被保留。常用的阈值在 0.6 到 0.8 之间；阈值越低，入选名单越短。

方差膨胀因子#

相关系数只比较两个变量，但一个变量也可能由其他几个变量共同解释。方差膨胀因子（VIF）将每个变量对其他所有变量做回归：其他变量完全无法解释的变量 VIF 为 1；其他变量越接近完全解释它，VIF 越大，且没有上限。VIF 的平方根是共线性使该变量系数的标准误放大的倍数。

>>> pd.concat([vif(X).rename("candidates"), vif(X[kept]).rename("kept")], axis=1).round(2)
           candidates  kept
poutcome         2.18  1.90
pdays            2.46  1.93
previous         2.47   NaN
contact          1.16  1.12
job              1.21  1.21
housing          1.12  1.09
balance          1.03  1.03
loan             1.02  1.02
education        1.15  1.15
marital          1.03  1.03
campaign         1.02  1.02

常见的经验法则把 VIF 高于 5（或高于 10）视为有害的共线性。这里所有的值都远低于这一水平；剔除 previous 后，另外两个描述上一次营销活动的变量的 VIF 也随之降低。

基于 WOE 的逻辑回归#

logistic_regression() 拟合带截距项的模型，并报告每个系数及其标准误、Wald z 统计量和该统计量的双侧 p 值。只含一个 WOE 编码变量的模型说明了 WOE 为什么适合逻辑回归：

>>> logistic_regression(X[["poutcome"]], target).round(4)
             coef      se        z  p_value
intercept -2.0309  0.0595 -34.1097      0.0
poutcome   1.0000  0.0824  12.1332      0.0
>>> print(f"{np.log(target.sum() / (len(target) - target.sum())):.4f}")
-2.0309

kivi 将分组的 WOE 定义为 \(\ln(p_i / q_i)\) ，即其事件占比与非事件占比之比的对数。它等于该组的对数优势减去整个样本的对数优势，因此截距取样本的对数优势、系数取 1，就能精确重现每个组的对数优势。只要没有单元格需要平滑，系数就恰好为 1。

有多个变量时，每个系数衡量的是一个变量相对于其他变量的权重。WOE 越高总是意味着事件率越高，所以每个系数都应为正。负系数表示其他变量反转了该变量的作用，通常源于共线性。在包含全部候选变量的模型中， previous 的系数为负：

>>> logistic_regression(X, target).loc[["poutcome", "pdays", "previous"]].round(3)
           coef     se      z  p_value
poutcome  0.709  0.121  5.880    0.000
pdays     0.368  0.146  2.527    0.012
previous -0.116  0.189 -0.612    0.541

基于这个模型的评分卡会给此前联系次数更多的客户更低的分数，尽管他们的认购率更高。

逐步回归#

stepwise() 按 p 值筛选模型的变量。默认的 direction="both" 从只含截距的模型开始，反复加入 p 值最小且低于 p_enter （0.05）的变量，然后移除 p 值已升至 p_remove （0.10）以上的已选变量。 direction="forward" 只加入变量； direction="backward" 则从全部变量开始，只移除变量。

>>> selected = stepwise(X[kept], target)
>>> selected.tolist()
['poutcome', 'pdays', 'contact', 'job', 'housing', 'balance', 'loan', 'marital']
>>> logistic_regression(X[selected], target).round(3)
            coef     se       z  p_value
intercept -2.029  0.062 -32.484    0.000
poutcome   0.675  0.113   5.975    0.000
pdays      0.353  0.123   2.863    0.004
contact    0.576  0.153   3.754    0.000
job        0.546  0.172   3.175    0.001
housing    0.572  0.191   2.992    0.003
balance    0.692  0.199   3.479    0.001
loan       0.679  0.275   2.469    0.014
marital    1.005  0.275   3.657    0.000

education 和 campaign 的 p 值始终高于 0.05，因此未入选。

默认的 positive=True 使每个系数都为正：只有扩展后模型的所有系数都为正时变量才会入选，系数不为正的变量会被优先移除。这里 previous 本来就因 p 值而未能入选。若放宽显著性水平，它能通过 p 值检验，只有符号规则会把它排除在外：

>>> lenient = {"p_enter": 0.7, "p_remove": 0.7}
>>> "previous" in stepwise(X, target, **lenient, positive=False)
True
>>> "previous" in stepwise(X, target, **lenient)
False

备注

逐步回归在同一份数据上检验了许多模型，因此所选模型的 p 值偏乐观。请把结果当作建议：与业务方逐一审核变量，并在使用前用验证样本检验模型。

样本权重#

logistic_regression() 和 stepwise() 接受 weights ：把每一行计为相应个数相同观测的频数权重。因此整数权重与重复这些行得到相同的系数、标准误和变量选择：

>>> weights = np.random.default_rng(0).integers(1, 4, len(X))
>>> repeated = np.repeat(np.arange(len(X)), weights)
>>> weighted = logistic_regression(X[selected], target, weights=weights)
>>> np.allclose(weighted, logistic_regression(X[selected].iloc[repeated], target.iloc[repeated]))
True
>>> stepwise(X[kept], target, weights=weights).equals(
...     stepwise(X[kept].iloc[repeated], target.iloc[repeated])
... )
True

标准误把总权重当作独立观测的个数，因此取决于权重的尺度：把每个权重加倍会使标准误除以 \(\sqrt 2\) ，并降低每个 p 值，就像样本加倍一样。

>>> doubled = logistic_regression(X[selected], target, weights=2 * weights)
>>> print(f"{(weighted['se'] / doubled['se']).mean():.4f}")
1.4142

不表示观测个数的权重给不出与数据相符的标准误。 拒绝推断 中拒绝推断的权重会使标准误偏小：拒绝申请人变成一行坏样本和一行好样本，其结果是推断出来的而不是观测到的；重新加权则让每个获批申请人计为多个申请人，但这些行都被计为观测。应把这类拟合的 p 值视为偏乐观的结果，并在获批申请人上选择变量。
