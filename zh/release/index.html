版本说明#

未发布#

上次发布以来合并的改动。

新增#

  • kivi.lifetime.conditional_matrix 在 Belkin、Suchower 和 Forest（1998）的单因子模型中把转移矩阵移到给定的经济状况：违约、降级和升级都随一个系统因子变化，违约列就是 kivi.capital.conditional_pd 的条件 PD。违约状态保持为吸收态，因此一个情景的各期平移矩阵相乘即得到其累计 PD。

  • kivi.lifetime.matrix_factor 用极大似然由一期的计数矩阵估计该期的因子， kivi.lifetime.matrix_correlation 估计使多期因子的样本方差为 1 的相关系数。

  • kivi.datasets.make_loan_panel 新增 correlation 和 factors ，用每月的系统因子使所有贷款的还款一起变化。默认的相关系数为 0，得到与以前版本相同的面板。

  • kivi.scorecard.ScorecardSpec 为生产环境保存完整的评分卡：其各特征的 BinningSpec 、每个分组的分值（可以取整或手工调整）、刻度、开发样本中没有的分组的分值，以及可选的 PD 校准和主标尺。校准可以是对数几率的平移或 Platt 缩放，也可以是评分的保序校准。 points 、 score 、 probability 、 grade 和 reason_codes 把评分卡应用于任意样本； score 逐列相加分值，因此分组相同的申请人在任何计算机上都得到完全相同的评分。

  • ScorecardSpec.from_model 由基于 WOE 值的逻辑回归的系数构建方案， to_json 和 from_json 把它保存和加载为带版本号的 JSON（格式版本 1）。读取时拒绝重复的键以及文本中的 NaN 或 Infinity 。

变更#

  • 行数远多于列数时， kivi.selection.vif_filter 快得多：它只对标准化后的列分解一次，此后每一轮的 VIF 都由一个小方阵算出；50,000 行、40 列时约快 20 倍。保留的变量不变，因为它比较的 VIF 与 kivi.selection.vif 的结果只差舍入误差。

修复#

  • kivi.scorecard.score_scaling 、 pd_to_score 、 score_to_pd 、 points_table 、 woe_to_points 和 reason_codes 遇到浮点数无法表示的过大整数参数（例如 pdo=10**400 ）时，引发 ValueError 而不是 OverflowError 。

1.8.0（2026-11-25）#

新增#

  • kivi.vintage.default_rate_table 按 EBA 的 PD 估计指引中的队列法，给出每个等级的一年违约率，默认以季末为起点月。起点月处于违约的贷款不属于任何队列，等级取起点月的等级，一年内违约两次的贷款只计一次，一年内未违约就离开面板的贷款仍留在队列中，并计入 exited 。 probability 增加每个队列的平均 PD。

  • kivi.calibration.central_tendency_shift 返回 log odds 的平移量，使校准样本的平均 PD 等于中心趋势（例如长期平均违约率），且不改变 PD 的顺序，即 Tasche（2013）的缩放似然比。

  • kivi.calibration.quasi_moment_fit 按中心趋势和准确性比率拟合 logistic PD 曲线，即 Tasche（2009）的 quasi moment matching，返回由 kivi.calibration.platt_predict 应用的斜率和截距。

  • kivi.binning.optimal_edges 在等频细分箱的所有合并方式中，用动态规划精确找出信息值最大的分箱边界，约束包括最大箱数、每箱的最小占比（ min_bin_share ）、每箱事件数和非事件数的最小值（ min_bin_events ），以及 WOE 的趋势 trend ： "increasing" 、 "decreasing" 、 "u_shaped" 、 "inverted_u" 、 "any" ，或默认的 "auto" ，即两种单调趋势中较好的一种。 kivi.spec.fit_spec 用 method="optimal" 调用它。

  • kivi.binning.chimerge_edges 和 kivi.binning.monotonic_edges 新增 min_bin_share ：在其他合并之前，占比低于拟合取值该比例的箱，会与卡方统计量较小的相邻箱合并。默认值 0 保持以前版本的结果。

  • WOE 与 IV 指南说明了为什么有监督分箱在其开发样本上的信息值偏乐观，以及如何在验证样本上或用置换检验衡量它。

  • kivi.plotting 新增五种结果表的图： survival_chart() （按期的 cumulative_pd 或 survival 阶梯线；对 cumulative_pd 有竞争风险时画出两类）、 transition_chart() （把迁移矩阵画成热力图，对角线描边）、 rule_set_chart() （每条规则的 new_hits 及 approval_rate ）、 profit_chart() （ profit 对 approval_rate 的曲线，标出最优截断点）和 lgd_chart() （各组的 mean 、 zero_share 和 full_share ）。

  • kivi.rules.rule_candidates() 在数据框的数值列中搜索单阈值政策规则：用 kivi.binning.tree_edges() 或 kivi.binning.ks_edges() 拟合切点，每个阈值保留事件率较高的一侧，并按提升度从高到低列出满足 min_hit_rate 和 min_lift 的规则。其计数与 kivi.rules.rule_table() 对同一规则的结果相同，缺失值和特殊值不命中任何规则。

  • kivi.binning.variance_edges 把驱动因素的分箱边界拟合到连续型响应上，例如实际 LGD 或 CCF：它在等频细分箱的所有合并方式中，用 optimal_edges 的动态规划精确找出箱内响应平方和最小的分箱，约束包括最大箱数、每箱取值的最小占比，以及各箱均值的趋势 trend 。响应可以落在 [0, 1] 之外，但不能缺失； weights 为频数权重。请用 kivi.binning.cut 对取值分组，再用 kivi.lgd.lgd_table 汇总；LGD 与 EAD 指南就是这样为有抵押贷款的贷款价值比拟合分段的。

1.7.0（2026-11-25）#

新增#

  • kivi.strategy.cutoff_table 新增参数 revenue ，即每个观测的非负收益，例如一笔贷款的利差；传入后表中增加 approved_revenue 列，即通过客群的收益，同时传入 loss 时还增加 profit 列，即收益减去损失。 table["profit"].idxmax() 给出各截断点中利润最高的一个。不传入 revenue 时，表保持不变。

  • 新增 kivi.metrics.expected_maximum_profit ，给出 Verbraken、Bravo、Weber 和 Baesens（2014）提出的信用评分期望最大利润（EMP）：最优截断点下每位申请人的利润，以贷款金额的比例表示，并对违约损失取平均，损失以概率 no_loss_share 为 0、以概率 full_loss_share 为全部贷款，其余均匀分布在两者之间；同时给出最优截断点拒绝的申请人比例。默认值和结果与 R 包 EMP 和 Python 包 empulse 一致， weights 为频数权重。

  • 新模块 kivi.rules 衡量信贷策略中的政策规则，规则以 DataFrame 传入，每条规则一列布尔值，或 0 与 1。 rule_table 给出每条规则的命中数、命中率和独有命中，即规则集中其他规则都没有命中的样本；给出目标时，还给出结果已知的命中、事件数、事件率、提升度、召回率和独有命中中的事件数。 rule_set_table 按顺序执行规则，即决策瀑布表：每一行给出一条规则的新增命中及其中的事件，以及到这条规则为止仍然通过的客群，各列与 kivi.strategy.cutoff_table 相同。与 kivi.strategy.swap_set 一样，目标中的缺失标签表示未知结果；规则中的缺失值会报错； weights 是频数权重。

  • 新增的政策规则指南基于模拟的申请数据，衡量两条政策规则和两条候选规则：它们的命中和事件率、规则的重叠矩阵、以评分截断点为最后一条规则并重现审批决策的瀑布表、规则顺序改变了什么，以及只靠已通过申请人的结果能说明什么、不能说明什么。

1.6.0（2026-11-25）#

新增#

  • 新模块 kivi.lgd 度量违约贷款的违约损失率和信用转换系数并为其建模。 workout_lgd 按年利率（所有贷款一个或每笔贷款一个，天数按 ACT/365 计算）把每笔清收的回收和费用折现到违约日，给出每笔贷款的敞口、回收现值、费用现值和实际 LGD，不截断到 [0, 1]。违约日之前的费用按 EBA LGD 估计指引第 144 段的要求复利计算到违约日。

  • kivi.lgd.conversion_factor 由违约时的提用金额以及参考日的额度和提用金额给出每个授信额度的实际 CCF，参考日已满额或超额使用的额度为 NaN； kivi.lgd.lgd_table 按分组汇总实际 LGD：违约数、平均值、标准差、取值范围以及无损失违约和全额损失违约的份额，并按监管对长期平均的要求先把负的 LGD 记为 0。

  • kivi.lgd.fractional_regression 对取值在 0 到 1 之间的响应（例如实际 LGD）拟合 Papke 和 Wooldridge 的分数 logit，返回与 logistic_regression 相同的系数表，标准误为稳健（HC0）标准误。只含 0 和 1 的响应得到 logistic_regression 的系数。

  • 新增的 LGD 与 EAD 指南把巴塞尔框架、EBA 和中国 2023 年资本管理办法对实际 LGD 和 CCF 的规则并列，并注明段落和条款：折现率、违约前的费用、追加提款、核销、治愈、未结案的清收、长期平均、负值、LGD 和 EAD 下限、参考日、满额使用的额度以及初级法的 CCF。

  • kivi.datasets.make_defaults 为 LGD 和 EAD 模型模拟违约贷款：2018 年至 2024 年间违约的有抵押贷款、无抵押贷款和循环额度，带违约风险敞口、抵押品价值、循环额度在违约前 12 个月的额度和已提用金额、在违约日确定的折现率以及清收结束的日期；在数据截止日 2025 年 6 月 30 日仍未结案的清收，结束日期为缺失值。 kivi.datasets.make_recoveries 模拟其清收过程的现金流，每笔回收、费用或治愈一行，使实际 LGD 呈双峰分布：多数有抵押贷款和已治愈贷款接近 0，其他无抵押贷款和循环额度接近 1，另有少数负的 LGD、少数高于 1 的 LGD 和少数违约前的法律费用。循环额度的实际 CCF 大多在 0 到 1 之间。同一个 rng 种子总是给出同样的贷款和现金流。

1.5.0（2026-11-24）#

新增#

  • 新模块 kivi.capital 按内部评级法计算监管资本。 asset_correlation 和 capital_requirement 计算巴塞尔框架（CRE31）和中国 2023 年资本规则中公司敞口、高波动商业房地产、个人住房抵押贷款、合格循环零售敞口和其他零售敞口的风险权重函数，包括按 turnover 和 turnover_range （可取任一辖区的界限）所做的中小企业调整、对 financial 金融机构乘以 1.25，以及期限调整。它们复现了巴塞尔 II 附件 5 的 152 个风险权重。

  • kivi.capital.conditional_pd 给出 Vasicek 单因子模型在某个经济情景下的 PD， systematic_factor 给出观察到的违约率所对应的因子， vasicek_fit 用矩估计由违约率序列估计长期 PD 和资产相关系数，允许出现没有违约的年份。

  • kivi.capital.most_prudent_pd 给出 Pluto 和 Tasche 对违约很少或没有违约的组合的 PD 的最审慎上界，可假设违约独立或相关，并复现了其论文中的表格。

  • 新的监管资本指南并列给出巴塞尔框架和中国规则的参数及其条款：中小企业的区间和单位、金融机构乘数、PD 和 LGD 下限、初级法的 LGD、期限、高级法的适用范围以及输出下限。

  • kivi.lifetime.survival_table 由每笔贷款直到违约、因其他原因退出或最后一次被观测的持续期估计累计 PD 期限结构。它给出每期处于风险中的贷款、违约的贷款、其他原因退出的贷款和删失的贷款，以及风险率、仍在账上的概率和累计 PD：Kaplan–Meier 估计；或在给出 competing （例如提前还款）时，违约累计发生率的 Aalen–Johansen 估计，它不会像把已还清贷款计为删失的 1 − Kaplan–Meier 那样高估 PD。 entry 处理左截断，例如在贷款发放之后才开始的面板； weights 为频数权重。其 cumulative_pd 可以像 vintage 曲线一样用 convert_pd 转换。

  • kivi.datasets.make_loan_panel 新增 prepayment ，即正常贷款提前一次还清全部余额的月度概率。提前还款的贷款当月余额为 0，此后不再有记录，因此各列保持不变。默认值 0 对每个 rng 都给出与以前相同的面板。

  • 存续期 PD 指南展示如何从月度贷款面板得到持续期、违约和还款，为什么贷款会提前还款时存续期 PD 是累计发生率而不是 1 − Kaplan–Meier， entry 如何校正开始较晚的面板，以及用 logistic_regression 在“人-期”表上拟合的离散时间风险模型。

变更#

  • 监管资本指南排在模型验证指南之后。首页、用户指南索引和两份 README 都介绍了 kivi.capital 和 survival_table ，并配有各资产类别的风险权重随 PD 变化的图，以及把提前还款作为竞争风险或作为删失时的累计 PD 图。

1.4.0（2026-11-24）#

新增#

  • kivi.plotting.distribution_chart 用并排的柱形绘制增益表或 WOE 表每一行占全部非事件和占全部事件的比例，由原始的 non_event 和 event 计数算出，保持表的行顺序并保留空行。

  • kivi.plotting.precision_recall_chart 以阶梯的形式绘制 ROC 表每个阈值下的精确率相对于真正例率（即召回率）的变化，阶梯下的面积就是平均精确率，并用一条虚线标出样本的事件率，即随机排序评分的精确率。

  • kivi.selection.vif_filter 剔除 VIF 最大的变量，重新计算其余变量的 VIF，如此反复，直到没有 VIF 超过 threshold （默认 5）。VIF 为无穷大的变量先被剔除， priority （例如信息值）在 VIF 并列时决定剔除哪一个。它与 correlation_filter 一样返回保留的列。

新增#

  • 新模块 kivi.features 以时点正确的方式计算事件数据（如交易）的时间窗特征。 window_features 在截止于观察表每一行的观察时间（如申请日期）的窗口内聚合每个主体的事件，从不使用该时间当时及之后的事件。窗口可以按自然月计，如 "3M" ，也可以按天计，如 "90D" ； ("6M", "3M") 这样的一对表示最近一期之前的那一期； closed="right" 则把观察时间当时的事件计入。聚合有 count 、 sum 、 mean 、 min 、 max 、 std 、 nunique 、 first 、 last 和 days_since_last ， ratios 计算两个特征之比， prefix 为筛选后事件的特征命名。列名为 {prefix}{column}_{aggregation}_{window} ，另有每个窗口的事件数 {prefix}events_{window} 。事件只排序一次，每个窗口的边界用二分查找确定，因此计数、和、均值以及第一个和最后一个值的耗时随行数增长，而 min 、 max 、 std 和 nunique 要查看每个窗口中的每个事件。

  • kivi.binning.cut 现在对不属于特殊值的无穷值引发错误。 pandas.cut 会让 -inf 不落入任何区间、从而被算作缺失值，而把 inf 放进最后一个区间。若要让无穷值编码单独成组，请把它们传入 special 。

  • kivi.spec.BinningSpec.woe_transform 会给 inf 赋予最后一个区间的 WOE，而 -inf 属于未见分组。现在两者都属于未见分组，与所有不属于该列特殊值的无穷值一样：除非该列指定了未见分组的 WOE，否则会引发错误。 BinningSpec.cut 把两者都留为缺失值。

  • kivi.calibration 的计数参数过去把 True 和 False 读作 1 和 0，因此 binomial_test([True], [True], 0.5) 返回 0.5。现在 binomial_test 、 jeffreys_test 、 hosmer_lemeshow 和 fit_grade_pd 的 event 与 total ，以及 herfindahl_index 的 counts 都拒绝布尔值，与权重一致。概率和评分仍把布尔值算作 1 和 0。

0.8.0（2026-11-21）#

新增#

  • kivi.binning 以与数值分箱相同的两步对类别变量的类别分组。 category_groups 把低于 min_share 或 min_count 的类别归为一组， chimerge_groups 按平滑后的 WOE 对类别排序，并在 max_groups 、 alpha 和 min_group_share 的约束下用 ChiMerge 合并相邻类别。两者都返回从类别到组的 dict，接受 special 和 weights ，并排除缺失值。 group_categories 把该 dict 应用到任意样本；分组映射中没有的类别会引发错误，除非 unseen 指定了它应归入的组。

  • fit_spec 对 method 中以 "rare" 或 "chimerge" 指定的类别列分组，此时 special 和 options 也适用于该列， "chimerge" 列还适用 bins 。 BinningSpec 把分组映射保存在新字段 groups 中，并在 cut 和 woe_transform 中应用。没有分组的列与以前的拟合结果相同。

  • 已分组列的未见分组策略可以用 {"group": label} 指定其中一个组：此时 cut 把新类别分配到该组， woe_transform 让它们使用该组的 WOE。

  • 含已分组列的 BinningSpec 以 format_version 2 保存，该版本增加了分组映射和未见分组；其他分箱方案仍以版本 1 保存，因此早期版本的 kivi 也能读取。 from_json 能读取这两个版本。

  • 新模块 kivi.lifetime 提供存续期 PD 和 IFRS 9 的预期信用损失。 convert_pd 在累计、边际和条件 PD 之间转换 PD 期限结构（例如 vintage 表的累计坏账率），批次尚未达到的账龄保持缺失。 transition_pd 在违约状态设为吸收态的情况下，推算转移矩阵每个状态在任意期数下的累计 PD。

  • expected_credit_loss 把报告日之后每一期的边际 PD、LGD 和 EAD 按实际利率折现求和，得到每个账户的 12 个月或整个存续期预期信用损失。LGD 和 EAD 可以是常数、每个账户一个值，或每个账户每期一个值的计划表。

  • significant_increase 按相对和绝对 PD 阈值标记信用风险显著增加；这两个阈值是主体的政策，因此没有默认值。 assign_stages 根据这些标记、逾期天数兜底标准（默认按 IFRS 9 的假设，第二阶段为逾期超过 30 天，第三阶段为逾期 90 天及以上）以及违约标记确定第一到第三阶段， stage_table 汇总每个阶段的敞口和损失准备，并给出覆盖率。

  • 新模块 kivi.monitoring 按期跟踪评分。 monitoring_table 每期一行（例如每月），给出观测数、已知结果数和事件数、已知结果上的 AUC、Gini 和 KS，以及评分相对基准期或基准样本的 PSI，评分段只在基准上拟合一次。缺失的目标值表示结果尚未得知：它计入 total ，但不计入事件相关的列；两类结果不全的期，其区分能力为 NaN 而不是报错。

  • stability_table 给出每个已分组变量在每一期相对同一基准的 PSI，用于稳定性报告的变量部分。两个函数都接受 weights ，整数权重与重复相应行得到的表相同；对 monitoring_table 而言，这要求评分段边界相同。

  • kivi.metrics.roc_table 列出 ROC 曲线上的点，从高到低每个不同的评分一行，包含累计事件数和非事件数、真正例率和假正例率以及精确率。曲线下各梯形的面积之和等于 roc_auc ，两个比率之间的最大差距等于 ks 。

  • kivi.metrics.roc_auc_interval 用 DeLong 方法及 Sun 和 Xu 的快速中秩算法，给出 AUC 和 Gini 系数的标准误以及置信水平为 level 的置信区间。

  • kivi.metrics.delong_test 检验同一批观测的两个评分的 AUC 是否相同，返回两个 AUC、它们的差值及其标准误和区间、z 统计量和双侧 p 值。

  • 标准误把 weights 视为频数权重，因此整数权重与重复相应行的结果相同。对于 Hanley 和 McNeil（1982）以及 DeLong 等人（1988）的数据，它们重现了 Stata 和 SAS 手册公布的 DeLong 结果。

变更#

  • BinningSpec.format_version 现在是每个分箱方案写出的 JSON 格式版本，为 1 或 2，而不再是等于 1 的类属性。新的类常量 BinningSpec.FORMAT_VERSION 是 kivi 能读取的最新版本，目前为 2。

  • 各篇主题指南采用同一结构和相同的小节标题，例如 Special values （特殊值）、 Sample weights （样本权重）和 Errors and warnings （错误与警告），开篇链接到前后两个步骤。分箱指南把特殊值的内容集中到一节，单变量概况在按 IV 筛选之后再介绍特殊值编码。kivi 函数在每一节第一次出现时都链接到其 API 条目。

  • API 参考新增两页并排在最前面：一页是所有函数共同遵守的约定，包括参数顺序、仅限关键字的选项、输入与结果、样本权重和错误信息；另一页是信用风险术语表。模块页面按用户指南的顺序排列，每页都有简介和指向对应指南的链接， :mod: 链接现在也能跳转到这些页面。

  • 迁移指南把 BinaryMetrics 的 ROC 曲线和精确率-召回率曲线、精确率、召回率、F1 分数和混淆矩阵，以及 evaluate/Heatmap.py 的相关性热力图列为未移植，并给出替代做法。

  • 用户指南新增“模型监控”和“存续期 PD 与预期信用损失”两篇指南，并按项目顺序放在相应位置。术语表和约定页涵盖新函数的术语和规则。风控建模流程示例给出 Gini 的 DeLong 区间，并引向监控和预期信用损失。各指南新增类别分组、ROC 曲线、监控报告、各期变量稳定性和 PD 期限结构图，README 展示监控图和存续期 PD 图。

修复#

  • 使用非整数 weights 时， kivi.metrics.roc_auc 和 kivi.metrics.gini 可能因舍入而返回略大于 1 的值。现在二者都不超过 1，与文档一致；其他取值不变。

  • 当两个样本都是无序分类且类别相同但排列顺序不同时（例如 ["a", "b"] 和 ["b", "a"] ）， kivi.stability.psi_table 、 kivi.stability.csi_table 和 kivi.monitoring.stability_table 会把当前样本的分组计入错误的标签。现在分组按标签匹配。

  • 两个样本是按不同整数边界划分的 pandas.cut 分箱、且其中一个含有缺失值时， kivi.stability.psi_table 和 kivi.stability.csi_table 会引发 pandas 的 IntCastingNaNError 。现在这类分箱以浮点数区间合并，它们与对应的整数区间相等。

  • 当一个样本是含无穷边界的 pandas.cut 分箱、而另一个样本是其他分组（按其他边界划分的分箱、移除了未使用类别的分箱、非分类型的区间或其他标签）时， kivi.stability.psi_table 和 kivi.stability.csi_table 在低于 2.2 版的 NumPy 上不再发出 RuntimeWarning （"invalid value encountered in cast"）。表格结果不变。

  • weights Series 过去只与数据的索引比较，因此当评分、取值或分组是数组时，它会与另一个索引的 target Series 按位置匹配。 kivi.metrics 的函数、 kivi.woe.woe_table 、 kivi.calibration.calibration_table 、 platt_fit 和 isotonic_fit 、 kivi.binning 的有监督函数，以及 kivi.selection.logistic_regression 和 stepwise 现在会在这种情况下引发错误，例如 "target and weights must have identical indices"，与描述相同观测的任意其他两个 Series 的处理方式一致。

0.7.0（2026-11-20）#

新增#

  • kivi.datasets.make_applications 按种子模拟贷款申请数据，每个申请人都有数值型和类别型特征、现行评分卡的 PD、政策拒绝、审批决策和真实的违约标记，可用来试验拒绝推断。

  • kivi.calibration.master_scale 根据每个等级的 PD 构建主标尺，例如由 numpy.geomspace 生成的几何网格：每个等级一行，包含其下界、PD 和上界，覆盖 0 到 1。界限默认取相邻 PD 的几何平均数，设置 boundary="arithmetic" 时取其算术平均数，与 0.2 版本相同。

  • fit_grade_pd 按观测违约率拟合每个等级的 PD：把违约率的对数拟合为等级编号的直线，使用以观测数为权重的最小二乘法。没有违约的等级以 smoothing 次违约参与拟合，没有观测的等级从这条直线得到 PD。

  • assign_grades 以有序分类变量的形式为每个预测 PD 指定标尺上的等级， calibration_table 可以直接按标尺的顺序统计这些等级。恰好落在界限上的 PD 归入较低的等级，与 pandas.cut 相同。

  • 新模块 kivi.reject_inference 推断拒绝申请人的结果，使在获批申请人上开发的评分卡能在全部申请人上重新拟合。 fuzzy_augmentation 把每个拒绝申请人拆成按其 PD 加权的一行坏样本和一行好样本； parceling 用带种子的生成器按各评分段的坏账率标记其中的拒绝申请人，或者返回期望权重； reweighting 以各评分段通过率的倒数为该段获批申请人加权。大于 1 的 factor 会提高推断的坏账率，没有获批申请人的评分段会引发错误。

  • logistic_regression 和 stepwise 接受 weights ，即与 statsmodels 的 GLM(freq_weights=...) 相同的频数权重。整数权重与重复行得到相同的系数、标准误和变量选择；不表示观测个数的权重（例如拒绝推断的权重）会使标准误和 p 值偏小。

  • 新模块 kivi.strategy 支撑评分卡之后的信贷决策。cutoff_table 针对 PD 或取负分数的每个候选截断点，给出通过率、通过客群的坏账率、被拒绝的坏客户和好客户所占比例，传入 loss 时还给出通过客群的预期损失。评分不高于截断点即予以通过，因此相同评分总是得到相同的决策。

  • swap_set 在各自的截断点上比较现行评分与新评分的决策：两者都通过的申请人、换入和换出，以及两者都拒绝的申请人，并在结果已知时给出事件率。缺失的目标值表示结果未知，例如被现行评分拒绝的申请人。

  • expected_loss 将 PD、LGD 与 EAD 相乘，expected_loss_table 汇总每个等级的敞口和预期损失，并给出预期损失率和按敞口加权的 PD。

  • 新模块 kivi.univariate 对模型的候选变量进行概况分析。 profile_table 用一行概括数据框的每一列：类型、缺失值、不同取值个数和最常见的取值；数值列还给出取值范围、分位数、均值和标准差。有目标变量时，还会加入缺失行与非缺失行的事件率和提升度、快速分箱的 IV 以及数值取值的 Gini 系数。分位数重合会记录在 tied_bins 列中，而不会对每一列发出警告； special 编码和 weights 的用法与 fit_spec 相同。

变更#

  • 风控建模流程示例改用 profile_table 筛选候选变量，用 master_scale 和 assign_grades 在主标尺上校准 PD，并用 cutoff_table 和 expected_loss_table 设定截断点。用户指南新增截断点曲线、拒绝推断、等级 PD 和缺失值图，README 也展示了截断点图和拒绝推断图。

修复#

  • gains_table 在评分并列时发出的警告曾建议使用 bin_edges 的 special 参数，而 gains_table 并没有这个参数。现在它与 cutoff_table 一样，建议减少箱数或给出明确的边界，并且警告指向调用它的那一行。

0.6.0（2026-11-20）#

新增#

  • kivi.calibration.platt_fit 和 platt_predict 用逻辑曲线校准评分， isotonic_fit 和 isotonic_predict 则用随评分上升的阶梯函数进行校准。拟合结果是普通的数值（斜率和截距，或分段边界及其概率），可以应用到之后任何样本的评分上。

  • kivi.stability.csi_table 计算评分卡变量的特征稳定性指标：每组占比从基准样本到当前样本的变化乘以该组的分值。其总和是该变量平均分值的变化，对所有变量求和则是平均分数的变化。占比不做平滑；没有分值的分组会引发错误，除非用 unseen_points 给出其分值。

  • kivi.datasets.load_bank 读取银行营销数据。 Dataset.bank_data 返回相同的数据，并且可以继续使用，不会发出警告。

  • kivi.datasets.make_loan_panel 按给定种子模拟分期贷款的月度面板数据，其中逾期会向前滚动，也会回到正常，可用来试用 Vintage 和滚动率相关函数。

  • reason_codes 新增 unseen_points 参数，即 woe_transform 用 unseen 编码的分组中申请人的分值，可以是一个值，也可以按变量给出。与任何分组都不匹配、但与 unseen_points 相差不超过 atol 的分值视为没有造成损失，因此该变量不会成为这些申请人的原因。其他任何不匹配仍会引发错误，错误信息现在会先提示检查 atol 以及模型和刻度。

  • 新模块 kivi.spec 一次对数据框的所有列分箱。 fit_spec 用 bin_edges 、按列选定的有监督方法或给定的边界拟合每个数值列，并计算每个分组的 WOE；其他列保留其标签。分箱从不自动更改。

  • 得到的 BinningSpec 用 cut 对样本分组，用 woe_transform 按列的未见分组策略编码，并保留每一列的 woe_table 供审阅。 to_json 和 from_json 保存并加载它，分组和 WOE 编码都不会改变，因此生产环境可以完全复现开发时的结果。

  • 新模块 kivi.vintage 用于分析贷款资产组合。 vintage_table 按账龄给出每个放款批次的累计坏账率，可以按笔数或按放款金额计算，并把批次尚未达到的账龄留为 NaN。 transition_matrix 统计贷款在逾期档位之间、或债务人在评级之间的迁移，结果可以是计数、行内比例或余额之和； roll_rates 给出每个档位滚动到下一个更差档位的比例。

  • roc_auc 、 gini 、 ks 、 gains_table 、 brier_score 和 calibration_table 与 woe_table 一样接受 weights 。计数变为权重之和，整数权重与重复相应行的结果相同（ gains_table 须使用固定边界）。

变更#

  • 风控建模流程示例用 fit_spec 保存入选变量的分箱，并在稳定性报告中加入每个评分卡变量的特征稳定性指数（CSI）。用户指南新增增益、校准和 vintage 曲线图，README 也展示了增益图和 vintage 曲线图。

修复#

  • 在 pandas 2.0 上，目标为可空整数类型时， calibration_table 不再报错。

  • cut 、 bin_edges 和有监督分箱函数会在转换数字字符串之后再匹配特殊编码，因此按文本读入的列（例如 pdays 中的 "-1" ）会让编码 -1 单独成组，而不是落入某个区间。布尔型特殊编码会报错：由于 True == 1 ，它们原先会匹配取值 1。

移除#

  • 移除 kivi.evaluate ；请从 kivi.stability 导入 psi_table 等稳定性函数。

  • bin_edges 不再接受按位置传入的 method ；请用关键字传入，例如 method="uniform" 。

0.5.0（2026-11-20）#

新增#

  • 新模块 kivi.calibration 用于检查 PD 的校准情况。 prior_correction 和 corrected_intercept 在开发样本的事件率与总体不同时校正模型。 calibration_table 比较主标尺等级或其他分组的观测违约率与预测违约率，再由 binomial_test 、 jeffreys_test 和 hosmer_lemeshow 进行检验。 herfindahl_index 衡量各等级的集中程度。

  • kivi.woe.woe 、 kivi.woe.iv 和 kivi.stability.psi 可直接根据已汇总的计数（包括加权计数）计算 WOE、IV 和 PSI。

  • kivi.stability 模块包含 psi_table 和 psi 。

  • kivi.metrics 根据二分类目标评估评分。roc_auc、gini 和 ks 衡量评分把事件排在非事件之前的能力，gains_table 按评分段报告事件率、捕获的事件、KS 和提升度，brier_score 将预测概率与实际结果进行比较。与 woe_table 一样，这些函数都是评分在前、目标在后，与 scikit-learn 的顺序相反。评分越高必须表示事件概率越高，因此评分卡分数须取负后再传入。

  • bin_edges 、 chimerge_edges 、 tree_edges 、 monotonic_edges 和 woe_table 新增 weights 参数， psi_table 新增 reference_weights 和 current_weights 参数。计数变为权重之和，等频边界变为逆累积分布意义下的加权分位数，权重为零的观测或分组会被排除。

  • 新模块 kivi.scorecard 把基于 WOE 的逻辑回归转换为评分卡分值。 score_scaling 、 pd_to_score 和 score_to_pd 依据 PDO（几率翻倍所需分数）、基准分数和基准几率，在概率与分数之间相互转换。 points_table 给出每个分组的分值， woe_to_points 给出每个申请人的分值， reason_codes 列出让申请人失分最多的变量。

  • 新增 kivi.selection 模块，用于从 WOE 编码的候选变量中筛选评分卡变量。 correlation_filter 对每一对强相关的变量剔除其中一个，保留优先级（例如 IV）较高的那个。 vif 计算方差膨胀因子。

  • logistic_regression 用 NumPy 拟合逻辑回归，并报告每个系数及其标准误、Wald z 统计量和 p 值。当变量把两类完全分开、以致估计值不存在时，它会抛出 SeparationError 。

  • stepwise 按 p 值进行向前、向后或双向的变量筛选。默认情况下，它使每个系数都为正，这正是 kivi 的 WOE 所预期的。

  • woe_transform 用 woe_table 结果中的 WOE 替换每个分组，这正是评分卡模型使用的编码。不在表中的分组会引发错误，除非用 unseen 指定其 WOE。

变更#

  • API 参考改为每个模块一页。原来指向单页中某个函数的链接，现在改为指向该函数所在模块的页面。

  • bin_edges 的 method 参数改为仅限关键字。按位置传入会发出 FutureWarning ，并将在 0.6.0 中失效。

  • kivi.evaluate 已弃用，请改用 kivi.stability 。从中导入 psi_table 会发出 FutureWarning ，该模块将在 0.6.0 中移除。

  • 风控建模流程现在完整串联：变量筛选、逻辑回归拟合、评分卡分值、模型评估、校准以及分数稳定性。

  • woe_table 为每组新增 total 、 total_share 和 event_rate 三列，即分箱报表中常用的列。它们使用实际观测到的计数；只有 non_event_share 和 event_share 经过平滑。

修复#

  • 分组来自带无穷端点的 pandas.cut 时， woe_table 和 psi_table 在 NumPy 2.2 以下的版本上不再引发 pandas 的 RuntimeWarning: invalid value encountered in cast 。

  • 在 pandas 2.0 上，可空整数或浮点数与 special 一起使用时， cut 和监督分箱函数不再报错。

0.4.0（2026-11-19）#

新增#

  • bin_edges 新增 special 参数。 -1 、 -999 等编码在拟合边界时会被排除。

  • kivi.binning.cut 把取值分配到拟合好的各箱，并让每个特殊值单独成组。不传特殊值时，结果与 pandas.cut 相同。

  • chimerge_edges、tree_edges 和 monotonic_edges 依据二分类目标拟合边界：分别是对等频细分箱做 ChiMerge 合并、按熵或基尼指数做决策树切分（可设定最小箱占比），以及合并到 WOE 单调为止。它们接受与 woe_table 相同的类数组输入，与 bin_edges 一样返回两端为无穷的边界，只依赖 NumPy 和 pandas。

  • 分箱指南在银行数据上对比了这三种方法，并为每种方法配有图表。

  • chimerge_edges、tree_edges 和 monotonic_edges 与 bin_edges 一样接受 special 参数。这些编码连同其标签不参与拟合；再把相同的编码传给 kivi.binning.cut ，即可让每个编码单独成组。

变更#

  • bin_edges 、 woe_table 和 psi_table 接受任意一维类数组输入，例如列表或 NumPy 数组。传给 woe_table 的分组与标签序列仍须共享同一索引；数组和列表按位置对应。

  • 边界重合导致实际箱数少于期望箱数时， bin_edges 会发出 UserWarning 。提示信息会写出出现次数最多的取值，便于将其传给 special 。

  • 错误信息会写明参数名以及收到的值。

  • 从未安装的源码目录导入 kivi 时， kivi.__version__ 为 "0+unknown" ，不再抛出错误。

  • 分组计数改用 numpy.bincount ，在大样本上更快。

  • API 参考补充了异常、警告、公式和相关函数的说明。

  • woe_table 和 psi_table 对分类型分组（包括 pandas.cut 的结果）按类别顺序排列，缺失值排在最后。其他标签仍按首次出现的次序排列。此前所有分组都按首次出现的次序排列，需要用 sort_index 才能让区间有序。
