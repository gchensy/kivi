Charts#

Draw the result tables of the other modules with matplotlib, one function per table, such as woe_chart() for a WOE table, roc_chart() for a ROC table, monitoring_chart() for a monitoring report, survival_chart() for a survival table and profit_chart() for a cut-off table with profit. Each function draws on the Axes passed as ax, or on a new figure, and returns the Axes it drew on. matplotlib is an optional dependency: install it with pip install "kivi[plot]".

See Charts for examples on the bundled data.

kivi.plotting.woe_chart(table, *, line='event_rate', ax=None)#

Draw the population share of each group with its event rate or WOE.

The bars show total_share, the share of the sample in each group, on the left y-axis, and a line shows event_rate or woe on a second y-axis on the right. This is the one chart of the module with two y-axes, and so the one that returns two Axes. The groups keep the order of the table, and the legend gives the IV of the whole table.

Parameters:
tablepandas.DataFrame

A table from kivi.woe.woe_table, or one of the tables of a kivi.spec.BinningSpec. It needs the columns total_share, iv and the column named by line.

line{‘event_rate’, ‘woe’}, default ‘event_rate’

Column drawn as the line.

axmatplotlib.axes.Axes, optional

Axes of the bars. A new figure is created when it is not given.

Returns:
barsmatplotlib.axes.Axes

Axes of the bars, ax when it is given.

linematplotlib.axes.Axes

Axes of the line, a twin of bars that shares its x-axis.

Raises:
ImportError

If matplotlib is not installed.

ValueError

If table is not a DataFrame, lacks a column it needs or has no rows, a column it needs is not numeric, line is neither 'event_rate' nor 'woe', or ax is not a matplotlib Axes.

See also

kivi.woe.woe_table

The table that this chart draws.

psi_chart

Compare the shares of two samples in the same groups.

Notes

The tick labels are the group labels of the index, with NaN for the group of missing values. Sort the table first, for example with table.sort_index() or table.sort_values("woe"), to draw the groups in another order.

Each y-axis is labeled in the color of what it shows, and the dotted line of zero WOE belongs to the right axis. Both axes leave room at the top for the legend, so that it covers no bar and no point.

Examples

>>> import pandas as pd
>>> from kivi.plotting import woe_chart
>>> from kivi.woe import woe_table
>>> groups = pd.Series(["a", "b", "b", "c", "c", "c"])
>>> target = pd.Series([1, 0, 1, 0, 0, 1])
>>> bars, line = woe_chart(woe_table(groups, target))
>>> [label.get_text() for label in bars.get_xticklabels()]
['a', 'b', 'c']
>>> line.get_ylabel()
'event_rate'
kivi.plotting.correlation_chart(matrix, *, ax=None)#

Draw a correlation matrix as a heatmap with the value in each cell.

Positive correlations are blue and negative ones amber, darker as they approach 1 or -1, so that pairs of variables that carry the same information stand out before a model is fitted.

Parameters:
matrixpandas.DataFrame

Square matrix of correlations with the same labels, in the same order, in its index and columns, such as X.corr() or X.corr(method="spearman") of the WOE-encoded candidates X.

axmatplotlib.axes.Axes, optional

Axes to draw on. A new figure, sized to the number of variables, is created when it is not given.

Returns:
matplotlib.axes.Axes

The Axes drawn on, ax when it is given.

Raises:
ImportError

If matplotlib is not installed.

ValueError

If matrix is not a DataFrame, has no rows, does not have the same labels in its index and columns, has a column that is not numeric or a value outside [-1, 1], such as a covariance, or ax is not a matplotlib Axes.

See also

kivi.selection.correlation_filter

Drop one variable of each highly correlated pair.

kivi.selection.vif

Variance inflation factor of each variable.

Notes

The colors run from -1 to 1 whatever the values, and a missing value, such as the correlation of a constant column, leaves its cell empty. The heatmap is ax.images[0], so ax.figure.colorbar(ax.images[0], ax=ax) adds a color bar.

Examples

>>> import pandas as pd
>>> from kivi.plotting import correlation_chart

>>> ax = correlation_chart(X.corr())
>>> [label.get_text() for label in ax.get_yticklabels()]
['a', 'b', 'c']
>>> ax.texts[1].get_text()
'0.60'

kivi.plotting.precision_recall_chart(table, *, label=None, ax=None)#

Draw the precision against the recall of every threshold of a score.

Flagging the observations from the highest score down, the curve plots precision, the event rate of the flagged observations, against true_positive_rate, the share of all events flagged, also called the recall, as steps whose area is the average precision. A dashed line marks the event rate of the sample, the precision of a score that ranks at random.

Parameters:
tablepandas.DataFrame

A table from kivi.metrics.roc_table. It needs the columns true_positive_rate and precision.

labelstr, optional

Legend entry of the curve. A legend is drawn only when a curve has a label.

axmatplotlib.axes.Axes, optional

Axes to draw on. A new figure is created when it is not given.

Returns:
matplotlib.axes.Axes

The Axes drawn on, ax when it is given.

Raises:
ImportError

If matplotlib is not installed.

ValueError

If table is not a DataFrame, lacks a column it needs or has no rows, a column it needs is not numeric, no row has a precision, or ax is not a matplotlib Axes.

See also

kivi.metrics.roc_table

The table that this chart draws.

roc_chart

The true positive rate against the false positive rate.

kivi.strategy.confusion_table

Precision and recall at chosen cut-offs.

Notes

The first row of a roc table, at the threshold inf, flags nobody and has no precision. From a recall of 0, the curve steps through the other rows: from the recall of one row to that of the next, it stays at the precision of the next row. Straight lines between the rows would overstate the precision between them [1]. With \(R_n\) and \(P_n\) the recall and the precision of the n-th row, and \(R_0 = 0\), the area under the steps is the average precision

\[\mathrm{AP} = \sum_n (R_n - R_{n-1})\, P_n.\]

The last row flags every observation, so its precision is the event rate: the curve ends on the dashed line, which is labeled with that rate at its left end.

The curve takes the next color of the Axes’ color cycle, so that the curves of several scores drawn on the same ax are told apart by color and by label. The dashed line is gray, as the diagonal of roc_chart, and is drawn once for each event rate shown, so that the scores of one sample share it and two samples get one line each.

References

[1]

J. Davis and M. Goadrich, “The Relationship Between Precision-Recall and ROC Curves”, Proceedings of the 23rd International Conference on Machine Learning, 233-240, 2006.

Examples

>>> from kivi.metrics import roc_table
>>> from kivi.plotting import precision_recall_chart
>>> table = roc_table([0.1, 0.4, 0.35, 0.8], [0, 0, 1, 1])
>>> ax = precision_recall_chart(table)
>>> ax.get_xlabel(), ax.get_ylabel()
('true_positive_rate', 'precision')
>>> ax.texts[0].get_text()
'event_rate = 0.5'
kivi.plotting.gains_chart(table, *, ks=True, label=None, ax=None)#

Draw the cumulative shares of events and non-events by score band.

Reviewing the bands from the highest scores down, the curves show the share of all events and of all non-events captured against the share of the sample reviewed, cum_total_share. With ks, a vertical segment marks the band with the largest ks, the gap between the two curves.

Parameters:
tablepandas.DataFrame

A table from kivi.metrics.gains_table, with the highest band first. It needs the columns cum_total_share, cum_event_share, cum_non_event_share and ks.

ksbool, default True

Whether to mark the largest ks.

labelstr, optional

Name of the score, added to the legend entries of both curves, as in cum_event_share (label).

axmatplotlib.axes.Axes, optional

Axes to draw on. A new figure is created when it is not given.

Returns:
matplotlib.axes.Axes

The Axes drawn on, ax when it is given.

Raises:
ImportError

If matplotlib is not installed.

ValueError

If table is not a DataFrame, lacks a column it needs or has no rows, a column it needs is not numeric, ks is not True or False, or ax is not a matplotlib Axes.

See also

kivi.metrics.gains_table

The table that this chart draws.

roc_chart

The same separation over all thresholds.

Notes

Both curves start at the origin, before the first band is reviewed, and each band adds one point. The diagonal is the cum_event_share of a score that ranks at random.

The cum_event_share curve is solid and the cum_non_event_share curve dashed, both in the next color of the Axes’ color cycle, so that the gains of several scores drawn on the same ax are told apart by color and by label. Examples

>>> from kivi.metrics import gains_table

>>> ax = gains_chart(gains_table(score, target, bins=3))
>>> ax.get_xlabel()
'cum_total_share'

'ks = 0.800'
kivi.plotting.distribution_chart(table, *, ax=None)#

Draw the share of all non-events and of all events in each group side by side.

Each row of the table, such as a score band of a gains table or a bin of a WOE table, gets a pair of bars: its share of all the non-events of the table and its share of all the events, from the raw non_event and event counts. The further apart the two distributions lie, the better the score or the variable tells the classes apart.

Parameters:
tablepandas.DataFrame

A table from kivi.metrics.gains_table or kivi.woe.woe_table, or one of the tables of a kivi.spec.BinningSpec. It needs the columns non_event and event.

axmatplotlib.axes.Axes, optional

Axes to draw on. A new figure is created when it is not given.

Returns:
matplotlib.axes.Axes

The Axes drawn on, ax when it is given.

Raises:
ImportError

If matplotlib is not installed.

ValueError

If table is not a DataFrame, lacks a column it needs or has no rows, a column it needs is not numeric, a count is negative or not finite, the table counts no event or no non-event, or ax is not a matplotlib Axes.

See also

kivi.metrics.gains_table

Score bands, with the highest first.

kivi.woe.woe_table

Bins or groups of a variable.

gains_chart

The cumulative shares of the same bands.

psi_chart

The shares of two samples in the same groups.

Notes

The bars keep the order of the table, the highest band first for a gains table, and its empty rows, so that the charts of two samples binned on the same edges line up. The shares are not smoothed, so for a group without events or without non-events they differ from the event_share and non_event_share columns of a WOE table, which give an empty cell the smoothing. The tick labels are the group labels of the index, with NaN for the group of missing values.

The non-events are blue and the events red. The y-axis leaves room at the top for the legend, so that it covers no bar.

Examples

>>> from kivi.metrics import gains_table
>>> from kivi.plotting import distribution_chart
>>> score = [1, 2, 3, 3, 4, 5, 1, 2]
>>> target = [0, 0, 1, 0, 1, 1, 0, 0]
>>> ax = distribution_chart(gains_table(score, target, bins=3))
>>> [label.get_text() for label in ax.get_xticklabels()]
['(3.0, inf]', '(2.0, 3.0]', '(-inf, 2.0]']
>>> [f"{bar.get_height():.2f}" for bar in ax.patches]
['0.00', '0.20', '0.80', '0.67', '0.33', '0.00']

Draw one curve per cohort of its cumulative bad rate by month on book.

Each row of the table is a cohort and each column a month on book. Later cohorts are drawn in darker blue, so that a cohort whose curve rises faster than those before it stands out.

Parameters:
tablepandas.DataFrame

A table from kivi.vintage.vintage_table, with one row per cohort and one numeric column per month on book, or another table of the same shape, such as cumulative PDs from kivi.lifetime.convert_pd.

axmatplotlib.axes.Axes, optional

Axes to draw on. A new figure is created when it is not given.

Returns:
matplotlib.axes.Axes

The Axes drawn on, ax when it is given.

Raises:
ImportError

If matplotlib is not installed.

ValueError

If table is not a DataFrame or has no rows, its columns are not numbers, it holds a value that is not numeric, or ax is not a matplotlib Axes.

See also

kivi.vintage.vintage_table

The table that this chart draws.

Turn the curves into marginal or conditional PDs.

Notes

The missing months of a cohort, those it has not reached or that come before its first observed month on book, are left out of its curve. The x-axis is labeled with the name of the columns.

In a figure of several panels, use a layout engine, such as layout="constrained", to make room for it.

>>> ax = vintage_chart(vintage_table(loan, cohort, month_on_book, bad))

kivi.plotting.survival_chart(table, *, column='cumulative_pd', label=None, ax=None)#

Draw the cumulative PD or the survival curve of a survival table as steps.

The curve starts at period 0 with 0 for cumulative_pd and 1 for survival and changes at each period, as steps, which is how the Kaplan-Meier estimate behaves between observations. When the table was computed with competing risks, the cumulative incidence of the competing cause is drawn next to that of the event.

Parameters:
tablepandas.DataFrame

A table from kivi.lifetime.survival_table. It needs the column named by column, and with competing risks, which is when it has a competing column, also at_risk and survival.

column{‘cumulative_pd’, ‘survival’}, default ‘cumulative_pd’

Column to draw. survival is the all-cause survival, one curve whether or not there are competing risks.

labelstr, optional

Legend entry of the curve, in place of column. With competing risks it is put in front of the name of each cause, as in 'high cumulative_pd' and 'high competing'.

axmatplotlib.axes.Axes, optional

Axes to draw on. A new figure is created when it is not given.

Returns:
matplotlib.axes.Axes

The Axes drawn on, ax when it is given.

Raises:
ImportError

If matplotlib is not installed.

ValueError

If table is not a DataFrame, lacks a column it needs or has no rows, a column it needs is not numeric, column is neither 'cumulative_pd' nor 'survival', or ax is not a matplotlib Axes.

See also

kivi.lifetime.survival_table

The table that this chart draws.

vintage_chart

Cumulative bad rates by cohort.

Notes

With competing risks and column='cumulative_pd' the legend names the curves cumulative_pd and competing. The cumulative incidence of the competing cause is the sum of the all-cause survival of the previous period times competing over at_risk, as that of the event is, so the two curves and the survival add up to 1. Periods after the last one with accounts at risk have no value and end the curves.

The curve starts one period before the first row of the table, so a slice of a table starts at its own first period, and it is drawn one period beyond the last row so that the last change is visible. The limits of the axes cover every curve already drawn on ax, so the curves of several tables, each with a label, can share one. A table without a single value, which is what kivi.lifetime.survival_table gives when nobody is at risk in its first period, draws an empty chart: a flat line at the start value.

Examples

>>> from kivi.lifetime import survival_table
>>> from kivi.plotting import survival_chart
>>> table = survival_table([1, 2, 3, 3, 4], [1, 0, 1, 1, 0])
>>> ax = survival_chart(table)
>>> ax.lines[0].get_ydata().round(3).tolist()
[0.0, 0.2, 0.2, 0.733, 0.733, 0.733]
>>> ax.get_xlabel(), ax.get_ylabel()
('period', 'cumulative_pd')
kivi.plotting.transition_chart(table, *, ax=None)#

Draw a transition matrix as a heatmap with the value in each cell.

The rows are the states before and the columns the states after. The shade of a cell is the share of its row that moved there, so that a table of counts and one of shares look alike, and the diagonal, the entities that stayed, is outlined in amber.

Parameters:
tablepandas.DataFrame

A table from kivi.vintage.transition_matrix, counts or shares (normalize=True), with the states before in its index and the states after in its columns. Missing values leave their cells empty.

axmatplotlib.axes.Axes, optional

Axes to draw on. A new figure, sized to the number of states, is created when it is not given.

Returns:
matplotlib.axes.Axes

The Axes drawn on, ax when it is given.

Raises:
ImportError

If matplotlib is not installed.

ValueError

If table is not a DataFrame, has no rows or fewer than two columns, has a column that is not numeric or a negative value, or ax is not a matplotlib Axes.

See also

kivi.vintage.transition_matrix

The table that this chart draws.

kivi.vintage.roll_rates

The share of each state that moved to the next worse one.

correlation_chart

A heatmap of a correlation matrix.

Notes

A cell is outlined when its row label equals its column label, so a matrix whose states before and after are not the same set has an outline only where they meet. Whole numbers below 10,000 are written in full, shares, when no value exceeds 1, with two decimals, and any other value with three significant digits and a suffix K, M or B, so that weighted counts fit their cells. >>> ax.get_xlabel(), ax.get_ylabel()
('after', 'before')
kivi.plotting.rule_set_chart(table, *, ax=None)#

Draw the share of the book that each rule declines and the approval rate left.

A rule set is a waterfall: each rule declines only the applicants that no earlier rule declined. The bars show the new_hits of each rule, in the order of the table, as a share of all rows, and a line shows the approval_rate of the book after the rule, on the same axis. The approval rate after a rule is therefore the one before it minus its bar, and the first starts from 100%.

kivi.rules.rule_set_table

The table that this chart draws.

cutoff_chart

The same trade-off for a score instead of rules.

Notes

The total that the bars are shares of is the approved of the first rule plus its new_hits, so it counts every row of the rules, outcomes known or not, and is a total weight when the table was computed with weights.
