Univariate profile
==================

.. module:: kivi.univariate

Profile every column of a data frame in one row: how complete it is, how its values are distributed and, with a binary target, how strongly it separates events from non-events. :func:`~kivi.univariate.profile_table` is the first look at the candidates of a model.

See :doc:`/user_guide/univariate` for an example and how to read the profile.
