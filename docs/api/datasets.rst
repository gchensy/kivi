Example data
============

.. module:: kivi.datasets

Example data for the guides: the bank marketing data of :func:`~kivi.datasets.load_bank`, and the synthetic loan panel, loan applications and account transactions of :func:`~kivi.datasets.make_loan_panel`, :func:`~kivi.datasets.make_applications` and :func:`~kivi.datasets.make_transactions`.

See :doc:`/user_guide/datasets` for their columns and how the synthetic data are simulated.
