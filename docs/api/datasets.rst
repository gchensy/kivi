Example data
============

.. module:: kivi.datasets

Example data for the guides: the bank marketing data of :func:`~kivi.datasets.load_bank`, and the synthetic loan panel and loan applications of :func:`~kivi.datasets.make_loan_panel` and :func:`~kivi.datasets.make_applications`.

See :doc:`/user_guide/datasets` for their columns and how the synthetic data are simulated.
