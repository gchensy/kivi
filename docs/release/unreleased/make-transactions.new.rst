* ``kivi.datasets.make_transactions`` simulates the account transactions that precede the applications of ``make_applications``: card purchases, cash withdrawals and instalment repayments over the twelve months (or ``months``) before each application date, as a long table with the applicant id, the timestamp, the amount, the kind and the merchant category. Defaulters withdraw more cash as the application nears and repay less, and the volumes scale with income, so that features of time windows carry a clear but imperfect signal about ``target``. The function also returns the table of observations, one row per application with its date, and takes the dates from a column, as one date or as a Series. The same ``rng`` seed always gives the same transactions.
