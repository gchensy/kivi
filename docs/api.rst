API reference
=============

Import each function from its module, as in ``from kivi.woe import woe_table``. :doc:`api/conventions` describes the rules that every function follows for its arguments, results and errors, :doc:`api/compatibility` what a release may change and how it announces the change, and :doc:`api/glossary` defines the terms of the guides. Each of the other pages documents one module, in the order of the user guide.
